# MediaServer Configuration

## Basic Configuration

Configure the fundamental settings of your MediaServer:

### Database Setup

Set up your database connection for storing media metadata.

### Library Paths

Add directories containing your media files:

- Movies
- TV Shows
- Music
- Documents

### Server Settings

Configure server port, logging level, and other runtime options.

## Advanced Configuration

For advanced users, additional configuration options are available in the config file.
