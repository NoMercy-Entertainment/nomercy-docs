# NoMercy MediaServer

## Overview

NoMercy MediaServer is a comprehensive solution for managing and streaming your media collection.

## Features

- **Centralized Management**: Organize all your media in one place
- **Streaming**: Stream media to any device
- **Search**: Powerful search with semantic understanding
- **Organization**: Automatic tagging and categorization
