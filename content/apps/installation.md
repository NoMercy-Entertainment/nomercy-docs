# Installation Guide

This guide will walk you through the installation process for NoMercy applications.

## System Requirements

- Windows 10 or later
- 4GB RAM minimum
- 100MB disk space

## Installation Steps

1. Download the latest installer from our releases page
2. Run the installer
3. Follow the setup wizard
4. Launch the application

## Troubleshooting

If you encounter any issues during installation, please check our FAQ or contact support.
