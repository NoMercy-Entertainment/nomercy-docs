## What is MediaServer?

MediaServer is a core component of NoMercy that handles media file storage, organization, and streaming. It provides efficient management of your entertainment content library with powerful indexing and search capabilities.

## Key Features

### Media Organization

- **Automatic Cataloging**: Automatically detect and categorize media files
- **Smart Tagging**: Intelligent tagging system for content discovery
- **Folder Structure**: Flexible organization supporting complex folder hierarchies
- **Multi-Format Support**: Support for various video, audio, and image formats

### Streaming Capabilities

- **Direct Streaming**: Stream media directly to supported devices
- **Format Transcoding**: Automatic transcoding for optimal playback quality
- **Adaptive Bitrate**: Intelligent bitrate adjustment for different connection speeds
- **Subtitle Support**: Automatic subtitle detection and management

### Performance & Reliability

- **Efficient Indexing**: Fast indexing for quick content discovery
- **Caching System**: Intelligent caching for improved performance
- **Backup Support**: Built-in backup and recovery mechanisms
- **Monitoring**: Real-time monitoring of media library health

## Supported Media Formats

### Video Formats
- MP4, MKV, AVI, MOV, FLV, WebM, and more

### Audio Formats
- MP3, FLAC, AAC, OGG, WAV, and more

### Image Formats
- JPG, PNG, WebP, GIF, and more

## Components

MediaServer consists of several components:

1. **Indexer**: Scans and catalogs media files
2. **Database**: Stores metadata and configuration
3. **Streamer**: Handles media playback and delivery
4. **Monitor**: Tracks system health and performance

## Getting Started with MediaServer

To get started with MediaServer:

1. [Configure MediaServer](/mediaserver/configuration) - Set up paths and settings
2. Add media folders to your library
3. Let the indexer scan and organize your content
4. Start streaming and enjoying your media
