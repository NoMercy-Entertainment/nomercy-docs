# Albums

An album page lists its tracks in order, with the cover and what is known about the release.

Play the album, play one track, or add tracks to a playlist.

## Lyrics

Where lyrics are available for a track, they show with it. Timed lyrics follow along as it plays.

If the lyrics run ahead of or behind the music, they can be shifted for that track. The offset is saved, so it applies every time you play it.

## Editing an album

Someone who administers the server can correct the details or replace the cover from this page.

::Troubleshooting

**A track is on the album but will not play.** The album came from the metadata source; the file has to be there as well. A track your server has no file for shows on the list and cannot be played.

**No lyrics.** They were looked for and not found. That answer is remembered, so the providers are not asked again for the same track.

::
