# Where the app runs

Anywhere with a current browser. There is nothing to install to get going.

## Browsers

Current versions of Chrome, Edge, Firefox and Safari all work, on desktop and on a phone.

What differs between them is which formats the browser itself can play. Where a browser cannot take a file as it stands, the server converts it while it plays, so every browser gets a picture. See [Quality](/nomercy-app-web/quality).

## Installing it

The app can be installed from the browser, and it then behaves like any other app: its own window, its own icon, no address bar.

**Chrome and Edge** offer an install button in the address bar.

**Safari on iPhone and iPad** installs through Share, then Add to Home Screen.

Installing changes the frame around the app, not the app. It is the same page, signed in the same way.

## On a television

An Android TV app is the way to watch on a television. It talks to the same server and shares your progress, so a film paused on the sofa carries on in bed.

You can also cast from the app to a Chromecast. See [Casting](/nomercy-app-web/chromecast).
