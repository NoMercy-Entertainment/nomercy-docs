# Home

Home is rows of cards, built from what your server holds and what you have been watching.

## Continue watching

The first row is what you started and have not finished, most recent first. It updates as you watch, on whichever device you watched on.

To take something off it, remove it from the row. That hides the item without marking it watched and without touching the file.

## The rest of the rows

The other rows come from your own library: what was added recently, what sits under a genre, what belongs together. A server with one library shows fewer rows than a server with five, because there is less to group.

The server decides the rows, not the app. That is why the same account shows different rows on different servers, and why a server update can change the screen without an app update.

## Getting anywhere else

The sidebar has your libraries, music, search, and, if you administer the server, the dashboard.

::Troubleshooting

**Home is empty.** The server has nothing in it yet, or the scan has not finished. Watch it from [Libraries](/nomercy-app-web/dashboard/libraries) in the dashboard.

**Continue watching does not update.** Progress is saved as you watch, and a player closed immediately after starting saves nothing. If it stays empty across devices, check that the item plays to begin with.

::
