# Subtitles

Pick a subtitle track from the player's subtitle button, or cycle through them with `v`.

## Your choice is remembered

The player remembers the language you chose and applies it to the next thing you watch.

It remembers the language, never the position in the list. Track order comes from however the file was made, so "the second track" is English on one episode and Japanese on the next. Remembering the language means the next episode gives you the language you asked for.

The same holds for audio: see [Watching](/nomercy-app-web/watch).

## Styling

Size, colour and background are yours to set, and are remembered along with the choice of track.

Subtitles that carry their own styling, such as signs and songs in anime, are drawn as the file describes them. Those keep their own look rather than taking yours, because the styling is part of what is being said.

## Where subtitles come from

Two places. Subtitles inside the file are used as they are. Subtitles fetched for a title are stored beside it.

::Troubleshooting

**No subtitle button, or an empty list.** The file carries none and none have been fetched for it.

**Subtitles are out of step with the speech.** The timing belongs to the subtitle file, not to the player. A different track for the same language is usually the fastest fix.

**The wrong language keeps coming back.** The saved choice is per language. If a title has no track in that language, the player falls back to what the file offers.

::
