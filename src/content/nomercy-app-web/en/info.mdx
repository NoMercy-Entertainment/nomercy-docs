# Title details

The details page is where you decide to watch something: the artwork, what it is about, who is in it, and what your server actually has.

## Play, or not yet

A title your server holds plays from here. A title it knows about and has no file for says so instead of failing when you press play.

That difference matters on a series: a season can be half there, and the page shows which episodes are and which are not.

## Episodes

A series lists its seasons, and each season its episodes. An episode you have started shows how far in you are, so carrying on is one press.

## Liking and lists

The like button marks it as yours; it shows up under Favorites. Adding to a list puts it in a playlist you built. Both are per account, so nobody else's screen changes.

## People

Cast and crew link through to their own page, which shows what else of theirs your server holds.

::Troubleshooting

**The details are for the wrong title.** The match went astray. Fixing it is a dashboard job: see [Metadata](/nomercy-media-server/media/metadata).

**Play does nothing.** If the page says the title is unavailable, the server has no file for it. If it says nothing and play still fails, see [Common app issues](/nomercy-app-web/troubleshooting).

::
