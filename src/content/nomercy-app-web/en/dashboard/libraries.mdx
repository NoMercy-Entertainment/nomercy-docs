# Libraries

The Libraries screen in the dashboard is where you create libraries, point them at folders, and add content to them.

For what the library types mean and how to choose folders, see [Library Management](/nomercy-media-server/libraries). This page is about the screen itself.

## The library list

Every library, with how many folders each one has.

**New library** creates one. **Refresh all libraries** re-reads metadata for everything, which is rarely what you want; refreshing a single title from its own page is faster.

Select a library to open its settings.

## Library settings

**Library name** and **Media type**. The type decides how file names are read, so changing it on a library that already has content means that content is re-read against a different kind of match.

**Special season display name** sets what specials are called in this library. Series use "Specials" by convention.

**Subtitle download languages** picks which languages are fetched for new content.

**Auto-encode files found by scanning** controls what happens to files the server discovers in this library's folders. Off by default: found files are listed in their original form, and play like anything else. Switch it on when you want the whole shelf in the folder's format. It does not affect content you add yourself with **Add content**, which is always encoded.

**Encoding preset** becomes available when auto-encode is on. See [Encoding profiles](/nomercy-media-server/encoding/profiles).

Changes to metadata and artwork settings apply to content added afterwards. Existing titles keep what they have until you refresh them individually.

## Folders

A library needs at least one folder. Most only ever need one.

**Add new folder** opens the picker. It browses the **server's** disks, not the device you are sitting at, and it can create a folder for you with **New folder**.

Each folder has its own encoder profiles, which is what lets one library keep content on two drives with different settings.

**Change storage** moves a folder to a different storage driver, for network shares and object storage.

## Adding content

**Add content** takes files that already exist somewhere the server can read and brings them into the library, laid out and encoded the way that folder is set up.

Pick the source folder, pick the destination folder inside the library, tick the files, and add the selection. Your source files are only read, never moved or changed.

Everything added this way is encoded, whatever the auto-encode switch says.

**Rescan** re-reads the library's folders and picks up anything new.
