# Logs

What the server itself wrote. For a record of what people did, read [Activity](/nomercy-app-web/dashboard/activity) instead.

## Filtering

Three filters, and using them together is what makes a busy log readable.

**Type.** Which part of the server: the encoder, the queue, the scanner, and so on. The list comes from the server, so it matches what is actually being written.

**Level.** How severe. Dropping down to warnings and errors is the fastest way to find something wrong.

**Filter.** Free text matched in the message.

## Live

New lines arrive while the page is open, so a problem you are reproducing shows as you cause it.

## Clearing

The log can be cleared from here. It clears what is recorded, not the files the server writes on disk. See [Logs](/nomercy-media-server/troubleshooting/logs) for where those live.
