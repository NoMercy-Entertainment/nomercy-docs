# Activity

The activity log answers "what happened here". It is the people-shaped record; the [log](/nomercy-app-web/dashboard/logs) is the technical one.

## What is recorded

| Category | Covers |
|----------|--------|
| Auth | Signing in and out |
| Connection | Clients connecting and dropping |
| Playback | What was played, and where |
| Configuration | Settings that changed |
| Failure | Something that went wrong |
| Encoder | Encode jobs starting, finishing or giving up |
| Library | Scans, and files arriving or leaving |
| Security | Addresses the server banned or released by itself |

Rows can be filtered by category, so "who watched what" and "what the encoder did" are separate views of one list.

## Clearing it

Rows can be cleared by category, or everything older than a date. That keeps a long-running server's log useful rather than emptying it.

## Privacy

This shows what everyone on the server did, so reading it needs the manage permission. Somebody with plain access can see their own playback and nothing else.
