# Encoder profiles

A profile decides what the encoder does with a file. This screen lists them and lets you build your own.

## The list

Profiles are shown in a table you can sort and filter: by container, by tag, by whether they are built in, and by searching the name.

Built-in profiles come with the server. They cannot be edited, which is what makes them safe to fall back to.

## Making your own

Clone the built-in that is closest and edit the clone. Starting from nothing is possible and rarely what you want.

Clicking a row opens it beside the list, so you can read one without losing your place.

## Setting a default

One profile is the default. Anything encoded without a specific choice uses it.

## Checking before you commit

A profile can be validated, and previewed against a real file. The preview is the honest answer to "will this re-encode or copy this file", which is worth knowing before a library's worth of work is queued.

## Sharing

Profiles export and import. An import is checked against the publishers this server trusts; accepting an unsigned one is a deliberate choice.
