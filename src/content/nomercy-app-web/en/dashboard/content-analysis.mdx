# Content analysis

Four jobs that read a file and produce something the player can use. All of them are owner-only, because each puts the machine to work.

Each one takes a title, found by searching your library rather than by pasting an id.

## Crop detection

Probes a file for the black bars around the picture, so a film shot wider than the frame can be shown without them.

## Subtitle OCR

Some subtitles are pictures rather than text: the ones on DVDs and Blu-rays. OCR reads them into text, which can then be searched, styled and resized.

You choose which subtitle stream to read and the language it is in.

## Transcription

Turns the speech into a subtitle track, for a file with no subtitles at all. It can also translate to English while it goes.

Progress arrives while it runs, so a long file shows how far in it is rather than sitting silent.

## Intro detection

Runs across a season, because a repeated opening is only findable by comparing episodes. What it finds becomes the skip button in the player.

The screen shows how many episodes were scanned.

## Where the results go

All of it lands as content segments and subtitle tracks on the title itself. See [Content segments](/nomercy-api/rest/content-segments).
