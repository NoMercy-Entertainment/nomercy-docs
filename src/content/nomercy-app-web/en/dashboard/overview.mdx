# The dashboard

Administering a server happens inside the app, under Dashboard. It appears if you have the permission for it, on the server you are pointed at.

Opening the dashboard lands on the system overview, because a page listing what the sidebar already lists would be a stop on the way.

## The overview

Cards, each answering one question:

**The server.** Its name, version, address and how long it has been up.

**Hardware.** What the machine can encode with, from the benchmark.

**Tasks.** What the queue is doing. See [Logs](/nomercy-app-web/dashboard/logs) and the queue view for detail.

**Activity.** What has happened lately. See [Activity](/nomercy-app-web/dashboard/activity).

**Resources.** Processor, memory and disk as they move. This one is live, and appears once the dashboard's live connection is up.

## Getting around

The sidebar groups the screens: your content, the system, monitoring, and the advanced settings. Each is documented on its own page here.

## Who sees what

Some screens need only the manage permission. A few, such as plugins and content analysis, are owner-only, because they let code run or put the machine under load.

::Troubleshooting

**No dashboard in the sidebar.** Your account does not administer this server. The owner grants that in [Users](/nomercy-app-web/dashboard/users).

**The resource card is missing.** Its live connection is not up. Everything else on the page still works, because the rest is fetched rather than streamed.

::
