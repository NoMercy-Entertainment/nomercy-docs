# Live sessions

A live session is the server converting a file while somebody watches it. This screen lists the ones running, with a count at the top.

## What a session shows

The quality it is serving, with the resolution and bitrate behind that label, so "1080p" is backed by numbers rather than taken on trust.

That is the screen to open when the machine is working hard and you want to know what it is working on.

## Acting on one

A session can be ended, moved to a different quality, or moved to a position, by naming its id.

Ending a session frees the machine. The person watching it will find their player reconnecting, so it is a thing to do knowingly.

::Troubleshooting

**More sessions than people watching.** A session that was abandoned rather than closed expires on its own after an idle period.

**Everything is a live session.** Nothing plays as it is, which usually means the library is encoded in a form the clients cannot take directly. See [Encoding profiles](/nomercy-media-server/encoding/profiles).

::
