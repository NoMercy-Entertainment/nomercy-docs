# Quality

The quality button offers Auto and whatever rungs the title was encoded at.

## Auto

Auto follows the connection. It starts where it can and moves up or down as bandwidth allows, so playback keeps going rather than stalling at a quality the line cannot carry.

This is the right setting almost always.

## Choosing one yourself

Pick a rung and the player stays there. Useful on a metered connection, where you would rather cap the data than have Auto reach for the best.

The choice is remembered by height, not by its position in the list, so it survives a title whose ladder differs.

## When the server transcodes

Where a browser cannot take a file as it stands, the server converts it while it plays. It happens without asking, and playback starts either way, whatever the library is stored in.

A modest machine can struggle to convert a heavy source in real time. Where that shows, the answer is on the server side: encode those titles ahead of time. See [Encoding profiles](/nomercy-media-server/encoding/profiles).

::Troubleshooting

**Quality keeps dropping.** Auto is doing its job on a connection that cannot hold the higher rung. On a home network, check whether the traffic is going out to the internet and back rather than staying local.

**Only one quality is offered.** The title was encoded at one, or is being played as it is. Which rungs exist comes from the profile it was encoded with: see [Encoding profiles](/nomercy-media-server/encoding/profiles).

::
