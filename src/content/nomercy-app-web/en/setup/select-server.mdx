# Selecting a server

Your NoMercy account can reach more than one server: your own, and any that other people have shared with you. When there is a choice to make, NoMercy asks which one you want.

## When you see this

With exactly one server, NoMercy picks it and you never see this screen.

With more than one, you choose. You can switch later from your profile menu without signing out.

## What is in the list

Every server your account can reach. That means servers you own, and servers whose owner has given your account access.

Each one shows whether it is currently reachable. An unreachable server cannot be selected. See [Server offline](/nomercy-app-web/setup/server-offline).

## No servers listed

Three things cause this, in order of likelihood.

**You are signed in with a different account.** The account that owns the server is the one that sees it.

**Your server has not finished its own setup.** A server that has not been claimed does not exist as far as your account is concerned. Finish [First-Run Setup](/nomercy-media-server/first-run) on the server itself.

**Nobody has shared one with you.** If you do not run a server yourself, the owner has to add your account before it appears.

## Switching servers

Use your profile menu. Switching servers is a separate action from signing out.

## Where to go next

- [Server offline](/nomercy-app-web/setup/server-offline) if the one you picked cannot be reached.
- [First-run wizard](/nomercy-app-web/setup/first-run) if the server is new.
