# First-run wizard

The first time you open NoMercy against a newly claimed server, it takes you through a short wizard instead of the home screen. Three steps, and then you are done with setup for good.

This runs after the server itself is set up. If you have not done that, start at [First-Run Setup](/nomercy-media-server/first-run).

Only someone who can manage the server sees the wizard. Everyone else waits until it is finished.

## Step 1: Base info

Give the server a name.

This is the name you and anyone you share with will see when picking a server, so something recognisable is better than something clever. "Living room" beats "server1".

The step also links the privacy policy and terms of service. Nothing else is asked here.

You cannot continue until the name has something in it.

## Step 2: Media libraries

Create at least one library. This is the substantial step and it is worth doing carefully.

For each library:

1. Choose a type: Movies, TV Shows, Anime, or Music. This decides how file names are read, so it is the choice that matters most.
2. Add a folder. The picker browses the **server's** disks, not the device you are on. You can create the folder here with **New folder**.

The wizard does not ask about encoding. Each folder is given a preset automatically, and you can change it later from [Library Management](/nomercy-media-server/libraries).

Libraries can be dragged into the order you want them to appear in.

You cannot continue until at least one library exists.

See [Library Management](/nomercy-media-server/libraries) for what each type means and how to choose folders.

## Step 3: Finish

A summary of what was set up, and a button that takes you into NoMercy.

## The home screen is empty

That is correct. The wizard built your shelves and left them empty. Titles appear once you add a disc or some files.

Go to the dashboard and either rip a disc or add content. See [Discs](/nomercy-media-server/media/optical) or [Scanning and importing](/nomercy-media-server/media/scanning).

## Where to go next

- [Library Management](/nomercy-media-server/libraries) for choosing types and folders.
- [Discs](/nomercy-media-server/media/optical) to add your first title.
