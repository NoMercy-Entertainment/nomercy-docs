# Reference: Domain Types

The shapes every method in this collection reads or returns, independent of medium. `nomercy-video-player` and `nomercy-music-player` extend the item and event types with their own domain fields, everything below is what they extend.

## Playlist item

```ts
interface BasePlaylistItem {
	id: string | number;
	title?: string; // cross-library canonical display name
	image?: string; // cross-library canonical cover art / poster
	url?: string;   // cross-library canonical media source, resolved through auth on load()
}
```

Music adds `name: string` (required, aliases `title`) and `cover?: string` (aliases `image`); video adds `poster?` and `thumbnail?` (both alias `image`). Code targeting both libraries should populate `title` / `image` / `url`.

## Time & tracks

| Type | Shape |
|---|---|
| `TimeState` | `{ time, position, duration, buffered, remaining, percentage }` — seconds except `percentage` (0-100); `time` aliases `position`. Returned by `timeData()`. |
| `CanPlayResult` | `{ supported, smooth, powerEfficient }` — maps `MediaCapabilities.decodingInfo()`. |
| `QualityLevel` | `{ bitrate, height?, width?, label, index, supported?, dynamicRange? }` — `dynamicRange` is `'sdr' \| 'hdr'`. |
| `AudioTrack` | `{ id, language?, label, channels?, default? }` |
| `SubtitleTrack` | `{ id, language?, label, kind?, url, default?, type? }` — `kind` is `'subtitles' \| 'captions' \| 'descriptions'`. |
| `CurrentSubtitleSelection` / `CurrentAudioTrackSelection` / `CurrentQualitySelection` | `{ index, track }` — `null` when nothing is selected (or `'auto'` for quality). |
| `SubtitleStyle` | `{ fontSize, fontFamily, textColor, textOpacity, backgroundColor, backgroundOpacity, edgeStyle, areaColor, windowOpacity }` |
| `Chapter` | `{ index, start, end, title, synthetic? }` — `synthetic` is `true` only on gap-filler entries the malformed-chapter safety net generated, absent on chapters that came from the source. |

## Device & metrics

`DeviceCapabilities` is what `player.device()` returns. It carries mutually exclusive environment flags (`isTv` / `isMobile` / `isDesktop`), API availability (`pipSupported` / `fullscreenSupported` / `webLocksSupported`), `autoplayAllowed` (`boolean | 'unknown'`), and `preferred` (`'smooth' | 'powerEfficient'`, a decode-preference hint).

`PlaybackMetrics` is returned by `player.metrics()` and emitted periodically as `playback:metrics`.

`ttfb`, `avgBitrate`, `decoderStalls` and `droppedFrames` are `number | null`. A `null` means the active backend cannot report that counter at all, so guard before using one.

`ttff`, `rebufferRatio`, `joinTime` and `sessionDurationMs` are always `number`.

An index signature, `[customMetric: string]: number | null`, lets plugins publish their own namespaced counters onto the same object.

## i18n & plugin declaration types

```ts
type Translations = Record<string, Record<string, string>>; // lang tag -> key -> value
type TranslationLoader = (lang: string) => Promise<Record<string, string> | undefined>;

type PluginCtorWithId = (new (...args: never[]) => unknown) & {
	readonly id: string;
	readonly version?: string;
	readonly requires?: ReadonlyArray<RequireSpec>;
	readonly replaces?: string;
	readonly priority?: number;
	readonly advisories?: ReadonlyArray<PluginAdvisory>;
	readonly translations?: Translations;
	// + description, minCoreVersion, onError
};

type RequireSpec = PluginCtorWithId | { plugin: PluginCtorWithId; optional?: boolean; minVersion?: string };
```

`PluginAdvisory` (`static advisories` on a `Plugin` class) declares an invariant without handler code: `{ method, duringPhase?, duringEvent?, severity, reason, message }`. At registration every plugin's advisories merge into one lookup, and a matching mutation auto-fires the declared severity event. `duringPhase` gates on `player.phase()`. `duringEvent` gates on the currently-dispatching event name, including another plugin's own custom `before*` event.

## Tier-4 escape hatch

`PlayerExperimental` (`player.experimental`): `override(method, fn)` monkey-patches a method with auto-restore when the calling plugin disposes, `restore(method)` reverts manually, `overrides()` lists every active override for devtools. The `nmplayer/no-experimental` lint rule flags any call from inside plugin code, consumer app code is unrestricted.

## Config & player identity

```ts
type AuthHeaderValue = string | (() => string) | (() => Promise<string>);

type PlayerConstructorId = string | number;
```

`AuthHeaderValue` is what `AuthConfig.bearerToken` accepts: a static string, a sync getter, or an async getter, so Vue refs, signals, and reactive stores all plug in as `bearerToken: () => myStore.token`. See [Recipe: Auth Fetch](/nomercy-player-core/recipes/auth-fetch).

`PlayerConstructorId` is the argument `nmplayer(id)` takes: a string id or a numeric registry index. Any other type throws `core:player/invalid-id-type`. The registry is per library, so music and video can reuse the same id.

## Adapter ports

The injectable contracts behind `setup()` fields. Each has a working default; you implement one only to swap the underlying engine. The map of which port does what lives in [Tour: Adapters](/nomercy-player-core/tour/adapters).

### Single-function ports

```ts
interface IClock { now(): number }                    // setup({ clockSource })
interface IIdGenerator { next(): string }             // default: crypto.randomUUID()
interface IFetch { (url: string, opts?: RequestInit): Promise<Response> }
interface ILanguageMatcher { (tag: string): string[] } // 'pt-BR' -> ['pt-BR', 'pt']
```

`IClock` returns Unix epoch milliseconds; inject a server-synced clock for distributed sync. `IFetch` is the transport under `authFetch`, swapped in tests and native shells. `ILanguageMatcher` produces the BCP-47 fallback chain the translator walks. See [Adapter: Translator](/nomercy-player-core/plugins-adapters/adapter-translator).

### ILifecycleRegistry / LifecycleRegistry

```ts
interface ILifecycleRegistry {
	addCleanup(fn: () => void): void;
	listen(target: EventTarget, event: string, handler: EventListener, options?: AddEventListenerOptions | boolean): void;
	timeout(fn: () => void, ms: number): number;
	interval(fn: () => void, ms: number): number;
	observe<O extends { disconnect(): void }>(observer: O): O;
	abortable(): AbortController;
	frame(fn: (deltaMs: number, time: number) => void): void;
	dispose(): void;
	isDisposed(): boolean;
}
```

Every plugin receives one as `this.lifecycle`. Anything registered through it (listeners, timers, observers, abort controllers, RAF loops) is torn down by one `dispose()` call. `LifecycleRegistry` is the default class implementation; `dispose()` is idempotent, and calls made after disposal are safe no-ops. See [Handbook: Anatomy](/nomercy-player-core/handbook/anatomy).

### ICueParserRegistry

```ts
interface ICueParserRegistry {
```

Ordered registry of cue parsers. Resolution is most-recently-registered first, so your parser can override a built-in for the same URL pattern. See [Adapter: Cue Parser](/nomercy-player-core/plugins-adapters/adapter-cue-parser).

### ISubtitleRenderer


Pluggable subtitle renderer. `markup` is the raw string from `VTTSubtitlePayload.markup` and carries only inline `<i>` / `<b>` / `<u>` tags. Custom renderers (canvas, WebGL) are injected through a plugin, not a `setup()` field.

### Platform probe types

```ts
interface DecodeProfile {
	contentType: string;
	width?: number;    // video probes only;
	height?: number;   // omit all four for an
	bitrate?: number;  // audio-only probe
```

## Stream source types

The typed event surface of `IStreamSource`, see [Adapter: Stream Source](/nomercy-player-core/plugins-adapters/adapter-stream-source).

```ts
type StreamEvent
	= 'manifest-loaded' | 'level-switched' | 'level-considered'
	| 'fragment-loaded' | 'encrypted' | 'error';

interface StreamEventPayloadMap {
	'manifest-loaded': undefined;
	'level-switched': LevelSwitchedData;          // hls.js type
	'level-considered': StreamLevelConsideredPayload;
	'fragment-loaded': FragLoadedData;            // hls.js type
	'encrypted': StreamEncryptedPayload;
	'error': StreamErrorPayload;
}

interface StreamLevel {
	bitrate: number;
	height?: number;
	width?: number;
	label: string;
	index?: number;
}

interface StreamLevelConsideredPayload {
	level: number;   // candidate index
	reason: string;  // why the switch was not made
}

interface StreamEncryptedPayload {
	keyUri: string;
	keyFormat?: string; // e.g. 'com.apple.streamingkeydelivery'
}

type StreamErrorPayload = MediaError | ErrorData; // native path, or hls.js
```

`StreamEventPayloadMap` narrows the callback type automatically at `source.on(event, fn)` call sites, no casts needed. `StreamLevel` is one rendition from the manifest; fixed-bitrate sources report an empty level list.

### HlsStreamSource

```ts
class HlsStreamSource implements IStreamSource {
	readonly kind = 'hls';
	constructor(url: string, registry?: StreamRegistry);
}
```

The built-in HLS `IStreamSource`. On Safari and iOS WebKit it sets the URL natively on the element; everywhere else hls.js handles ABR and segment loading. Registry interceptors run on the hls.js path only, the native path fetches directly.

## Media element backend

```ts
type AuthHeaderProvider = (url: string) => string | undefined;

abstract class MediaElementBackend<TEl extends HTMLMediaElement, TPayload> {
	setAuthHeaderProvider(provider: AuthHeaderProvider): void;
	// shared play/pause/stop, time/duration/rate, volume, mute,
	// DOM-bridge and loader plumbing for element-backed backends
}
```

`AuthHeaderProvider` answers "what Authorization header goes on this request" per URL, synchronously, because hls.js resolves headers per segment in a sync callback. Read from a store or ref; never fetch inside it. `MediaElementBackend` is the abstract substrate every `HTMLMediaElement` backend extends; subclasses implement `load` / `unload` / `dispose` / `state` and their domain surface. See [Build: Backend Contract](/nomercy-player-core/build/backend-contract).

## HDR policy

```ts
interface DisplayRangeProbe {
	matches: (query: string) => boolean; // answers a CSS media query
}

type HdrOnSdrFallback = 'play' | 'refuse';

type HdrDecision
	= | { kind: 'as-is' }
	| { kind: 'tone-map' }
	| { kind: 'cap-to'; level: QualityLevel }
	| { kind: 'play-unconverted' }
	| { kind: 'refuse' };
```

`hdrDecision()` returns the cheapest correct answer when HDR content meets a screen. It plays as-is on an HDR display, caps ABR to the best SDR rung when one exists, or asks the backend to tone-map when it can. Otherwise it applies the consumer's `HdrOnSdrFallback` choice.

`DisplayRangeProbe` is the injectable media-query probe behind `detectDisplayHdr()`. `browserDisplayRangeProbe()` returns `null` when there is no browser to ask, and the default answer is SDR.

```ts
interface VTTSubtitlePayload {
	text: string;      // all inline tags stripped
	markup?: string;   // <i> <b> <u> preserved; feed to buildSubtitleFragment()
```

`VTTSpritePayload` is the parsed `#xywh=x,y,w,h` crop from a VTT sprite cue, the shape thumbnail previews consume. `LrcPayload.words` is present only for enhanced LRC lines with word-level timestamps.
