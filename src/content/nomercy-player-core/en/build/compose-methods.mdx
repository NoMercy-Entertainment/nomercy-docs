# Build a Player: Compose the Methods

This is a four-step tutorial that assembles a player from the kit one capability at a time: compose the shared methods, wire a backend contract, add a plugin, add i18n. Each step is a complete, typechecked file that extends the one before it. By the end you'll have one class exhibiting all four.

## The shell

Every step in this tutorial starts from the same three ingredients, the ones [Quickstart](/nomercy-player-core/quickstart) introduces:

1. Extend `EventEmitter`, so `.on()` and `.emit()` work.
2. Resolve the three-form constructor with `resolvePlayerConstructor` and `initPlayerCoreState`.
3. Stamp `playerCoreMethods` onto the prototype with `composeMixins`.

Read Quickstart first if you have not. It explains why each piece exists. This page takes that as read and uses the result as a foundation.

## Why this is the right starting point

`playerCoreMethods` is the full aggregate both real players compose onto their prototypes. It is not a cut-down demo subset.

So `MinimalPlayer` above already has setup, the phase machine, the queue, volume, i18n, plugin registration and auth. Everything except a media backend.

The next three steps add no kit machinery. They add what a consumer supplies: a backend, a plugin, and translations.

## What's next
