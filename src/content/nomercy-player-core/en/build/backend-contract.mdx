# Backend Contract

Use this when you write your own media backend, or when you need the shared element surface Player Core exports.
Player Core does not decode picture or sound.
Transport, time, and volume call whatever `fn backend` returns on your instance.

## How the player finds it

Add `fn backend` on your class.
The shared methods reach it with optional chaining.
A missing method is a safe no-op.
There is no setup field that installs a backend for you.

## The shared substrate

`cls MediaElementBackend` is the shared base for an `HTMLMediaElement` backend.
Core exports it and does not construct one for you.
Call `super` with the element, whether you own it, and a backend id.

It already forwards play, pause, stop, time, rate, mute, and volume.
A volume write clamps to 0 through 1, then applies a square-law gain to the element.
It also holds an auth header provider, DOM bridges, loader pause and resume, and element capability helpers.

| Area | What the base covers |
| --- | --- |
| Transport | `fn play`, `fn pause`, `fn stop` |
| Time | `fn currentTime`, `fn duration`, ranges, rate |
| Level | `fn volume`, `fn mute`, `fn unmute` |
| Element | `fn mediaElement`, stream, sink, keys |

## What you still supply

The base does not implement `fn load`, `fn unload`, `fn dispose`, `fn state`, `fn buffered`, or `fn outputProtectionState`.
Add them when your medium needs them.
A call the base does not have is a no-op from the player.
Wire DOM events with `fn attachDomBridges`, or a custom set that still fills the handler list for teardown.
Override `fn play`, `fn volume`, or `fn mute` only when your medium needs extra work first.

## Backend state

`BACKEND_STATE` names `str idle`, `str loading`, `str ready`, `str playing`, `str paused`, and `str error`.
DOM bridges map loadstart, loadedmetadata, play, pause, ended, and error onto those values.
A pause bridge leaves `str idle` and `str error` alone.

`fn bridgeBackendPlayState` copies play, playing, and pause onto your player's play flag.
By default, `str loadstart` resets that flag.
Pass `key resetEvents` or `key pauseGuard` when your medium needs different gating.

## Auth for each request

`cls AuthHeaderProvider` takes the request URL and returns an Authorization header value, or nothing.
It must stay synchronous.
Read from a store or ref.
Do not fetch inside it.

## Helpers you can reuse

Use `fn isHls` and `fn supportsNativeHls` to choose a pipeline.
`fn attachHlsOrFallback` attaches hls.js, or sets `src` when that engine is unsupported.
Pass your own hls config.
The helper does not merge defaults.
`fn resolveOrCreateMediaElement` finds or creates the tag.
`fn resetMediaElement` clears a previous source before a new one.
