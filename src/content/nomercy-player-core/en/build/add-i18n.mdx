# Add i18n

Use this when you need status text after compose, or when a plugin ships its own labels.
English `core.*` strings are already on the player after `fn setup`.
Day-to-day lookups stay on the [i18n tour](/nomercy-player-core/tour/i18n).

## English that ships

`key enTranslations` is the flat English map.
`key defaultTranslations` wraps it as `{ en: enTranslations }`.
Import either from `@nomercy-entertainment/nomercy-player-core`.

The map covers network, auth, browser policy, media, DRM, queue state, accessibility, and chapter titles.
Keys use the shape `core.<feature>.<message>`.
The same map also holds a few `plugin.<id>.*` strings for built-in plugin messages.

Pass `key language` and `key translations` on `fn setup` when you add or override strings up front.
Your English keys win over matching defaults.
Spread `key defaultTranslations` when you want that map as the base for other tags.

## Plugin strings

Put a static `key translations` on your `cls Plugin` subclass.
Keys inside must already use the `plugin.<id>.` prefix.
Registration merges that map into the live table.
`fn t` on the plugin prepends `plugin.<id>.` for you, so pass the short key only.

| Piece | Role |
| --- | --- |
| `key enTranslations` | Flat English key-to-string map |
| `key defaultTranslations` | `{ en: ... }` shape for setup |
| `key translations` on `cls Plugin` | Bundles merged at registration |
| `fn t` on the plugin | Short-key lookup under your id |
