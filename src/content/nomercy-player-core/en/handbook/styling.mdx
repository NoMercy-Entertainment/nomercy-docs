# Styling

This package ships no stylesheet.
Your CSS enters the page through plugin helpers, and the player stamps state classes on its container.

## Put CSS in the document

From a `cls Plugin` subclass, call `fn appendStyles` or `fn appendInlineStyles` in `fn use`.
Both write into `var document.head`.
Both take a `var styleId` you choose.

`fn appendStyles` adds a stylesheet link for a URL.
When the class sets `key moduleUrl`, a relative URL resolves against it.
Otherwise it resolves against `var document.baseURI`.

`fn appendInlineStyles` writes a style element whose text is the CSS you pass.
The rules are in the document as soon as the call returns.
You do not wait on a stylesheet request.

```ts
this.appendInlineStyles(
  '.nmplayer-badge-root { position: absolute; inset-block-start: 1rem; }',
  'plugin-badge-inline',
);
```

If `var document` is missing, both calls return without writing.

## One id wins

Before writing, each helper looks up `var styleId` in the document.
When that id already exists, the call does nothing.
The first call wins, even if a later call passes different CSS or a different URL.

Choose a stable, plugin-specific id such as `plugin-<id>-styles`.
Reuse another plugin's id and the dedupe check silences your own sheet.

Neither helper removes its node when the plugin disposes.
A later registration finds the id already present and skips the write.

## Classes on the container

After `fn setup`, the container carries `str nomercyplayer`.
Emitted player events keep further classes in sync, so your CSS can follow state without script.

| Class | Meaning |
| --- | --- |
| `str playing` `str paused` `str stopped` `str ended` `str loading` `str buffering` | Play and load presentation |
| `str active` `str inactive` | User activity; exactly one is present once `str activity` has fired, which setup does unless `key inactivityMs` is `0` |
| `str muted` | Mute is on |
| `str fullscreen` `str pip` `str theater` | Display mode is on |

`str buffering` arrives from `str waiting` or `str stalled`.
`str canplay` or an advancing `str time` clears it.
The first time the phase becomes `str loading`, the container can gain that class.
After the first `str ready`, a later `str loading` phase leaves the classes alone.

```css
.nomercyplayer.inactive .nmplayer-badge-root {
  opacity: 0;
}
```

## Names on your elements

`fn addClasses` and `fn removeClasses` add or drop class names on a node you already hold.
`fn mount` claims a div under the container and sets its class to `nmplayer-<id>-<name>`.
Point your rules at that class so mount points stay unique across plugins.

## Subtitle style values

`fn subtitleStyle` with no argument returns the current `cls SubtitleStyle` object.
Pass a partial object to merge fields and emit `str subtitleStyle` with the result.
The event carries that merged object.

```ts
player.subtitleStyle();
player.subtitleStyle({ fontSize: 120 });
```
