# Building DOM

Build UI nodes with five helpers from Player Core.
They create elements, set attributes, and toggle classes.
You choose where each node lives in the tree.

Import them from the `str adapters/element-factory` path.

## createElement

`fn createElement` takes a tag name, an `key id`, and an optional `key unique` flag.
It returns a fluent builder.
Chain `fn addClasses`, `fn setAttribute`, `fn setProperty`, `fn appendTo`, or `fn prependTo`, then call `fn get` for the node.

`fn setProperty` writes a CSS custom property on the inline style.
`fn appendTo` appends the node and returns a shorter chain with `fn get` and `fn addClasses`.
`fn prependTo` inserts before the parent's first child the same way.

Pass `unique: true` to reuse an existing node with that id instead of creating another.
The lookup uses `fn document.querySelector` with a CSS-escaped id.
When the found node already has an id, that id is left alone.

```ts
const label = createElement('span', 'badge-label')
	.addClasses(['badge-label'])
	.setAttribute('data-state', 'live')
	.appendTo(root)
	.get();
```

## Buttons and SVG

`fn createButton` returns a ready `<button>`.
It sets `attr type` to `str button`, copies `key label` onto `attr aria-label` and `attr title`, and attaches the click handler.

`fn createSVG` returns an `<svg>` in the SVG namespace with `attr id`, `attr viewBox`, and `attr xmlns` set.
Append path or use children yourself.
There is no fluent builder on that return value.

## Classes

`fn addClasses` adds names to an element and skips empty strings.
It returns a fluent builder so you can keep chaining.

`fn removeClasses` removes names the same way and returns the element.
Removal is terminal: there is no builder after it.

These are the five helpers:

| Helper | Returns |
| --- | --- |
| `fn createElement` | Fluent builder, then `fn get` for the node |
| `fn createButton` | An accessible `HTMLButtonElement` |
| `fn createSVG` | An `SVGSVGElement` |
| `fn addClasses` | Fluent builder on the same element |
| `fn removeClasses` | The element itself |
