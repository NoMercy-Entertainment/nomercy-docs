# i18n

A plugin is extra behavior you add, such as counting each play.
This page names the i18n exports on the package root, and how a plugin ships its strings.
Day-to-day `fn language`, `fn t`, and `fn addTranslations` stay on the [i18n tour](/nomercy-player-core/tour/i18n).

## Names on the package root

Import these from `@nomercy-entertainment/nomercy-player-core` when you wire strings.

| Name | Role |
| --- | --- |
| `cls DefaultTranslator` | Built-in engine behind the live translation table |
| `fn translationsFromGlob` | Build a `cls Translations` map from per-tag modules |
| `fn createNetworkTranslationLoader` | Build a loader that fetches one JSON URL per tag |
| `key enTranslations`, `key defaultTranslations`, `key nlTranslations` | English map, `{ en: ... }` wrapper, and Dutch map |

`fn bcp47FallbackChain` returns parent tags for a BCP-47 value, most specific first.
`cls ITranslator`, `cls Translations`, and `cls TranslationLoader` type those shapes.
`key i18nMethods` is the mixin chunk you compose onto a player class.

## Static bundles on the class

`key translations` on a `cls Plugin` subclass merges at registration.
Keys inside the bundle must already use the `plugin.<id>.` prefix.
Registration walks ancestor classes, so a subclass only ships its own keys.
Dispose removes `plugin.<id>.` only when that static field is present.

`fn translationsFromGlob` builds a lazy `cls Translations` object from one module per tag.
Only the active tag and its parents are fetched, at registration and again on each language switch.

## Look up from the instance

`fn t` on the plugin prepends `plugin.<id>.` for you.
Pass a vars map when the stored string has `{name}` placeholders.
A miss falls through to `key onMissingTranslation` when set, then to the namespaced key.

## Load after use

Override `fn loadTranslations` when strings live outside the source tree.
Return bare keys; the player namespaces them under `plugin.<id>.`.
Return `undefined` when that tag has no bundle.
For player-wide CDN JSON, pass `fn createNetworkTranslationLoader` as setup `key loadTranslations`.
