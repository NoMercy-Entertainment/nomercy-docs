# Quick Start

Compose your own player class when you are building a player, not when you only want to play a file.
The video and music players already do this for you.

## Install

```bash
npm install @nomercy-entertainment/nomercy-player-core
```

That is the only install on this page.
Do not add a second package for streaming.
Core already brings it.

## Compose the class

You wire the class in four steps.

1. Extend `cls EventEmitter` so `fn on` and `fn emit` work.
2. Resolve the constructor with `fn resolvePlayerConstructor`.
3. Seed the player with `fn initPlayerCoreState`, using the same class name.
4. Stamp `playerCoreMethods` onto the prototype with `fn composeMixins`.

:::snippet{file="core-quickstart" live="false"}
:::

`fn composeMixins` copies each bundle onto the prototype, including getters and setters.
When two bundles use the same name, the later one wins.
`playerCoreMethods` is the same set the video and music players compose, so your class gets the queue, transport, time, volume, plugins, and auth.

## Mount and set up

Pass a string id, a number, or nothing.

A new string looks up `document.getElementById` and requires a `div`.
A missing element throws `str core:player/element-missing`.
A node that is not a `div` throws `str core:player/element-not-div`.

The sample creates a labeled `div` and passes its id.
This class has no picture or sound of its own, so play has nothing to drive.
`fn setup`, `fn ready`, and `fn dispose` still run.
