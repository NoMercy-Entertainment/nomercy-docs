# Quick Start

Compose a player class from `@nomercy-entertainment/nomercy-player-core`.

## Install

```bash
npm install @nomercy-entertainment/nomercy-player-core
```

That is the only package this page installs.

## Compose the class

Three exports from the package root do the work:

1. Extend `EventEmitter` so `.on()` and `.emit()` work.
2. Resolve the constructor with `resolvePlayerConstructor`, then seed state with `initPlayerCoreState`.
3. Stamp `playerCoreMethods` onto the prototype with `composeMixins`.

:::snippet{file="core-quickstart" live="false"}
:::

`composeMixins` copies each module's own property descriptors onto the prototype, including getters and setters.

Later modules override earlier ones when two modules export the same key.

`playerCoreMethods` is the aggregate both `NMVideoPlayer` and `NMMusicPlayer` spread into that call.

## Mount and set up

`resolvePlayerConstructor` takes a string id, a numeric index into the registry, or `undefined`.

A string that is not yet registered looks up `document.getElementById(id)` and requires a `<div>`.

Missing elements throw `core:player/element-missing`.
A non-div throws `core:player/element-not-div`.

The sample creates a labeled `<div>` and passes its id to `corePlayer`.

This class has no media backend, so transport methods have nothing to drive.
`setup()`, `ready()`, and `dispose()` run without one.
