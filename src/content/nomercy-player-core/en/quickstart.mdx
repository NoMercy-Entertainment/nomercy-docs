# Player Core: Quick Start

For library authors and plugin developers working directly against `nomercy-player-core`, the base library beneath the video and music players. If you are building a video or music player, use the [Video Quick Start](/nomercy-video-player/quickstart) or [Music Quick Start](/nomercy-music-player/quickstart) instead — both packages include everything here.

## Install

```
npm install @nomercy-entertainment/nomercy-player-core@rc
```

`hls.js` ships with the core as the default HLS stream factory. See [Installation](/nomercy-player-core/installation) for details.

## Minimal working player

The core is the player engine. Compose its method mixins onto a class and you have a working player: the queue, transport, time, volume, the typed event bus, and the plugin system are all there.

```ts
import {
  composeMixins,
  initPlayerCoreState,
  lifecycleMethods,
  playerCoreMethods,
  queueMethods,
  timeMethods,
  transportMethods,
  volumeMethods,
} from '@nomercy-entertainment/nomercy-player-core';

class MyPlayer {
  constructor(id: string) {
    initPlayerCoreState(this, { className: 'MyPlayer' });
    this.setup({ playlist: [{ id, url: '/path/to/media.m3u8' }] });
  }
}

composeMixins(
  MyPlayer.prototype,
  playerCoreMethods,
  lifecycleMethods,
  queueMethods,
  transportMethods,
  timeMethods,
  volumeMethods,
);

const player = new MyPlayer('intro');

player.on('ready', () => player.play());
```

That class drives the full core surface. The only thing it does not do on its own is render a medium — which is what `nomercy-video-player` and `nomercy-music-player` add on top.

## Core controls

```ts
player.play();
player.pause();
player.stop();
player.next();
player.previous();

player.time(30);   // seek to 30 seconds
player.volume(80); // 0-100
player.mute();

player.queue();    // read the queue
```

See [Playback Control](/nomercy-player-core/transport) for the full transport, time, and volume surface.

## Listening to events

```ts
player.on('ready', () => { /* setup complete */ });
player.on('current', ({ item, index }) => { /* active item changed */ });
player.on('time', ({ time }) => { /* position update */ });
player.on('play', () => { /* started */ });
player.on('pause', () => { /* paused */ });
```

See [Event System](/nomercy-player-core/event-system) for typed events and cross-plugin listening.
