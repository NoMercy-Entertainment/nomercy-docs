# Core: Quick Start

This is the shortest path to composing a player from the kit. No media backend, no UI. You use the same three ingredients `nomercy-video-player` and `nomercy-music-player` are built from. Everything below is real, published code, not pseudocode.

## Install

```bash
npm install @nomercy-entertainment/nomercy-player-core
```

You will not normally install this package directly. `nomercy-video-player` and `nomercy-music-player` already depend on it and re-export everything you need day to day. Install it yourself only when you're composing your own player, as below.

## Compose a minimal player

Three ingredients, in order:

1. Extend `EventEmitter` so `.on()` / `.emit()` work.
2. Resolve the three-form constructor with `resolvePlayerConstructor` plus `initPlayerCoreState`. An id, an index, or `undefined` then all do the right thing.
3. Stamp every shared mixin onto the prototype in one `composeMixins` call.

`playerCoreMethods` is not a cut-down subset picked for this example. It is the same aggregate `NMVideoPlayer` and `NMMusicPlayer` compose onto their own prototypes. `MinimalPlayer` is missing exactly one thing they have: a media backend.

Everything else is the identical code running underneath both real players:

- `setup()`, `ready()`, `dispose()`
- The phase machine
- The queue
- Volume
- i18n
- Plugin registration
- Auth

## Mounting it

The constructor's three-form resolution is what `nmplayer(id)` does in the real libraries. When an instance is already registered under the string id you pass, the constructor returns that instance. Otherwise it resolves `document.getElementById(id)` and requires the element to be a `<div>`.

```html
<div id="player-container"></div>
```

```ts
const player = minimalPlayer('player-container');

player.setup({ logLevel: 'info' });
await player.ready();

console.log(player.phase()); // 'ready'
player.dispose();
```

`setup()` runs the same fixed pipeline described in [What is nomercy-player-core](/nomercy-player-core#the-setup-then-freedom-model). With no media backend attached, `MinimalPlayer` reaches `ready` without ever loading or playing anything. That's exactly the point: everything up to and including `ready()` is kit behavior, proven independently of any specific medium.
