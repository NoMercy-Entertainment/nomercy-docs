# Installation

You rarely install the core directly — it arrives as a dependency of [`nomercy-video-player`](/nomercy-video-player/installation) and [`nomercy-music-player`](/nomercy-music-player/installation). Install it on its own only when you are writing a plugin or building a new player package on top of the core.

## Requirements

- Node.js 18 or later (tooling only; the engine itself runs in any modern browser)
- A module bundler (Vite, Webpack, Rollup, or similar)

## Install the package

```bash
npm install @nomercy-entertainment/nomercy-player-core@rc
```

The package-manager toggle, pinned to the top right, switches this command to yarn, pnpm, or bun.

`hls.js` ships with the core as the default HLS stream factory (`@nomercy-entertainment/nomercy-player-core/streams/hls`), loaded lazily for HLS sources.

## CDN (no bundler)

The core has no standalone CDN / IIFE build — it is a bundler-only library. Consume it through a bundler, or use it via the [video](/nomercy-video-player/installation) or [music](/nomercy-music-player/installation) players, which ship their own CDN builds.

## Import paths

```ts
// Compose a player from the core mixins
import {
  composeMixins,
  initPlayerCoreState,
  playerCoreMethods,
  lifecycleMethods,
  queueMethods,
  transportMethods,
  timeMethods,
  volumeMethods,
} from '@nomercy-entertainment/nomercy-player-core';
import type { IPlayer, BaseEventMap } from '@nomercy-entertainment/nomercy-player-core';
```

Adapters, built-in plugins, and stream factories are also available as tree-shakable subpaths, one per module — for example `@nomercy-entertainment/nomercy-player-core/adapters/storage`, `/plugins/equalizer`, and `/streams/hls`.

## TypeScript

The package ships full TypeScript declarations. No `@types/` package is needed.

The recommended type for a consumer-held player reference is `IPlayer<BaseEventMap>`:

```ts
import type { IPlayer, BaseEventMap } from '@nomercy-entertainment/nomercy-player-core';

let player: IPlayer<BaseEventMap>;
```
