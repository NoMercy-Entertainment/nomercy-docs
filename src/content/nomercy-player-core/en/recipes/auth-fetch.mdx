# Recipe: Use authFetch

Call the auth-aware HTTP pipeline from outside a plugin with `fn authFetch`, or from inside a plugin with `fn this.fetch`.

`fn authFetch` is exported from `@nomercy-entertainment/nomercy-player-core`.
You pass `key url`, optional `cls AuthConfig`, and a required `key signal`.
Inside a plugin, `fn this.fetch` wraps the same pipeline and supplies auth, signal, and plugin scope for you.

Media headers are a separate choice on `cls AuthConfig`.
Set `key mediaAuthorization` when a media backend should send an `Authorization` value for a given URL.
Leave it unset and media requests send no token.

## What `fn authFetch` applies

`fn authFetch` builds one `Request` per attempt, then runs a bounded retry loop.
Fields on `cls AuthConfig` are optional.
When `key auth` is omitted, or `key bearerToken` is unset, no `Authorization` header is added.

When those fields are present, the order is fixed.

1. `key transformUrl` rewrites the URL when supplied.
2. `Authorization: Bearer <token>` is set only when `key bearerToken` resolves to a non-empty string.
3. `key headers` merge in; per-call `key headers` win on collision.
4. `key signRequest` runs last when supplied.

`key signal` is required on every `fn authFetch` call.
You own the `AbortController`.

Each failure class has its own path.

| Failure | What happens |
| --- | --- |
| 401 | Calls `key refreshOnUnauthenticated` once when that hook is set and `key retryAfterRefresh` is not `0`, then retries without consuming a retry slot. |
| 403 | Throws `str core:auth/forbidden`. No refresh, no retry. |
| Other 4xx | Throws the matching `str core:network/*` code. No retry. |
| 5xx, network, timeout | Retries per the call's `cls RetryConfig`. The default is `{ attempts: 0 }`. |

Configure live player auth with `fn auth` on the composed player from [Compose the Methods](/nomercy-player-core/build/compose-methods).
`fn auth()` returns a redacted snapshot with `key bearerToken` stripped.
`fn this.fetch` reads the raw config at call time.

## Response typing

`key responseType` chooses how the body is decoded.

| `key responseType` | Resolves to |
| --- | --- |
| `str text` (default) | The response string. Optional `key parser` turns that string into `T`. |
| `str json` | `response.json()` cast to `T`. |
| `str arrayBuffer` | `response.arrayBuffer()`. |

A thrown `key parser` or invalid JSON surfaces as `str core:network/parse-failed`.
Narrow caught errors with `fn isAuthError` and `fn isNetworkError`.
