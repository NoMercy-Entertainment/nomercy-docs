# Plugin: Media Session

`MediaSessionPlugin` (id `'media-session'`) bridges player transport state to the browser's `navigator.mediaSession` API. That API powers lock-screen media controls, hardware media keys, Bluetooth remotes, and OS "Now Playing" widgets. The main entry does not re-export the plugin. Import it from the `plugins/media-session` subpath.

## Options

Currently empty (`MediaSessionOptions = {}`), reserved for future options.

## Rules & restrictions

- When `navigator.mediaSession` is absent (Node, JSDOM, some older WebViews), the plugin silently no-ops. Every method is guarded at the top. Nothing throws.
- When duration is zero, `NaN`, or `Infinity`, the plugin skips position reporting. Some browsers throw on an invalid `setPositionState` call.
- Not every browser supports `setActionHandler('stop')`. The plugin catches the resulting `TypeError` rather than propagating it.
- When embedded, Safari requires the `autoplay` attribute on the host `<iframe>` for MediaSession to activate at all. See the note on the [Embed](/nomercy-player-core/plugins-adapters/embed) plugin.

## How to extend it

To target a native shell (Capacitor, Electron) instead of the browser API, subclass with the same `static id` and override the platform touchpoints:

```ts
import nmplayer from '@nomercy-entertainment/nomercy-video-player'; // nomercy-music-player's factory works identically
import { MediaSessionPlugin } from '@nomercy-entertainment/nomercy-player-core/plugins/media-session';

const player = nmplayer('player');

player.addPlugin(MediaSessionPlugin);
await player.ready();

const session = player.getPlugin(MediaSessionPlugin);
session!.metadata({ title: 'Sintel', artist: 'Blender Foundation' });
```
