# Quality policies

Use the quality policies when your own backend must pick the highest rung a viewer can actually see.
They cap that pick to the screen's HDR (High Dynamic Range) or SDR (Standard Dynamic Range) support.
They decide two limits on a ladder of `cls QualityLevel` rungs: one from the screen's dynamic range, and one from the player's size.

A `cls QualityLevel` holds `key bitrate`, an optional `key width` and `key height`, a `key label`, its manifest `key index`, an optional `key supported` flag, and an optional `key dynamicRange` of `str sdr` or `str hdr`.
A ladder is an array of `cls QualityLevel` rungs.

They are plain functions, not an interface, so there is nothing to register.
Import them from the package root.

## Built-in adapter

The video player's HTML5 backend calls these functions to cap adaptive streaming.
It passes `key hdrOnSdr` from `fn setup`, which is `str play` by default.
`fn device` on any player reports `key hdrDisplay` from `fn detectDisplayHdr`.

## Functions

The table lists every function.

| Function | Returns |
|---|---|
| `fn detectDisplayHdr` | `true` when the screen reports HDR for video or for the page. `false` when nothing can be asked. |
| `fn browserDisplayRangeProbe` | A probe that wraps `window.matchMedia`, or `null` without one. |
| `fn hdrAbrCeiling` | The best SDR rung, or `null` on an HDR screen or a ladder with no HDR. |
| `fn isHdrUnplayable` | `true` when every rung is HDR and the screen is not. |
| `fn hdrDecision` | One `cls HdrDecision`, cheapest correct answer first. |
| `fn sizeAbrCeiling` | The smallest rung that covers the pane, or `null`. |
| `fn panePixels` | An element's size in device pixels. |
| `fn abrCeiling` | The lower of the HDR cap and the size cap. |

`fn hdrDecision` returns one of five kinds.

| Kind | When |
|---|---|
| `str as-is` | The screen is HDR, or there is nothing to change. |
| `str cap-to` | An SDR rung exists. It carries that rung as `key level`. |
| `str tone-map` | Every rung is HDR and the backend can convert. |
| `str play-unconverted` | No SDR rung, no converter, and the fallback is `str play`. |
| `str refuse` | No SDR rung, no converter, and the fallback is `str refuse`. |

`fn sizeAbrCeiling` returns `null` for a pane of zero size, an empty ladder, or when the covering rung is already the tallest.
A rung without a `key width` is not ruled out by width.
