# IEventBus

`cls IEventBus` is the listening surface every player and plugin exposes.
You came from [Use authFetch](/nomercy-player-core/recipes/auth-fetch).
This page is the contract those `fn on` and `fn emit` calls satisfy.

Use it to type a wrapper, a test fake, or a helper that accepts anything you can listen to.
It is not a setup field.
There is no `key eventBus` option.

```ts
import { EventEmitter } from '@nomercy-entertainment/nomercy-player-core';
import type { IEventBus } from '@nomercy-entertainment/nomercy-player-core/adapters/event-bus';
```

`cls EventEmitter` is also available from the `./adapters/event-bus` subpath.
`cls IEventBus` lives only on that subpath.

## Built-in adapter

`cls EventEmitter` is the shipped implementation.
Player Core exports the class from the package root.
Inside `nomercy-player-core`, `cls MediaList`, `cls MediaElementBackend`, and `cls StubPlayer` extend it.

Nothing in setup constructs a separate bus to inject.
Classes that need the surface inherit `cls EventEmitter` themselves.

`cls EventEmitter` is a superset of the interface.
These behaviors are on the class and not on `cls IEventBus`.

| Extra | Behavior |
|---|---|
| `str all` | `fn on` with `str all` calls the handler for every emit as `(event, data)`. |
| `str listeners-changed` | Fired on a microtask when an event goes from empty to non-empty or back. Payload has `key name` and `key count`. |
| `str current` | `fn on` with `str current` logs a console warning that points to `str item`. |

A throwing handler does not stop the rest of the dispatch.
`fn emit` snapshots listeners before iterating.
Registering the same function twice for one event registers it once.

`fn once` stores a wrapper so `fn off` with your original function still removes it.
`fn listenerCount` is the total across every event, including firehose listeners.
`fn hasListeners` ignores the firehose.

## Interface

```ts
interface IEventBus<E extends Record<string, any> = Record<string, any>> {
	on<K extends keyof E>(event: K, fn: (data: E[K]) => void): void;
	on(event: string, fn: (data: unknown) => void): void;

	once<K extends keyof E>(event: K, fn: (data: E[K]) => void): void;
	once(event: string, fn: (data: unknown) => void): void;

	off<K extends keyof E>(event: K, fn?: (data: E[K]) => void): void;
	off(event: 'all'): void;
	off(event: string, fn?: (data: unknown) => void): void;

	emit<K extends keyof E>(event: K, data?: E[K]): void;
	emit(event: string, data?: unknown): void;

	hasListeners<K extends keyof E>(event: K): boolean;
	hasListeners(event: string): boolean;

	listenerCount(): number;
}
```

Every method also has a bare-string overload beside the typed one.
Dynamic names such as `str plugin:<id>:<event>` type-check through that overload.

## Custom implementation

Implement `cls IEventBus` when you need a fake or a forwarding wrapper.
You cannot pass it through setup.
Nothing in Player Core constructs a replaceable bus instance.

```ts
import type { IEventBus } from '@nomercy-entertainment/nomercy-player-core/adapters/event-bus';

type DemoEvents = {
	ready: { id: string };
};

class RecordingBus implements IEventBus<DemoEvents> {
	private readonly handlers = new Map<string, Set<(data: unknown) => void>>();

	on(event: string, fn: (data: unknown) => void): void {
		let set = this.handlers.get(event);
		if (!set) {
			set = new Set();
			this.handlers.set(event, set);
		}
		set.add(fn);
	}

	once(event: string, fn: (data: unknown) => void): void {
		const wrapper = (data: unknown): void => {
			this.off(event, wrapper);
			fn(data);
		};
		this.on(event, wrapper);
	}

	off(event: string, fn?: (data: unknown) => void): void {
		if (event === 'all' && !fn) {
			this.handlers.clear();
			return;
		}
		const set = this.handlers.get(event);
		if (!set) return;
		if (!fn) {
			this.handlers.delete(event);
			return;
		}
		set.delete(fn);
	}

	emit(event: string, data?: unknown): void {
		const set = this.handlers.get(event);
		if (!set) return;
		for (const fn of Array.from(set)) fn(data);
	}

	hasListeners(event: string): boolean {
		return (this.handlers.get(event)?.size ?? 0) > 0;
	}

	listenerCount(): number {
		let total = 0;
		for (const set of this.handlers.values()) total += set.size;
		return total;
	}
}
```
