# ILifecycleRegistry

Use `cls ILifecycleRegistry` when a helper must record its cleanup on whatever registry it is handed.
The registry decides what gets torn down when the owner goes away.
The player builds a new `cls LifecycleRegistry` for every plugin it registers.
There is no `key lifecycleRegistry` option in `fn setup`.

:::snippet{file="core-adapter-lifecycle-registry" lines="17-18" live="false"}
:::

`cls LifecycleRegistry` comes from the package root and from the subpath.
`cls ILifecycleRegistry` is only on the subpath.

## Built-in adapter

`fn dispose` removes DOM listeners first.
Then it clears timeouts, intervals and frame loops, disconnects observers, and aborts controllers.
The `fn addCleanup` callbacks run last, most recent first.

A callback that throws is caught and logged, and the teardown goes on.
A throw inside a `fn timeout`, `fn interval` or `fn frame` body is caught and logged the same way.

Every method stays safe after `fn dispose`, so you never check `fn isDisposed` first.

| Call after dispose | Result |
|---|---|
| `fn addCleanup` | Runs the callback at once. |
| `fn listen` | Attaches nothing. |
| `fn timeout`, `fn interval` | Schedule nothing and return `-1`. |
| `fn observe` | Records nothing and returns the observer. |
| `fn abortable` | Returns a controller that is already aborted. |
| `fn frame` | Starts nothing and returns a canceller that does nothing. |
| `fn dispose` | Returns without a second teardown. |

`fn frame` also starts nothing where `requestAnimationFrame` is missing, such as Node or server rendering.

## Interface

The table lists every member of `cls ILifecycleRegistry`.

| Member | Behavior |
|---|---|
| `fn addCleanup` | Queues a callback for `fn dispose`. |
| `fn listen` | Calls `addEventListener` with the same arguments and removes it on dispose. |
| `fn timeout` | Wraps `setTimeout` and returns the timer ID. |
| `fn interval` | Wraps `setInterval` and returns the timer ID. |
| `fn observe` | Keeps any object with `disconnect()` and returns it, so a call can chain. |
| `fn abortable` | Returns a new `cls AbortController` that dispose aborts. |
| `fn frame` | Runs a callback on every animation frame with `(deltaMs, time)`. |
| `fn dispose` | Releases everything recorded. |
| `fn isDisposed` | Whether `fn dispose` has run. |

On the interface, `fn frame` returns nothing.
`cls LifecycleRegistry` returns a `() => void` that stops that one loop.
Code typed against the interface cannot reach that canceller.

## Custom implementation

Type your helper against `cls ILifecycleRegistry` instead of implementing one.
The player never takes a registry from you, so a second implementation has no slot to fill.
