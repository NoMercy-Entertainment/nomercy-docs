# ILanguageMatcher

Use `cls ILanguageMatcher` when your own lookup must try a specific language, then a broader one.
It decides the fallback order for one BCP 47 tag.

The built-in translator walks the default chain when it looks up a string, for the player's own strings and for plugin strings.
The player also walks it to load plugin bundles for a language.

There is no `key languageMatcher` option in `fn setup`.
To change the lookup order, pass your own `key translator` in `fn setup`: it then owns the lookup.

## Built-in adapter

`var bcp47FallbackChain` is the shipped `cls ILanguageMatcher`.
It returns the tag, then strips one trailing subtag at a time on the `str -` separator.
An empty tag returns an empty array.

It keeps case and whitespace as given, because bundle keys are compared byte for byte.
`str PT-br` does not match a bundle stored as `str pt-BR`.

Call the matcher with a tag and walk the array in order.

## Interface

`cls ILanguageMatcher` has one call signature and no members.

| Part | Type |
|---|---|
| `key tag` | `string`, a BCP 47 tag |
| Return | `string[]`, most specific first |
