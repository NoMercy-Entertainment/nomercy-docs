# Adapter: Stream Source

`IStreamSource` is one active instance per playback item: native, HLS, or DASH. Backend code never branches on protocol. `IStreamFactory` decides which kind gets created for a given URL. A consumer registers a factory to add a new protocol.

## The factory contract

```ts
interface IStreamFactory {
	readonly id: string;
	canPlay(url: string, contentType?: string, capabilities?: StreamCapabilities): boolean;
	create(opts: StreamFactoryOptions): IStreamSource;
}
```

The player calls `canPlay` for every URL it resolves. Only return `true` when your factory can actually handle the URL. `capabilities` lets a factory decline a URL it could parse but this device cannot decode smoothly. The player calls `create` at most once per resolution.

## The source contract

`IStreamSource` exposes `attach(element)`, `detach()`, and `destroy()` for lifecycle, plus `state()` for the current `StreamSourceState`.

Adaptive formats also get an optional ABR surface:

- `getLevels()`
- `setLevel(idx)`
- `getCurrentLevel()`
- `setLevelStrategy(fn)`

Fixed-bitrate sources simply omit those methods.

These events flow through `on()` and `off()`:

- `manifest-loaded`
- `level-switched`
- `level-considered`
- `fragment-loaded`
- `encrypted`
- `error`

## Rules & restrictions

- `StreamRegistry.resolve()` injects a `registry` field into `create()` automatically. The created source uses it to pipe fetches through `runInterceptors()`. Consumers never set the field themselves.
- `StreamInterceptor` functions installed via `StreamRegistry.intercept()` compose in registration order. Each receives the previous one's output. Use them to rewrite manifest URLs or inject auth into segment requests without forking the factory.

## How to extend it

```ts
import nmplayer from '@nomercy-entertainment/nomercy-video-player'; // nomercy-music-player's factory works identically
import type { IStreamFactory } from '@nomercy-entertainment/nomercy-player-core';

const player = nmplayer('player');

const dashFactory: IStreamFactory = {
	id: 'dash',
	canPlay: url => url.endsWith('.mpd'),
	create: opts => myDashSourceFrom(opts),
};

player.registerStream(dashFactory);
```
