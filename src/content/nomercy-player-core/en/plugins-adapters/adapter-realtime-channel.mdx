# Adapter: Realtime Channel

`cls IRealtimeChannel` is a live connection reduced to five members, so plugin code writes against one shape whatever transport is underneath. `cls RealtimeFactory` is the function that builds one from a URL.

Supply your own factory when the player has to share a connection with the rest of your application, or speak something other than a bare WebSocket: a SignalR hub, Socket.IO, or a transport that reconnects on its own. Watch-party sync and remote-control sessions are the usual reasons.

## The interfaces

```ts
interface IRealtimeChannel {
	send(data: string | ArrayBuffer | Blob): void;
	close(code?: number, reason?: string): void;
	on(event: 'open' | 'message' | 'close' | 'error', fn: (data?: unknown) => void): void;
	off(event: 'open' | 'message' | 'close' | 'error', fn: (data?: unknown) => void): void;
	readonly readyState: 'connecting' | 'open' | 'closing' | 'closed';
}

type RealtimeFactory = (url: string, opts?: RealtimeFactoryOptions) => IRealtimeChannel;
```

`cls RealtimeFactoryOptions` reaches the factory whole:

| Field | What it carries |
|---|---|
| `key protocols` | Sub-protocol strings for the handshake. The built-in adapter passes them to the `cls WebSocket` constructor. |
| `key reconnect`, `key baseDelayMs`, `key maxDelayMs` | Reconnection settings. They are handed to the factory and acted on by a factory that implements reconnection. |
| `key factory` | A per-call override, for one connection on a different transport. |

## How a plugin opens one

`this.websocket(url, opts)` inside a plugin picks the factory in this order:

1. `key factory` on the call.
2. The player's configured `key websocketFactory`.
3. `fn nativeWebSocketAdapter`.

It then registers a cleanup on the plugin's lifecycle, so disposing the plugin closes the channel unless it is already closing or closed. Holding the reference to close it yourself is optional.

## Default implementation

`fn nativeWebSocketAdapter` wraps one browser `cls WebSocket`.

- `key readyState` maps the four numeric constants onto `str connecting`, `str open`, `str closing` and `str closed`, and anything else onto `str closed`.
- A `str message` listener receives the raw payload the socket delivered, not the event around it.
- A `str close` listener receives a `key code` and a `key reason`. An `str error` listener receives the browser's own event object.
- A listener that throws is caught, and the listeners registered after it on the same event still run.

It holds exactly one socket for its life. A connection that has to survive a drop is a property of the factory you supply.

## Where to import it from

```ts
import { nativeWebSocketAdapter } from '@nomercy-entertainment/nomercy-player-core';
import type { IRealtimeChannel, RealtimeFactory, RealtimeFactoryOptions } from '@nomercy-entertainment/nomercy-player-core';
```

All four are on the `./adapters/realtime` subpath as well.

## Rules & restrictions

- Send only while `key readyState` reads `str open`. A native socket throws on a send before the handshake finishes, and the port buffers nothing on your behalf.
- `fn on` takes every listener you give it and `fn off` needs the same function reference back. An inline arrow cannot be removed.
- `fn close` follows the WebSocket close handshake, so `key code` and `key reason` are the RFC 6455 values. Omit both for a clean close.
- A factory is called once per connection and gets the URL exactly as the caller wrote it. Signing or rewriting it is the factory's job.

## How to extend it

A global swap covers every realtime connection the player opens:

```ts
import nmplayer from '@nomercy-entertainment/nomercy-video-player'; // nomercy-music-player's factory works identically
import type { RealtimeFactory } from '@nomercy-entertainment/nomercy-player-core';

const signalRFactory: RealtimeFactory = (url, opts) => myHubChannel(url, opts);

const player = nmplayer('player');

player.setup({ websocketFactory: signalRFactory });
```

A single connection takes a different transport without touching that default:

```ts
this.websocket(url, { factory: socketIoFactory });
```
