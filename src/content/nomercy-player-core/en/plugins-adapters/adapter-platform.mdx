# IPlatform

Use `cls IPlatform` when the player runs inside a native shell, or when a test must fake the browser.
The bundle decides how the player keeps the screen awake, reads the network and tab visibility, and checks decode support.

Pass it to `fn setup` as `key platform`.
`fn platform` on the player returns the bundle in use, or `var browserPlatform` before `fn setup`.

## Built-in adapter

`var browserPlatform` is the default when `key platform` is not set.
Each field wraps a browser API, and each read of a field builds a new controller.
A spread such as `{ ...browserPlatform }` reads every field once, so the copy holds one controller per field.

Without `window` or `document`, `fn isOnline`, `fn isVisible` and each `fn subscribe` return safe values.
`fn type`, `fn downlinkMbps` and `fn rttMs` read `navigator` directly and throw where it is missing.

`fn acquire` on the wake lock throws `str core:policy/wakeLockUnsupported` where the browser has no wake lock API.
`fn enter` on fullscreen and picture in picture throws the matching `str core:policy/` error where the API is missing.

The player reads each field from one place.

| Field | What reads it |
|---|---|
| `key wakeLock` | The `key wakeLock` setup option, `str never` by default. |
| `key network` | The `key onOffline` option, and `fn networkState`. |
| `key visibility` | The `key pauseWhenHidden` option, and `fn visibilityState`. |
| `key capabilities` | `fn canPlay`, through `fn canDecode`. |
| `key fullscreen`, `key pip` | `fn device` for its two support flags, and the video player. |

## Interface

`cls IPlatform` holds four required controllers and two optional ones.
`key fullscreen` and `key pip` are for the video player only.

| Field | Members |
|---|---|
| `key wakeLock`, `cls IWakeLock` | `fn acquire`, `fn release`, `fn isHeld`, optional `fn isSupported` |
| `key network`, `cls INetworkMonitor` | `fn isOnline`, `fn type`, `fn downlinkMbps`, `fn rttMs`, `fn subscribe` |
| `key visibility`, `cls IVisibilityMonitor` | `fn isVisible`, `fn subscribe` |
| `key capabilities`, `cls ICapabilitiesProbe` | `fn canDecode`, optional `fn supportedCodecs` |
| `key fullscreen`, `cls IFullscreenController` | `fn enter`, `fn exit`, `fn isActive`, `fn isSupported`, `fn subscribe` |
| `key pip`, `cls IPipController` | `fn enter`, `fn exit`, `fn isActive`, `fn isSupported`, `fn subscribe` |

Each `fn subscribe` returns a function that removes the subscription.
`fn type` returns one of `str wifi`, `str cellular`, `str ethernet`, `str none` or `str unknown`.

When the network monitor reports a change while online, the player emits `str network:slow` once if `fn downlinkMbps` is more than 0 and less than 1.5.
With `key onOffline` set to `str ignore`, it never does.
`fn networkState` returns slow on the same rule at any time.
