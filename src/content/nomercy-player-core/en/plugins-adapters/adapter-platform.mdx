# Adapter: Platform

`cls IPlatform` is the bundle of browser primitives the kit reads instead of calling `ts navigator` and `ts document` itself. Wake lock, network state, tab visibility and decode capability all live behind it, so a Capacitor, Tauri or Electron shell swaps one object rather than patching call sites. [Swap an Adapter](/nomercy-player-core/recipes/swap-an-adapter) walks the same idea through a different port.

`fn setup` uses `cls browserPlatform` when `key platform` is omitted, and `player.platform()` reads back whichever object is in force.

## The interface

```ts
interface IPlatform {
	wakeLock: IWakeLock;
	network: INetworkMonitor;
	visibility: IVisibilityMonitor;
	capabilities: ICapabilitiesProbe;
	fullscreen?: IFullscreenController;
	pip?: IPipController;
}
```

## What reads each field

| Field | Methods | Who asks |
|---|---|---|
| `key wakeLock` | `fn acquire`, `fn release`, `fn isHeld`, `fn isSupported` | The `key wakeLock` config policy: `str never` by default, `str always` holds one for the player's life, `str auto` follows the phase. |
| `key network` | `fn isOnline`, `fn type`, `fn downlinkMbps`, `fn rttMs`, `fn subscribe` | The `key onOffline` policy, which emits `str network:offline`, `str network:online` and `str network:slow`. |
| `key visibility` | `fn isVisible`, `fn subscribe` | `key pauseWhenHidden`, off by default. When on, a hidden tab pauses and the player emits `str visibility:hidden`. |
| `key capabilities` | `fn canDecode`, `fn supportedCodecs` | `player.canPlay(profile)`, which answers `key supported`, `key smooth` and `key powerEfficient`. |
| `key fullscreen` | `fn enter`, `fn exit`, `fn isActive`, `fn isSupported`, `fn subscribe` | The video player's `fn fullscreen`, and `player.device().fullscreenSupported`. |
| `key pip` | the same five | The video player's `fn pip`, and `player.device().pipSupported`. |

`fn canDecode` takes a `cls DecodeProfile`: a `key contentType`, plus `key width`, `key height`, `key bitrate` and `key framerate` for a video probe. Give it the content type alone for an audio probe.

## Where to import it from

```ts
import { browserPlatform } from '@nomercy-entertainment/nomercy-player-core';
import type { ICapabilitiesProbe, IFullscreenController, INetworkMonitor, IPipController, IPlatform, IVisibilityMonitor, IWakeLock } from '@nomercy-entertainment/nomercy-player-core';
```

All of them are on the `./adapters/platform` subpath as well. `cls NetworkType` is the union `fn type` answers: `str wifi`, `str cellular`, `str ethernet`, `str none` or `str unknown`.

## Rules & restrictions

- `cls browserPlatform` builds a fresh controller on every property access, so read the one you want into a variable and keep it. State such as a held wake lock belongs to that instance, and a second read starts a second controller that knows nothing about the first. Spreading the object once, as the example below does, gives you six stable controllers.
- `key fullscreen` and `key pip` are the two optional fields, and the music player never reads either. Setting the video player's `fn fullscreen` or `fn pip` without the matching controller throws a `cls BrowserPolicyError` carrying `str core:policy/fullscreenUnsupported` or `str core:policy/pipUnsupported`. Reading the current state answers `str off` instead.
- `player.platform().fullscreen.isActive()` is the browser's own answer, which is what a control icon should follow.
- `fn acquire` throws `cls BrowserPolicyError` with `str core:policy/wakeLockUnsupported` where the Screen Wake Lock API is absent. Call `fn isSupported` first to gate the control rather than catch the throw. The kit's own wake-lock policy swallows the failure and plays on.
- `fn downlinkMbps` and `fn rttMs` answer `ts undefined` where the Network Information API is absent, which includes Firefox and Safari. They never invent a number, so `str network:slow` simply never fires there.
- `fn canDecode` answers `key supported` as `ts false` rather than throwing when the Media Capabilities API is missing, and `fn supportedCodecs` answers an empty array with no `ts MediaSource`.

## How to extend it

Spread the default and name only the controller you are replacing. The other five stay browser-native:

```ts
import nmplayer from '@nomercy-entertainment/nomercy-video-player'; // nomercy-music-player's factory works identically
import { browserPlatform } from '@nomercy-entertainment/nomercy-player-core';
import type { IWakeLock } from '@nomercy-entertainment/nomercy-player-core';

let held = false;

const shellWakeLock: IWakeLock = {
	async acquire() {
		await shell.keepAwake();
		held = true;
	},
	async release() {
		await shell.allowSleep();
		held = false;
	},
	isHeld: () => held,
	isSupported: () => true,
};

const player = nmplayer('player');

player.setup({
	platform: { ...browserPlatform, wakeLock: shellWakeLock },
	wakeLock: 'auto',
});
```

A shell that owns every primitive passes a whole object of its own instead, and the six fields above are the entire contract it has to satisfy.
