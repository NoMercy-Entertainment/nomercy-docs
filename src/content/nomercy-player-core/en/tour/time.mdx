# Time

Position and duration on the player are numbers of seconds.
`key percentage` is the exception: it runs from 0 to 100.

## Read position and duration

`fn time` with no argument returns the last known position in seconds.
It reads an internal slot, so a render loop can call it without querying the backend.

```ts
player.time();
player.duration();
```

`fn duration` returns the length in seconds.
It is `0` until metadata has loaded.

Treat `duration() === 0` as unknown length, not a zero-length item.
Guard any division by duration until that value is known.

## When the cursor moves

When the new id differs from the mounted one, time and duration become `0` before `str item` fires.
An `str item` listener therefore does not see the outgoing end position.

Wait for `str mediaReady` before you read the new item's position.
That event fires after the new media has mounted.

```ts
player.on('mediaReady', () => {
  console.log(player.time(), player.duration());
});
```

## One consistent snapshot

`fn timeData` returns every time field from one moment.
Derived values agree because they come from the same call.

Use these fields when you need position, length, and percentage together:

| Field | Unit and meaning |
| --- | --- |
| `key position` | seconds played; same number as `fn time` |
| `key duration` | length in seconds; `0` until known |
| `key buffered` | absolute timeline seconds buffered data reaches |
| `key remaining` | `duration - position`, floored at 0 |
| `key percentage` | position as 0 to 100 of duration; `0` while duration is `0` |

`key time` is another name for `key position`.

The `str time` event carries this same shape on each tick.
A handler can bind the payload without re-reading getters.

## Seek

Pass seconds to `fn time` to seek.
Negative values clamp to 0.
The setter returns a `Promise` you can await for the full seek cycle.

A listener can cancel through `str beforeSeek`.
When canceled, `str seekPrevented` fires and the position stays put.
Otherwise the player emits `str seek`, then `str seeked`, and forwards the position to the backend.

`fn seekByPercentage` takes 0 to 100, not 0 to 1.
Out-of-range values clamp into that band.
It is a no-op while duration is 0 or non-finite, so scrubbers stay quiet before metadata lands.

```ts
await player.time(82.4);
player.seekByPercentage(50);
```

## Buffer and ranges

`fn buffered` returns the absolute timeline position buffered data reaches, in seconds.
Draw a buffered bar as `buffered() / duration()` once duration is known.
It returns `0` when no backend is registered.

`fn bufferedRanges` and `fn seekable` return the backend's `cls TimeRanges`.
Each returns an empty range set when no backend is mounted or the method is missing.
Neither returns null.

## Ending soon

`str itemEndingSoon` fires once per item when remaining seconds drop to the threshold.
The default threshold is 10 seconds, set with `key itemEndingSoonThreshold`.

```ts
player.setup({
  itemEndingSoonThreshold: 30,
});
```

The payload carries `key remaining` and the current `key item`.

## Playback rate

`fn playbackRate` with no argument returns the current multiplier.
Pass a value to set it; the value clamps to 0.25 through 2.
`fn playbackRates` returns the fixed list `[0.5, 0.75, 1, 1.25, 1.5, 2]`.
