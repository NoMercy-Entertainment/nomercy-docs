# Adapters

Use an adapter when Player Core needs a capability it should not own.
The clock is the smallest one: what time is it right now.

`cls IClock` answers that with one method, `fn now`.
It returns a Unix-epoch millisecond integer.
The shipped default is `systemClock`, which calls `Date.now()`.

## Import the clock

Import the type and the default from the `adapters/clock` path.

```ts
import type { IClock } from '@nomercy-entertainment/nomercy-player-core/adapters/clock';
import { systemClock } from '@nomercy-entertainment/nomercy-player-core/adapters/clock';
```

## Read the default

Call `fn now` on `systemClock` when you want the millisecond value that default produces.

```ts
systemClock.now();
```

## Supply your own

Implement `cls IClock` when a test must fix the time, or when sync needs one shared timeline.
`fn setup` is the call that hands config to your player.
Pass that millisecond value through `key clockSource` on that call.
`key clockSource` is a function that returns the integer, so wrap your clock as `() => clock.now()`.
