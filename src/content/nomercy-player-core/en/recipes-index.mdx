# Recipes

The player core handles concerns that every player shares: auth, storage, session persistence, and system integration.
These recipes show you how to wire those concerns up in real projects, whether you are building on the video player, the music player, or your own player on top of `nomercy-player-core`.
Each guide is self-contained with working code you can drop straight in.

**Prerequisites:** a working install from the [Core quickstart](/nomercy-player-core/quickstart).

## Core recipes

| Recipe                                                        | What it solves                                                            |
| ------------------------------------------------------------- | ------------------------------------------------------------------------- |
| [Media Session](/nomercy-player-core/recipes/media-session)    | System MediaSession integration, lock-screen metadata, artwork            |
| [Persistence](/nomercy-player-core/recipes/persistence)        | Storage adapter selection, saving playback position, restoring on reload  |
| [Auth and Tokens](/nomercy-player-core/recipes/auth-and-tokens) | authFetch wrapper, refresh-on-401, propagating-on-403                     |

## Library-specific recipes

Anything tied to a media type lives with that library, not here.
Subtitles, chapters, quality selection and keyboard shortcuts are video concerns; crossfade, gapless and lyrics/EQ are music concerns.

- **[Video Player recipes](/nomercy-video-player/recipes/overview)**: subtitles, chapters, quality selection, playlist/queue, keyboard shortcuts, live transcoding
- **[Music Player recipes](/nomercy-music-player/recipes/overview)**: playlist/queue, crossfade and gapless, lyrics and equalizer
