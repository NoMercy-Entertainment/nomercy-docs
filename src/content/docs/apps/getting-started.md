## Welcome to NoMercy

NoMercy is a comprehensive entertainment management system designed to help you organize, discover, and manage your entertainment content effectively.

## What is NoMercy?

NoMercy provides:

- **Content Discovery**: Find and organize movies, TV shows, and other entertainment content
- **Media Management**: Centralized media server for efficient file organization and streaming
- **Smart Indexing**: Automatic categorization and tagging of your entertainment library
- **Easy Access**: Web-based interface for accessing your content from anywhere

## Getting Started

To get started with NoMercy:

1. **Install the Application**: Follow our [Installation Guide](/apps/installation) to set up NoMercy
2. **Configure MediaServer**: Set up the MediaServer component as described in the [Configuration Guide](/mediaserver/configuration)
3. **Add Your Content**: Add your entertainment files to the managed library
4. **Start Exploring**: Use the application to discover and manage your content
