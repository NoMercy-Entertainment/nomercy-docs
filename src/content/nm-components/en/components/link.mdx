`NMLink` is the component your server names when it wants a link.
Like every NM component it accepts children and takes its box from the payload, so you can place
one inside a dashboard without it needing to know where it was placed.

## Sending one

A component arrives inside the standard envelope. The `component` field names it and `props` is
everything below.

```json
{
  "id": "link-1",
  "component": "NMLink",
  "props": {
    "id": "link-1",
    "iconPosition": "right",
    "size": "inherit",
    "box": { "margin": { "y": "4" }, "padding": { "all": "3" } }
  }
}
```

The same thing from a server, or from a plugin, using the generated builder:

```csharp
NMLinkProps props = new()
{
    Id = "link-1",
    IconPosition = "right",
    Size = "inherit",
    Box = new() { Margin = new() { Y = NmSpace.X4 }, Padding = new() { All = NmSpace.X3 } },
};

// In a plugin, the record becomes a node the client draws:
PluginComponent node = PluginDesign.Node("link-1", props);
```

## Options

Every option is optional. Leave one out and the component uses the default in the last column,
which is the same default on every platform.

| Option | Accepts | Default | What it does |
| --- | --- | --- | --- |
| `disabled` | `true` , `false` | `false` | Disable link interaction |
| `external` | `true` , `false` | `false` | Open in new tab |
| `icon` | `true` , `false` | `false` | Show icon |
| `iconPosition` | `left` , `right` | `right` | Icon position |
| `iconValue` | icon name | `Arrows/arrow-up-right` | Icon |
| `size` | `sm` , `md` , `lg` , `inherit` | `md` | Link size |
| `text` | text | `` | Link text content |
| `variant` | `default` , `subtle` , `muted` , `animated` | `default` | Link visual style |

## Children

Anything you nest under `items` renders inside it.

## Accessibility

You do not have to do anything to get this. It is built in, and the list is here so you know what
you can count on and what you would be breaking if you overrode it.

| Attribute | Why |
| --- | --- |
| `aria-label` | For external links, append "(opens in new tab)" to the accessible name so users know the link opens in a new window |
| `aria-disabled` | Set to "true" on disabled links to indicate non-interactive state to assistive technologies |
| `aria-hidden="true"` | Apply to decorative icons so screen readers skip them and announce only the link text |
| `href` | `Required on <a> for valid link semantics and keyboard activation` |
| `target="_blank"` | Used with rel="noopener noreferrer" for external links; pair with aria-label for new-tab announcement |

### Keyboard and remote

Each of these works with a keyboard on web and with a D-pad on television.

| Key | What happens |
| --- | --- |
| `Enter` | Activates the link and navigates to the href |
| `Space` | Activates the link (when focusable) |
| `Tab` | Moves focus to the next focusable element |
| `Shift + Tab` | Moves focus to the previous focusable element |

## Placing it

Padding, margin, width, alignment and order all come from `box`, which every component accepts.
A parent decides where this component sits and how much room it takes; the component decides how
its own children are arranged. See [the box](/nm-components/box) for the full vocabulary.
