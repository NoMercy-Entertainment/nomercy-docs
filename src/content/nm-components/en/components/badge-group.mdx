title: Badge Group
description: Grouped badge with shared container and descriptive text
---

`NMBadgeGroup` is the component your server names when it wants a badge group.
Like every NM component it accepts children and takes its box from the payload, so you can place
one inside a dashboard without it needing to know where it was placed.

## Sending one

A component arrives inside the standard envelope. The `component` field names it and `props` is
everything below.

```json
{
  "id": "badge-group-1",
  "component": "NMBadgeGroup",
  "props": {
    "id": "badge-group-1",
    "badgePos": "right",
    "size": "lg",
    "box": { "margin": { "y": "4" }, "padding": { "all": "3" } }
  }
}
```

## What it does

These are the behaviours the design system specifies for it, so you can rely on all of them
being present on web, on mobile and on television.

- Grouped badge with shared container and descriptive text
- Badge position: left or right of text
- Optional arrow icon for navigation or CTA hints
- Ghost, solid, and outline variants
- Full Radix color palette (teal, blue, red, etc.)
- Two sizes: md and lg
- Uses Badge component internally

## Options

Every option is optional. Leave one out and the component uses the default in the last column,
which is the same default on every platform.

| Option | Accepts | Default | What it does |
| --- | --- | --- | --- |
| `badgePos` | `left` , `right` | `left` | Badge position relative to text |
| `badgeText` | text | `New feature` | Badge text content |
| `color` | text | `teal` | Badge color from Radix palette |
| `groupText` | text | `We've just released a new feature` | Descriptive text content |
| `size` | `md` , `lg` | `md` | Badge group size |
| `variant` | `ghost` , `solid` , `outline` | `ghost` | Badge visual style |

## Children

Anything you nest under `items` renders inside it.

## Accessibility

You do not have to do anything to get this. It is built in, and the list is here so you know what
you can count on and what you would be breaking if you overrode it.

| Attribute | Why |
| --- | --- |
| `aria-label` | Add to parent link if badge group is a clickable CTA |
| `aria-hidden="true"` | Use on arrow icon if it is purely decorative |
| `role` | No role needed for static badge groups; use semantic HTML (e.g., <a>) for links |

### Keyboard and remote

Each of these works with a keyboard on web and with a D-pad on television.

| Key | What happens |
| --- | --- |
| `Tab` | If wrapped in link, focus moves to the link |
| `Enter` | Activates link when badge group is a CTA |
| `Space` | Activates link when badge group is a CTA |

## Placing it

Padding, margin, width, alignment and order all come from `box`, which every component accepts.
A parent decides where this component sits and how much room it takes; the component decides how
its own children are arranged. See [the box](/nm-components/box) for the full vocabulary.
