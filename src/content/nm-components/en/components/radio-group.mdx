`NMRadioGroup` is the component your server names when it wants a radio group.
Like every NM component it accepts children and takes its box from the payload, so you can place
one inside a dashboard without it needing to know where it was placed.

## Sending one

A component arrives inside the standard envelope. The `component` field names it and `props` is
everything below.

```json
{
  "id": "radio-group-1",
  "component": "NMRadioGroup",
  "props": {
    "id": "radio-group-1",
    "layout": "inline",
    "size": "lg",
    "box": { "margin": { "y": "4" }, "padding": { "all": "3" } }
  }
}
```

## What it does

These are the behaviours the design system specifies for it, so you can rely on all of them
being present on web, on mobile and on television.

- Composes mom-field-label for group label (with required/optional/info markers)
- Composes mom-field-helper for group helper (with error state + optional icon)
- Toggle entries use mom-radio without per-item helper text
- Three layouts: vertical, horizontal, inline
- Three sizes: sm, md, lg
- Error and disabled states propagate to label, items, and helper

## Options

Every option is optional. Leave one out and the component uses the default in the last column,
which is the same default on every platform.

| Option | Accepts | Default | What it does |
| --- | --- | --- | --- |
| `groupDisabled` | `true` , `false` | `false` | Disabled state for the group |
| `groupError` | `true` , `false` | `false` | Error state for the group |
| `layout` | `vertical` , `horizontal` , `inline` | `vertical` | Layout direction |
| `size` | `sm` , `md` , `lg` | `md` | Radio group size |

## Children

Anything you nest under `items` renders inside it.

## Accessibility

You do not have to do anything to get this. It is built in, and the list is here so you know what
you can count on and what you would be breaking if you overrode it.

| Attribute | Why |
| --- | --- |
| `role="radiogroup"` | Identifies the container as a radio group |
| `aria-labelledby` | References the mom-field-label id |
| `aria-describedby` | References the mom-field-helper id |
| `aria-invalid` | Set when group has validation error |
| `aria-required` | Set when selection is mandatory |
| `aria-disabled` | Set when entire group is disabled |

### Keyboard and remote

Each of these works with a keyboard on web and with a D-pad on television.

| Key | What happens |
| --- | --- |
| `Tab` | Moves focus into the group |
| `Arrow keys` | Move selection between radio options |
| `Space` | Selects the focused radio option |
| `Shift + Tab` | Moves focus out of the group |

## Placing it

Padding, margin, width, alignment and order all come from `box`, which every component accepts.
A parent decides where this component sits and how much room it takes; the component decides how
its own children are arranged. See [the box](/nm-components/box) for the full vocabulary.
