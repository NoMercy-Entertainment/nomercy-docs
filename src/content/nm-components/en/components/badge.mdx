`NMBadge` is the component your server names when it wants a badge.
Like every NM component it accepts children and takes its box from the payload, so you can place
one inside a dashboard without it needing to know where it was placed.

## Sending one

A component arrives inside the standard envelope. The `component` field names it and `props` is
everything below.

```json
{
  "id": "badge-1",
  "component": "NMBadge",
  "props": {
    "id": "badge-1",
    "color": "green",
    "mode": "icon-only",
    "box": { "margin": { "y": "4" }, "padding": { "all": "3" } }
  }
}
```

## What it does

These are the behaviours the design system specifies for it, so you can rely on all of them
being present on web, on mobile and on television.

- Three variants: ghost, solid, and outline
- Three sizes: sm (22px), md (24px), lg (28px)
- Full Radix color palette (teal, cyan, blue, violet, red, green, gray, etc.)
- Text with optional left and right icons
- Icon-only mode for compact indicators
- Optional dot indicator for status badges
- Tag mode with close button for removable labels
- Badge group component for label + badge combinations

## Options

Every option is optional. Leave one out and the component uses the default in the last column,
which is the same default on every platform.

| Option | Accepts | Default | What it does |
| --- | --- | --- | --- |
| `color` | `teal` , `red` , `blue` , `green` | `teal` | Badge color |
| `dot` | `true` , `false` | `false` | Show status dot indicator |
| `mode` | `text` , `icon-only` | `text` | Display mode |
| `size` | `sm` , `md` , `lg` | `md` | Badge size |
| `text` | text | `Label` | Badge text content |
| `variant` | `ghost` , `solid` , `outline` | `ghost` | Visual style variant |

## Children

Anything you nest under `items` renders inside it.

## Accessibility

You do not have to do anything to get this. It is built in, and the list is here so you know what
you can count on and what you would be breaking if you overrode it.

| Attribute | Why |
| --- | --- |
| `role="img"` | Required for icon-only badges to expose them as images to screen readers |
| `aria-label` | Required for icon-only badges to provide an accessible name (e.g., "Add", "Remove") |
| `aria-hidden="true"` | Use on decorative icons and dot indicator so they are not announced |
| `aria-label` | Tag close buttons need descriptive labels (e.g., "Remove tag", "Remove filter") |

### Keyboard and remote

Each of these works with a keyboard on web and with a D-pad on television.

| Key | What happens |
| --- | --- |
| `Tab` | Moves focus to the next focusable element (tag close buttons) |
| `Shift + Tab` | Moves focus to the previous focusable element |
| `Enter` | Activates tag close button when focused |
| `Space` | Activates tag close button when focused |

## Placing it

Padding, margin, width, alignment and order all come from `box`, which every component accepts.
A parent decides where this component sits and how much room it takes; the component decides how
its own children are arranged. See [the box](/nm-components/box) for the full vocabulary.
