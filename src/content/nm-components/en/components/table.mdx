`NMTable` is the component your server names when it wants a table.
Like every NM component it accepts children and takes its box from the payload, so you can place
one inside a dashboard without it needing to know where it was placed.

## Sending one

A component arrives inside the standard envelope. The `component` field names it and `props` is
everything below.

```json
{
  "id": "table-1",
  "component": "NMTable",
  "props": {
    "id": "table-1",
    "size": "lg",
    "variant": "minimal",
    "box": { "margin": { "y": "4" }, "padding": { "all": "3" } }
  }
}
```

## Options

Every option is optional. Leave one out and the component uses the default in the last column,
which is the same default on every platform.

| Option | Accepts | Default | What it does |
| --- | --- | --- | --- |
| `hover` | `true` , `false` | `true` | Row hover effect |
| `size` | `sm` , `md` , `lg` | `md` | Table size |
| `striped` | `true` , `false` | `true` | Alternate row background colors |
| `variant` | `default` , `bordered` , `minimal` | `default` | Table visual style |

## Children

Anything you nest under `items` renders inside it.

## Accessibility

You do not have to do anything to get this. It is built in, and the list is here so you know what
you can count on and what you would be breaking if you overrode it.

| Attribute | Why |
| --- | --- |
| `role="table"` | Explicit table role for assistive technologies |
| `aria-label` | Provides accessible name for the table (use caption for visible titles) |
| `scope="col"` | Associates header cells with their column cells in thead |
| `aria-sort` | Indicates sort state on sortable columns (none, ascending, descending) |
| `aria-label on checkboxes` | Contextual labels like "Select Alex Chen" or "Select all rows" |
| `aria-label on action buttons` | Contextual labels like "Actions for Alex Chen" |

### Keyboard and remote

Each of these works with a keyboard on web and with a D-pad on television.

| Key | What happens |
| --- | --- |
| `Tab` | Moves focus between interactive elements (checkboxes, sort buttons, actions) |
| `Space` | Toggles checkboxes or activates sort/action buttons |
| `Enter` | Activates sort buttons and action buttons |
| `Arrow keys` | Navigate within rating star controls when focused |

## Placing it

Padding, margin, width, alignment and order all come from `box`, which every component accepts.
A parent decides where this component sits and how much room it takes; the component decides how
its own children are arranged. See [the box](/nm-components/box) for the full vocabulary.
