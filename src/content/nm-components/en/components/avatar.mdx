`NMAvatar` is the component your server names when it wants a avatar.
Like every NM component it accepts children and takes its box from the payload, so you can place
one inside a dashboard without it needing to know where it was placed.

## Sending one

A component arrives inside the standard envelope. The `component` field names it and `props` is
everything below.

```json
{
  "id": "avatar-1",
  "component": "NMAvatar",
  "props": {
    "id": "avatar-1",
    "color": "gray",
    "size": "xl",
    "box": { "margin": { "y": "4" }, "padding": { "all": "3" } }
  }
}
```

## What it does

These are the behaviours the design system specifies for it, so you can rely on all of them
being present on web, on mobile and on television.

- Four types: image, icon, single initial, or initials
- Five sizes: xs (24px), sm (32px), md (40px), lg (48px), xl (64px)
- All Radix colors: teal, red, pink, purple, blue, gold, gray
- Status indicators: online, offline, away, busy
- Square or circular shape via mom-avatar--square
- Fallback support for images (alt text and aria-label)

## Options

Every option is optional. Leave one out and the component uses the default in the last column,
which is the same default on every platform.

| Option | Accepts | Default | What it does |
| --- | --- | --- | --- |
| `alt` | text | x | Alt text for image (required for type="image") |
| `ariaLabel` | text | `User avatar` | ARIA Label |
| `color` | `teal` , `red` , `pink` , `purple` , `blue` , `gold` , `gray` | `teal` | Background color |
| `size` | `xs` , `sm` , `md` , `lg` , `xl` | `md` | The size of the avatar |
| `square` | `true` , `false` | `false` | Use square shape instead of circular |
| `src` | text | `https://api.dicebear.com/7.x/avataaars/svg?seed=avatar` | Image URL (for type="image") |
| `status` | `none` , `online` , `offline` , `away` , `busy` | `none` | Status indicator |
| `type` | `icon` , `initial` , `initials` , `image` | `icon` | The type of avatar content |

## Children

Anything you nest under `items` renders inside it.

## Accessibility

You do not have to do anything to get this. It is built in, and the list is here so you know what
you can count on and what you would be breaking if you overrode it.

| Attribute | Why |
| --- | --- |
| `alt` | Required on image avatars to describe the photo (e.g. user name) |
| `aria-label` | Use on icon and initials avatars to provide accessible name when standalone |
| `role="img"` | Applied to the avatar container for icon/initials types; status dot uses role="img" for the indicator |
| `aria-hidden="true"` | Applied to decorative inner elements (icon, text span) so screen readers skip redundant content |
| `aria-label on status` | Status dot includes aria-label (e.g. "Status: Online") for presence information |

### Keyboard and remote

Each of these works with a keyboard on web and with a D-pad on television.

| Key | What happens |
| --- | --- |
| `Tab` | When avatar is inside a focusable container (e.g. user card), focus moves to the parent |
| `Enter` | When avatar is part of a button or link, activates the parent control |
| `Space` | When avatar is part of a button, activates the parent control |
| `Shift + Tab` | Moves focus to the previous focusable element |

## Placing it

Padding, margin, width, alignment and order all come from `box`, which every component accepts.
A parent decides where this component sits and how much room it takes; the component decides how
its own children are arranged. See [the box](/nm-components/box) for the full vocabulary.
