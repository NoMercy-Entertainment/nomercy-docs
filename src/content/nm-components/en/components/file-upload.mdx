`NMFileUpload` is the component your server names when it wants a file upload.
Like every NM component it accepts children and takes its box from the payload, so you can place
one inside a dashboard without it needing to know where it was placed.

## Sending one

A component arrives inside the standard envelope. The `component` field names it and `props` is
everything below.

```json
{
  "id": "file-upload-1",
  "component": "NMFileUpload",
  "props": {
    "id": "file-upload-1",
    "box": { "margin": { "y": "4" }, "padding": { "all": "3" } }
  }
}
```

## What it does

These are the behaviours the design system specifies for it, so you can rely on all of them
being present on web, on mobile and on television.

- `Dropzone built with <label> and <input type="file"> for native accessibility`
- File items with multiple states: default, uploading (teal glow), progress bar, and error
- Progress bars with role="progressbar", aria-valuenow, aria-valuemin, aria-valuemax
- aria-live and aria-busy on uploading items for screen reader announcements
- role="alert" and aria-live="assertive" for error state announcements
- Action buttons: cancel (uploading), retry/dismiss (error), remove (success)
- aria-label on all action buttons for descriptive labels
- aria-label on file input for upload context

## Options

Every option is optional. Leave one out and the component uses the default in the last column,
which is the same default on every platform.

| Option | Accepts | Default | What it does |
| --- | --- | --- | --- |
| `uploadPct` | number | `40` | Upload progress percentage |

## Children

Anything you nest under `items` renders inside it.

## Accessibility

You do not have to do anything to get this. It is built in, and the list is here so you know what
you can count on and what you would be breaking if you overrode it.

| Attribute | Why |
| --- | --- |
| `for / id` | Label is associated with the file input via for/id for click-to-upload |
| `aria-label` | On file input ("Upload file") and all action buttons (Cancel, Retry, Dismiss, Remove) |
| `aria-live / aria-busy` | On uploading items so screen readers announce progress changes |
| `role="progressbar"` | On the progress bar with aria-valuenow, aria-valuemin, aria-valuemax |
| `role="alert"` | On error state items with aria-live="assertive" for immediate announcement |
| `aria-hidden` | On decorative icon wrappers to avoid redundant announcements |

### Keyboard and remote

Each of these works with a keyboard on web and with a D-pad on television.

| Key | What happens |
| --- | --- |
| `Tab` | Moves focus through the file input and action buttons |
| `Enter / Space` | Activates the focused file input or button |
| `Escape` | May cancel upload or close error (implementation-dependent) |

## Placing it

Padding, margin, width, alignment and order all come from `box`, which every component accepts.
A parent decides where this component sits and how much room it takes; the component decides how
its own children are arranged. See [the box](/nm-components/box) for the full vocabulary.
