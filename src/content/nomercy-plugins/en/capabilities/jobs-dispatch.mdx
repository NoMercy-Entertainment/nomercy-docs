# `jobs.dispatch`

Queue a server job by kind.

## What it covers

| | |
| --- | --- |
| Facade | `IPluginContext.Jobs.DispatchAsync` |
| Scope | job kind |
| Trust | low |
| Revocable while the plugin runs | yes |

The owner grants this without being asked a second time.

Taking this grant away stops the next call. The plugin keeps running.

## Asking for it

Name it in the manifest:

```json
{
  "capabilities": [
    { "name": "jobs.dispatch", "scope": "*" }
  ]
}
```

The scope is job kind. A call outside it is refused with the grant's own name in the message, so the author reads which scope to widen rather than that something went wrong.
