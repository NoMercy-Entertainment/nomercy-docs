# `network.dial`

Raw TCP and UDP client sockets through context.Net.

## What it covers

| | |
| --- | --- |
| Facade | `IPluginContext.Net.DialAsync` |
| Scope | host glob |
| Trust | medium |
| Revocable while the plugin runs | yes |

The owner is asked before this is granted, and the grant names its scope.

Taking this grant away stops the next call. The plugin keeps running.

## Asking for it

Name it in the manifest:

```json
{
  "capabilities": [
    { "name": "network.dial", "scope": "*.example.com" }
  ]
}
```

The scope is host glob. A call outside it is refused with the grant's own name in the message, so the author reads which scope to widen rather than that something went wrong.

## When it refuses

| Code | Severity | What happened |
| --- | --- | --- |
| `PLUGIN_SOCKET_UNDECLARED` | blocked | The plugin opened a raw socket without network.dial. |

Every refusal carries what the plugin did, why the server said no, and how to fix it. Read all three before changing code.


## What the analyzer catches first

| Rule | What it says |
| --- | --- |
| `NMP0002` | Opening a socket directly bypasses the granted host list. Use context.Net.DialAsync. |

These fire at build time, so the author sees them before the server ever refuses.
