# `media.proxy`

Serve third-party audio, video and images through the server under the app CSP.

## What it covers

| | |
| --- | --- |
| Facade | `IPluginContext.Media.Proxy` |
| Scope | host glob |
| Trust | low |
| Revocable while the plugin runs | yes |

The owner grants this without being asked a second time.

Taking this grant away stops the next call. The plugin keeps running.

## Asking for it

Name it in the manifest:

```json
{
  "capabilities": [
    { "name": "media.proxy", "scope": "*.example.com" }
  ]
}
```

The scope is host glob. A call outside it is refused with the grant's own name in the message, so the author reads which scope to widen rather than that something went wrong.

## When it refuses

| Code | Severity | What happened |
| --- | --- | --- |
| `PLUGIN_TOKEN_IN_URL` | blocked | The plugin put a bearer token in a media URL. The host mints every media URL. |
| `PLUGIN_MEDIA_TICKET_EXPIRED` | blocked | A media link the server minted has run out, or was never one it minted. |
| `PLUGIN_MEDIA_TICKET_USER_MISMATCH` | blocked | A media link minted for one account was used by another. |
| `PLUGIN_QUOTA_UPLOAD_EXCEEDED` | degraded | A plugin is sending faster than the share of the uplink the owner allowed it. |

Every refusal carries what the plugin did, why the server said no, and how to fix it. Read all three before changing code.


## What the analyzer catches first

| Rule | What it says |
| --- | --- |
| `NMP0011` | A media URL is built by the plugin. Use context.Media.Proxy.MintAsync. |

These fire at build time, so the author sees them before the server ever refuses.
