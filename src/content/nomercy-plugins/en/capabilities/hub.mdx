# `hub`

Push to clients over SignalR and receive their calls.

## What it covers

| | |
| --- | --- |
| Facade | `IPluginContext.Hub` |
| Scope | (always) |
| Trust | low |
| Revocable while the plugin runs | yes |

The owner grants this without being asked a second time.

Taking this grant away stops the next call. The plugin keeps running.

## Asking for it

Name it in the manifest:

```json
{
  "capabilities": [
    { "name": "hub", "scope": "*" }
  ]
}
```

The scope is (always). A call outside it is refused with the grant's own name in the message, so the author reads which scope to widen rather than that something went wrong.

## When it refuses

| Code | Severity | What happened |
| --- | --- | --- |
| `PLUGIN_HUB_CALLER_NOT_RESOLVED` | blocked | A hub method was reached on a connection the host could not resolve a caller for. |

Every refusal carries what the plugin did, why the server said no, and how to fix it. Read all three before changing code.
