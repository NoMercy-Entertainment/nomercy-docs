# `player.source`

Play or enqueue a URL on the caller's player.

## What it covers

| | |
| --- | --- |
| Facade | `IPluginContext.Player.PlayAsync` |
| Scope | host glob |
| Trust | low |
| Revocable while the plugin runs | yes |

The owner grants this without being asked a second time.

Taking this grant away stops the next call. The plugin keeps running.

## Asking for it

Name it in the manifest:

```json
{
  "capabilities": [
    { "name": "player.source", "scope": "*.example.com" }
  ]
}
```

The scope is host glob. A call outside it is refused with the grant's own name in the message, so the author reads which scope to widen rather than that something went wrong.
