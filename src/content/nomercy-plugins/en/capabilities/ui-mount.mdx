# `ui.mount`

Placements in the slots that kind offers.

## What it covers

| | |
| --- | --- |
| Facade | `IUiPlugin` |
| Scope | kind |
| Trust | low |
| Revocable while the plugin runs | yes |

The owner grants this without being asked a second time.

Taking this grant away stops the next call. The plugin keeps running.

## Asking for it

Name it in the manifest:

```json
{
  "capabilities": [
    { "name": "ui.mount", "scope": "*" }
  ]
}
```

The scope is kind. A call outside it is refused with the grant's own name in the message, so the author reads which scope to widen rather than that something went wrong.

## When it refuses

| Code | Severity | What happened |
| --- | --- | --- |
| `PLUGIN_ROUTE_RESERVED_PREFIX` | blocked | The plugin claimed a route under the underscore prefix the host owns. |

Every refusal carries what the plugin did, why the server said no, and how to fix it. Read all three before changing code.


## What the analyzer catches first

| Rule | What it says |
| --- | --- |
| `NMP0015` | A UI mount names a slot that does not exist for its kind. |

These fire at build time, so the author sees them before the server ever refuses.
