# `storage.derived`

The derived audio and video store with LRU eviction.

## What it covers

| | |
| --- | --- |
| Facade | `IPluginContext.Storage.Derived` |
| Scope | quota |
| Trust | low |
| Revocable while the plugin runs | yes |

The owner grants this without being asked a second time.

Taking this grant away stops the next call. The plugin keeps running.

## Asking for it

Name it in the manifest:

```json
{
  "capabilities": [
    { "name": "storage.derived", "scope": "*" }
  ]
}
```

The scope is quota. A call outside it is refused with the grant's own name in the message, so the author reads which scope to widen rather than that something went wrong.
