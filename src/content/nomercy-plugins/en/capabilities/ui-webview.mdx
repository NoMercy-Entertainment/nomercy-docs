# `ui.webview`

A sandboxed webview for custom UI.

## What it covers

| | |
| --- | --- |
| Facade | `PluginWebViewRef` |
| Scope | origin |
| Trust | medium |
| Revocable while the plugin runs | yes |

The owner is asked before this is granted, and the grant names its scope.

Taking this grant away stops the next call. The plugin keeps running.

## Asking for it

Name it in the manifest:

```json
{
  "capabilities": [
    { "name": "ui.webview", "scope": "*" }
  ]
}
```

The scope is origin. A call outside it is refused with the grant's own name in the message, so the author reads which scope to widen rather than that something went wrong.
