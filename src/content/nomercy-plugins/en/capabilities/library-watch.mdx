# `library.watch`

Events when the library changes.

## What it covers

| | |
| --- | --- |
| Facade | `IPluginContext.Library.Watch` |
| Scope | library id |
| Trust | low |
| Revocable while the plugin runs | yes |

The owner grants this without being asked a second time.

Taking this grant away stops the next call. The plugin keeps running.

## Asking for it

Name it in the manifest:

```json
{
  "capabilities": [
    { "name": "library.watch", "scope": "*" }
  ]
}
```

The scope is library id. A call outside it is refused with the grant's own name in the message, so the author reads which scope to widen rather than that something went wrong.
