# `library.import`

Register a file, show, movie, album or recording into the library.

## What it covers

| | |
| --- | --- |
| Facade | `IPluginContext.Library.Import` |
| Scope | library id |
| Trust | low |
| Revocable while the plugin runs | no |

The owner grants this without being asked a second time.

Taking this grant away needs the plugin restarted. What it already holds cannot be handed back mid-run.

## Asking for it

Name it in the manifest:

```json
{
  "capabilities": [
    { "name": "library.import", "scope": "*" }
  ]
}
```

The scope is library id. A call outside it is refused with the grant's own name in the message, so the author reads which scope to widen rather than that something went wrong.
