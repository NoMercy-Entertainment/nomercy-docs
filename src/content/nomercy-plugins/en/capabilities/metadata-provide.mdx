# `metadata.provide`

Be a metadata provider for a media type.

## What it covers

| | |
| --- | --- |
| Facade | `IMetadataPlugin` |
| Scope | media type |
| Trust | low |
| Revocable while the plugin runs | yes |

The owner grants this without being asked a second time.

Taking this grant away stops the next call. The plugin keeps running.

## Asking for it

Name it in the manifest:

```json
{
  "capabilities": [
    { "name": "metadata.provide", "scope": "*" }
  ]
}
```

The scope is media type. A call outside it is refused with the grant's own name in the message, so the author reads which scope to widen rather than that something went wrong.
