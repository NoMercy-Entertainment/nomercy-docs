# Music Player: Quick Start

This gets a real song playing in the preview below: "Where Dreams Drift" by Ketsa, streamed from the `nomercy-media` fixture catalogue, using the baseUrl pattern every NoMercy player and app is built around.

## Install

```
npm install @nomercy-entertainment/nomercy-music-player@rc
```

That's the only package you need. `nomercy-player-core` is a regular dependency of `nomercy-music-player`, npm installs it for you, there is no peer dependency to add by hand.

Add a `<div id="player"></div>` to your page for that code to mount into. The music player has no `autoPlay` config field, so playback starts with `player.item(0, { autoplay: true })` once `ready()` resolves. Browsers block unmuted autoplay for `<audio>` the same way they do for `<video>`, so call `player.mute()` first if you need it to start without a user gesture, or trigger the same call from a click.

## The baseUrl pattern

`baseUrl` is the one config field every playlist should set. Item paths (`url` above) stay relative, exactly the shape a real media server sends, and the player prepends `baseUrl` as a plain string prefix, keeping the whole base path:

- The server sends the base with no trailing slash (`.../master/Music`) and each item path with a leading slash (`/K/Ketsa/...`).
- Move to a different server, a different environment, or a signed-URL CDN, and you change one config value; nothing in your catalogue is hardcoded to today's origin.
- Never pre-join an absolute URL into an item yourself. That is the player's job, and doing it twice breaks the moment the base changes.
