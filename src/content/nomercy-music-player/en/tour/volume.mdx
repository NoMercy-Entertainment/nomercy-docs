# Volume

Volume is another kit surface `nomercy-music-player` inherits unchanged. There's no music-specific volume behavior. The backend just needs a real gain to move.

## Reading and setting the level

`volume()` reads the current level as a number in `[0, 100]`. `volume(level)` sets it, clamped to that range, and returns a `Promise<void>` once the backend applies it. Full signatures for every method on this page are on [Reference: Domain Types](/nomercy-player-core/reference/types#volume--mute-methods).

```ts
import nmplayer from '@nomercy-entertainment/nomercy-music-player';

const player = nmplayer('player');

const level = player.volume(); // 0-100
await player.volume(50);
```

`MusicPlayerConfig` doesn't add a volume field of its own. It inherits `defaultVolume` from the kit's `BasePlayerConfig`. Set it at `setup()` for a declarative initial level. It defaults to `100` when omitted:

```ts
player.setup({
  baseUrl: 'https://raw.githubusercontent.com/NoMercy-Entertainment/nomercy-media/master/Music',
  playlist: [/* ... */],
  defaultVolume: 40,
});
```

Read a saved preference into that same field before `setup()` runs instead of calling `volume()` after `ready()`.

## Mute

`mute()` and `unmute()` are absolute. `toggleMute()` flips based on the current state. When already in the target state, all three no-op instead of dispatching. Otherwise, they dispatch `beforeMute` first, the same cancellable shape as transport:

```ts
await player.mute();
await player.unmute();
player.toggleMute();
```

`volumeUp(step?)` and `volumeDown(step?)` nudge the level by `step`, a sane default when omitted. Both clamp to `[0, 100]`, the same as a direct `volume()` call. This is the pair a keyboard shortcut binds to.

## Reading the gain stage

`volumeState()` returns a typed `VolumeState.UNMUTED` or `VolumeState.MUTED`. A mute-icon component reads this value instead of tracking its own boolean. That way, it stays correct even when something other than that icon, such as a keyboard shortcut or a Connect sync, changes the mute state:

```ts
import { VolumeState } from '@nomercy-entertainment/nomercy-music-player';

if (player.volumeState() === VolumeState.MUTED) {
  // show the muted icon
}
```

`volume`, `beforeVolume`, `mute`, and `beforeMute` each carry their own payload, see [Reference: Events](/nomercy-player-core/reference/events#language-volume-mode-state). Subscribe to those instead of polling the getters from a render loop.
