# Equalizer

An equalizer isn't music-specific code living in this package, it's `nomercy-player-core`'s shared `AudioGraphPlugin` + `EqualizerPlugin` pair, available to any player built on the kit. `nomercy-music-player` just makes them the plugin most listening apps reach for first.

## Registering the chain

`AudioGraphPlugin` owns the Web Audio signal chain, `AudioContext`, the media source node, and `insertEffect()`. `EqualizerPlugin` inserts itself into that chain and requires it to already be registered:

```ts
import nmplayer from '@nomercy-entertainment/nomercy-music-player';
import { AudioGraphPlugin, EqualizerPlugin } from '@nomercy-entertainment/nomercy-player-core';

const player = nmplayer('player-container');
player.addPlugin(AudioGraphPlugin);
player.addPlugin(EqualizerPlugin, { persistKey: 'my-app-eq' });
player.setup({
  baseUrl: 'https://raw.githubusercontent.com/NoMercy-Entertainment/nomercy-media/master/Music',
  playlist: [
    {
      id: 'ketsa-01-where-dreams-drift',
      name: 'Where Dreams Drift',
      artist: 'Ketsa',
      url: '/K/Ketsa/CC.BY.FREE.TO.USE.FOR.ANYTHING.(2025)/01.Where.Dreams.Drift.mp3',
    },
  ],
});
```

Both plugins register *before* `setup()`, so they install as part of the setup pipeline. That is the rule every plugin in the trio follows.

Register either one after `setup()` and its `use()` still runs, inline and fire-and-forget rather than inside that pass. Completion then surfaces through the `plugin:installed` event or `ready()`, not through `setup()` resolving.

`AudioElementBackend`, the default, creates the Web Audio source node the first time `AudioGraphPlugin` asks for it. So registering the equalizer neither forces `WebAudioBackend` nor costs anything on a player that never taps the graph.

## Driving it

```ts
const eq = player.getPlugin(EqualizerPlugin);
eq!.band(1000, 4); // +4 dB at 1 kHz
eq!.preset('Rock'); // one of 19 built-in presets
eq!.save(); // persists through the configured storage adapter, if persistKey was set
```

`band(freq, gain)` sets one band directly; `preset(name)` applies a named preset in one call. The full options table, event list, and persistence rules live on [Core: Plugin: Equalizer](/nomercy-player-core/plugins-adapters/equalizer), this page only covers what's specific to reaching for it from a music player.
