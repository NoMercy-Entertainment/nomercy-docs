# MessagePlugin

Cross-tab and cross-frame messaging. Direct re-export of the kit's `MessagePlugin` — no music-specific overrides.

```ts
import { MessagePlugin } from '@nomercy-entertainment/nomercy-music-player/plugins';
```

---

## Registration

```ts

```
