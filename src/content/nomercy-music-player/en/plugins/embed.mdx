# EmbedPlugin

Iframe embed and `postMessage` control surface. This is a direct re-export of the kit's `EmbedPlugin` — no music-specific overrides.

```ts
import { EmbedPlugin } from '@nomercy-entertainment/nomercy-music-player/plugins';
```

---

## Registration

```ts
player.addPlugin(EmbedPlugin);
```
