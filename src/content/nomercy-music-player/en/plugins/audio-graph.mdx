# AudioGraphPlugin

Establishes a `Web Audio API` graph rooted at the backend's `outputNode`. Required by `EqualizerPlugin` and any custom plugin that needs to insert audio processing nodes.

`AudioGraphPlugin` originates in `@nomercy-entertainment/nomercy-player-core` and is re-exported by the music package for ergonomic imports.

```ts
import { AudioGraphPlugin } from '@nomercy-entertainment/nomercy-music-player/plugins';
```

---

## Registration

Always register `AudioGraphPlugin` before `EqualizerPlugin` or any custom graph plugin:

```ts
import { AudioGraphPlugin, EqualizerPlugin } from '@nomercy-entertainment/nomercy-music-player/plugins';

const player = nmMPlayer('main')
  .addPlugin(AudioGraphPlugin)
  .addPlugin(EqualizerPlugin, { presets: myPresets })
  .setup({ playlist: myTracks });
```

---

## Requirements

`AudioGraphPlugin` requires `WebAudioBackend` or `AudioElementBackend` with a `MediaElementAudioSourceNode`. The backend's `audioContext()` must be available before the plugin's `use()` resolves.

On the default `audio-element` backend, the Web Audio graph is created lazily — it is only initialized when `AudioGraphPlugin` (or another plugin requesting `outputNode`) first activates.
