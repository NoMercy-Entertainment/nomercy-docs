# DrmPlugin

EME-based DRM for music streams. **Roadmapped for v2.1.** Calling `addPlugin(DrmPlugin)` followed by `setup()` will cause `use()` to throw `NotImplementedError`.

```ts
import { DrmPlugin } from '@nomercy-entertainment/nomercy-music-player/plugins';
```

---

## Planned options

interface DrmOptions {
