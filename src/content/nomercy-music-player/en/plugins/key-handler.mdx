# KeyHandlerPlugin

Music-specific keyboard handler. Inherits all kit defaults and adds music-specific bindings for track navigation, repeat, and shuffle.

```ts
import { KeyHandlerPlugin } from '@nomercy-entertainment/nomercy-music-player/plugins';
```

---

## Registration

```ts
const player = nmMPlayer('main').addPlugin(KeyHandlerPlugin).setup({ playlist: myTracks });
```

---

## Key bindings

| Key          | Action                               |
| ------------ | ------------------------------------ |
| `Space`      | Toggle play/pause                    |
| `ArrowRight` | Skip forward                         |
| `ArrowLeft`  | Skip backward                        |
| `ArrowUp`    | Volume up                            |
| `ArrowDown`  | Volume down                          |
| `m`          | Toggle mute                          |
| `n`          | Next track                           |
| `p`          | Previous track                       |
| `r`          | Cycle repeat (off → all → one → off) |
| `s`          | Toggle shuffle (on/off)              |

The kit's base bindings (space, arrows, m) are inherited from `BaseKeyHandler`. The music-specific keys (n, p, r, s) are added by this subclass.
