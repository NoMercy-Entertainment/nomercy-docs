# MusicUiPlugin

Plugin-driven transport UI overlay for `NMMusicPlayer`. Mounts a self-contained HTML overlay inside the kit-managed `.nomercymusicplayer` container. State classes on the container (`.playing`, `.paused`, `.muted`, `.buffering`) are applied by the kit automatically.

```ts
import { MusicUiPlugin } from '@nomercy-entertainment/nomercy-music-player/plugins';
```

---

## Registration

```ts
const player = nmMPlayer('main')
  .addPlugin(MusicUiPlugin)
  .setup({ playlist: myTracks });
```

With options:

```ts
player.addPlugin(MusicUiPlugin, {
  showAlbumArt: true,
  showTrackInfo: true,
  showProgress: true,
  showVolume: true,
  showShuffle: true,
  showRepeat: true,
  showSpeed: false,
  volumeSlider: 'auto',
});
```

---

## Options

```ts
interface MusicUiOptions {
  showAlbumArt?: boolean;
  showTrackInfo?: boolean;
  showProgress?: boolean;
  showVolume?: boolean;
  showShuffle?: boolean;
  showRepeat?: boolean;
  showSpeed?: boolean;
  volumeSlider?: 'horizontal' | 'vertical' | 'auto';
}
```

### `showAlbumArt`

Show the album art section. Default: `true`.

### `showTrackInfo`

Show the title / artist / album block. Default: `true`.

### `showProgress`

Show the progress / seek bar row with current time and duration. Default: `true`.

### `showVolume`

Show the volume button and slider. Default: `true`.

### `showShuffle`

Show the shuffle toggle button. Default: `true`.

### `showRepeat`

Show the repeat mode button. Default: `true`.

### `showSpeed`

Show the playback-speed button. Default: `false`.

### `volumeSlider`

Volume slider orientation:

- `'horizontal'` — always-visible inline slider
- `'vertical'` — popup slider above the mute button, toggle on click
- `'auto'` — vertical when width ≤ 520 px or on a touch-only device (default)

## DOM structure

```
.nmmusic-ui
  ├─ .nmmusic-art
  ├─ .nmmusic-track-info
  ├─ .nmmusic-progress-row
  │   ├─ .nmmusic-time.nmmusic-current-time
  │   ├─ .nmmusic-seek-bar [role=slider]
  │   │   ├─ .nmmusic-seek-buffer
  │   │   ├─ .nmmusic-seek-fill
  │   │   └─ .nmmusic-seek-thumb
  │   └─ .nmmusic-time.nmmusic-duration-time
  └─ .nmmusic-controls-row
      ├─ .nmmusic-btn[data-action=shuffle]
      ├─ .nmmusic-btn[data-action=previous]
      ├─ .nmmusic-btn.nmmusic-play-btn
      ├─ .nmmusic-btn[data-action=next]
      ├─ .nmmusic-btn[data-action=repeat]
      └─ .nmmusic-volume-group
```

Override the visual appearance via CSS targeting these class names. The plugin injects minimal default styles — you can override any property without specificity fights.

---

## Events

### `seek`

```ts
'plugin:music-ui:seek': { time: number }
```

Fires when the user drags or clicks the seek bar. `time` is the target position in seconds. The plugin calls `player.currentTime(time)` internally — this event is for observation only.

---

## Responsive priority

Controls collapse at narrow widths via CSS container queries:

| Priority | Controls |
|----------|----------|
| Always visible | Play/pause |
| Priority 2 | Previous, Next |
| Priority 3 | Shuffle, Repeat |
| Priority 4 | Volume |
