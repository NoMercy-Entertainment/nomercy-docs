# MusicUiPlugin

Plugin-driven transport UI overlay for `NMMusicPlayer`. Mounts a self-contained HTML overlay inside the kit-managed `.nomercymusicplayer` container. State classes on the container (`.playing`, `.paused`, `.muted`, `.buffering`) are applied by the kit automatically.

```ts
import { MusicUiPlugin } from '@nomercy-entertainment/nomercy-music-player/plugins';
```

Plugin id: `'music-ui'`

---

## Registration

```ts
const player = nmMPlayer('main').addPlugin(MusicUiPlugin).setup({ playlist: myTracks });
```

With options:

```ts
player.addPlugin(MusicUiPlugin, {
  showAlbumArt: true,
  showTrackInfo: true,
  showProgress: true,
  showVolume: true,
  showShuffle: true,
  showRepeat: true,
  showSpeed: false,
  volumeSlider: 'auto',
});
```

---

## Options

| Option | Type | Default | Description |
| ------ | ---- | ------- | ----------- |
| `showAlbumArt` | `boolean` | `true` | Show the album art section. |
| `showTrackInfo` | `boolean` | `true` | Show the title / artist / album block. |
| `showProgress` | `boolean` | `true` | Show the progress / seek bar row with current time and duration. |
| `showVolume` | `boolean` | `true` | Show the volume button and slider. |
| `showShuffle` | `boolean` | `true` | Show the shuffle toggle button. |
| `showRepeat` | `boolean` | `true` | Show the repeat mode button. |
| `showSpeed` | `boolean` | `false` | Show the playback-speed button. Most music listeners do not want speed control; opt in explicitly. |
| `volumeSlider` | `'horizontal' \| 'vertical' \| 'auto'` | `'auto'` | Volume slider orientation. `'horizontal'` — always-visible inline slider. `'vertical'` — popup slider above the mute button, toggled on click. `'auto'` — vertical when container width ≤ 520 px or on a touch-only device. |

## DOM structure

```
.nmmusic-ui
  ├─ .nmmusic-art
  │   ├─ img.nmmusic-art-img
  │   └─ .nmmusic-art-placeholder
  ├─ .nmmusic-track-info
  │   ├─ p.nmmusic-track-title
  │   ├─ p.nmmusic-track-artist
  │   └─ p.nmmusic-track-album
  ├─ .nmmusic-progress-row
  │   ├─ span.nmmusic-time.nmmusic-current-time
  │   ├─ .nmmusic-seek-bar [role=slider]
  │   │   ├─ .nmmusic-seek-buffer
  │   │   ├─ .nmmusic-seek-fill
  │   │   └─ .nmmusic-seek-thumb
  │   └─ span.nmmusic-time.nmmusic-duration-time
  └─ .nmmusic-controls-row
      ├─ .nmmusic-btn[data-action=shuffle]    (priority 3)
      ├─ .nmmusic-btn[data-action=previous]   (priority 2)
      ├─ .nmmusic-btn.nmmusic-play-btn
      ├─ .nmmusic-btn[data-action=next]       (priority 2)
      ├─ .nmmusic-btn[data-action=repeat]     (priority 3)
      ├─ .nmmusic-btn.nmmusic-speed-btn       (hidden unless showSpeed: true)
      └─ .nmmusic-volume-group
          ├─ .nmmusic-btn[data-action=mute]
          ├─ input.nmmusic-vol-slider
          └─ .nmmusic-vol-slider-vertical     (vertical mode popup)
              ├─ input.nmmusic-vol-slider-vertical-input
              └─ button.nmmusic-vol-popup-mute
```

Override the visual appearance via CSS targeting these class names. The plugin injects minimal default styles — you can override any property without specificity fights.

## Events

### `seek`

```ts
'plugin:music-ui:seek': { time: number }
```

Fires when the user drags or clicks the seek bar. `time` is the target position in seconds. The plugin calls `player.currentTime(time)` internally — this event is for observation only.

---

## Responsive priority

Controls collapse at narrow widths via CSS container queries (lower number = higher priority = visible longer):

| `data-priority` | Controls | Behaviour |
| --------------- | -------- | --------- |
| `0` (none) | Play/pause, mute | Always visible |
| `2` | Previous, Next | Hide at narrower widths |
| `3` | Shuffle, Repeat, Speed | Hide at narrowest widths |
