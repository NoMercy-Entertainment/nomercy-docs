# CastSenderPlugin

Music Chromecast sender. A thin specialisation of the kit's shared `CastSenderPlugin` that adapts music-specific fields (`name`, `artistTracks`, `albumTracks`, `cover`) to `MusicTrackMediaMetadata` and sets `'audio/mpeg'` as the default content type.

All Cast session lifecycle — SDK probe, session negotiation, `RemotePlayer` event mirroring, forward/rewind helpers, resume-on-disconnect — is handled by the kit base class.

```ts
import { CastSenderPlugin } from '@nomercy-entertainment/nomercy-music-player/plugins';
```

Plugin id: `'cast-sender'`

---

## Registration

```ts
const player = nmMPlayer('main').addPlugin(CastSenderPlugin).setup({ playlist: myTracks });
```

With options:

```ts
player.addPlugin(CastSenderPlugin, {
  chromecastAppId: 'MY_RECEIVER_APP_ID',
  resumeLocalOnDisconnect: true,
});
```

---

## Options

| Option | Type | Default | Description |
| ------ | ---- | ------- | ----------- |
| `chromecastAppId` | `string` | `undefined` | Chromecast receiver app id. When omitted, the Cast SDK uses the default media receiver. |
| `enableAirPlay` | `boolean` | `undefined` | Whether AirPlay is allowed (Safari only). |
| `customReceiverNamespace` | `string` | `undefined` | Custom receiver namespace for messages sent to the receiver. |
| `resumeLocalOnDisconnect` | `boolean` | `true` | Resume local playback after the receiver disconnects, restoring the receiver's last `currentTime` and play/pause state. |
| `defaultContentType` | `string` | `'audio/mpeg'` | Override the default MIME type sent to the Cast SDK. The music subclass defaults this to `'audio/mpeg'`. Override per-item by setting `contentType` on the playlist item. |
| `live` | `boolean` | `false` | Treat the source as a live (unbounded) stream. |

---

## Events

| Event | Payload | Description |
| ----- | ------- | ----------- |
| `cast:available` | `{ devices: number }` | The Cast SDK has detected at least one Chromecast device. |
| `cast:connecting` | `{ deviceName: string }` | A Cast session is being established. |
| `cast:connected` | `{ deviceName: string }` | A Cast session is active on the named device. |
| `cast:disconnected` | `void` | The Cast session ended. |
| `cast:error` | `{ error: Error }` | A Cast error occurred (e.g. session refused, network loss). |
| `cast:remote-state` | `{ time: number; state: 'playing' \| 'paused' \| 'buffering' }` | The receiver's playback state was mirrored to the local player. |
| `cast:media-changed` | `{ contentId: string }` | The receiver loaded a different media item. |
| `unsupported` | `{ reason: string }` | The Cast SDK is unavailable in this browser (Firefox, non-Chromium). |

Listen using the namespaced string form:

```ts
player.on('plugin:cast-sender:cast:connected', ({ deviceName }) => {
  showCastBadge(deviceName);
});
```

---

## Metadata mapping

| `MusicPlaylistItem` field | `MusicTrackMediaMetadata` field |
| ------------------------- | ------------------------------- |
| `name` | `title` |
| `artistTracks[].name` joined with `, ` | `artist` |
| `albumTracks[0].name` | `albumName` |
| `cover` (resolved via `resolveUrl`) | `images[0].url` |

When `MusicTrackMediaMetadata` is not available from the Cast SDK, the plugin falls back to `GenericMediaMetadata`.

## Example

```ts
import nmMPlayer from '@nomercy-entertainment/nomercy-music-player';
import {
  CastSenderPlugin,
  AutoAdvancePlugin,
  MediaSessionPlugin,
} from '@nomercy-entertainment/nomercy-music-player/plugins';

const player = nmMPlayer('main')
  .addPlugin(CastSenderPlugin, { resumeLocalOnDisconnect: true })
  .addPlugin(AutoAdvancePlugin)
  .addPlugin(MediaSessionPlugin)
  .setup({
    baseUrl: 'https://raw.githubusercontent.com/NoMercy-Entertainment/nomercy-media/master/Music',
    playlist: [
      {
        id: 'kjc-01',
        name: 'Thaw You Out',
        url: '/D/Derek%20Clegg/%5B2010%5D%20KJC/01%20Thaw%20You%20Out.mp3',
        cover: '/D/Derek%20Clegg/%5B2010%5D%20KJC/01%20Thaw%20You%20Out.jpg',
        artistTracks: [{ id: 1, name: 'Derek Clegg' }],
        albumTracks: [{ id: 1, name: 'KJC' }],
      },
    ],
  });

player.on('ready', () => {
  player.current(0, { autoplay: true });
});
```
