# AutoAdvancePlugin

Autonomous-advance plugin. Listens to the player's `ended` event to advance the queue, and to `trackEndingSoon` to optionally preload the next track and/or initiate a crossfade.

Do not register this plugin when your app drives the player from a WebSocket or Cast sync layer — let the orchestrator drive `next()` instead.

```ts
import { AutoAdvancePlugin } from '@nomercy-entertainment/nomercy-music-player/plugins';
```

---

## Registration

```ts
const player = nmMPlayer('main')
  .addPlugin(AutoAdvancePlugin)
  .setup({ playlist: myTracks });
```

With options:

```ts
player.addPlugin(AutoAdvancePlugin, {
  enabled: true,
  preloadNext: true,
  crossfade: true,
  crossfadeDuration: 5,
});
```

---

## Options

```ts
interface AutoAdvanceOptions {
  enabled?: boolean;
  preloadNext?: boolean;
  crossfade?: boolean;
  crossfadeDuration?: number;
}
```

### `enabled`

Master toggle. Default: `true`. Set to `false` to pause all auto-advance behavior without removing the plugin.

### `preloadNext`

When `true`, the plugin calls `player.load(next, { slot: 'next' })` on the `trackEndingSoon` event. This buffers the next track before it is needed. Default: `false`.

### `crossfade`

When `true`, the plugin calls `player.crossfadeTo(next, { duration: crossfadeDuration })` on the `trackEndingSoon` event. Default: `false`.

### `crossfadeDuration`

Crossfade duration **in seconds** used when `crossfade: true`. Default: `0` (instant cut).

Set this to match or be less than `trackEndingSoonThreshold` from the player config.

---

## Methods

### `advance()`

```ts
advance(): Promise<void>
```

Force-advance to the next track immediately, regardless of playback state. Calls `player.next({ source: 'auto-advance' })`.

### `preloadNext()`

```ts
preloadNext(): Promise<void>
```

Peek the queue head and load it into the next slot. No-ops when there is no next track. Safe to call at any time.

### `addEndedHandler(fn)`

```ts
addEndedHandler(fn: () => void | Promise<void>): void
```

Register an additional callback that runs after the built-in `ended` advance logic. Use for analytics, logging, or server sync that should follow the queue advance.

### `addPreloadHandler(fn)`

```ts
addPreloadHandler(fn: (next: MusicPlaylistItem | undefined) => void | Promise<void>): void
```

Register an additional `trackEndingSoon` handler for preload behavior. `next` is the upcoming track or `undefined` when the queue is exhausted.

### `addCrossfadeHandler(fn)`

```ts
addCrossfadeHandler(fn: (next: MusicPlaylistItem | undefined, duration: number) => void | Promise<void>): void
```

Register an additional `trackEndingSoon` handler for crossfade behavior. `duration` is the resolved `crossfadeDuration` in seconds.

---

## Execution order

When `trackEndingSoon` fires:

1. If `preloadNext: true` — calls `preloadNext()`
2. If `crossfade: true` and there is a next track — calls `crossfadeTo(next, { duration })`
3. All registered `preloadHandlers` run
4. All registered `crossfadeHandlers` run

When `ended` fires:

1. Calls `player.next({ source: 'auto-advance' })`
2. All registered `endedHandlers` run

## Example

```ts
import nmMPlayer from '@nomercy-entertainment/nomercy-music-player';
import { AutoAdvancePlugin } from '@nomercy-entertainment/nomercy-music-player/plugins';

const BASE = 'https://raw.githubusercontent.com/NoMercy-Entertainment/nomercy-media/master/Music';
const D = `${BASE}/D/Derek%20Clegg/%5B2010%5D%20KJC`;

const player = nmMPlayer('main')
  .addPlugin(AutoAdvancePlugin, {
    crossfade: true,
    crossfadeDuration: 5,
    preloadNext: true,
  })
  .setup({
    trackEndingSoonThreshold: 8,
    crossfadeDefaults: { duration: 5, curve: 'equal-power' },
    playlist: [
      {
        id: 'kjc-01',
        name: 'Thaw You Out',
        url: `${D}/01%20Thaw%20You%20Out.mp3`,
        artist_track: [{ id: 1, name: 'Derek Clegg' }],
      },
      {
        id: 'kjc-02',
        name: 'Hope',
        url: `${D}/02%20Hope.mp3`,
        artist_track: [{ id: 1, name: 'Derek Clegg' }],
      },
    ],
  });

// Analytics hook:
const plugin = player.getPlugin(AutoAdvancePlugin)!;
plugin.addEndedHandler(() => {
  analytics.track('track_completed', { id: player.current()?.id });
});

player.on('ready', () => {
  player.current(0, { autoplay: true });
});
```
