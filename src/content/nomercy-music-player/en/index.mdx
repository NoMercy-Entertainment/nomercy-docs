# nomercy-music-player

`nomercy-music-player` is the headless audio engine that powers music on NoMercy TV.
The tricky part of a music player is the gap between two tracks, and this engine is built around getting it right: sample-accurate crossfade on the Web Audio backend, or a gapless hand-off when you want one track to run straight into the next.
Lyric sync and a full EQ chain are here too.
The generic parts, the queue, auth, plugins, i18n, and storage, live in `nomercy-player-core` underneath, so this package stays focused on what makes audio hard.
You bring your own UI and wire it to plain events and methods.

## What you get

- `NMMusicPlayer<T>`, the core class, generic over your own track type.
- `nmMPlayer(id)`, a factory that creates or returns a named player instance.
- Six music-specific adapter ports (audio backend, playlist generator, scrobbler, lyric source, similarity engine, now-playing art).
- Twelve built-in plugins, plus the audio-graph family (equalizer, spectrum, visualizers) re-exported from core.
- Full TypeScript types for all public methods, events, and configuration.

## Plugins

These are the built-in plugins shipped with `nomercy-music-player`.
Add the ones you want with `player.addPlugin(PluginClass)` and your bundler drops the rest.

| Plugin                  | Purpose                                             |
| ----------------------- | --------------------------------------------------- |
| `AutoAdvancePlugin`     | Advance queue automatically when a track ends       |
| `MediaSessionPlugin`    | Wire lock screen and notification media controls    |
| `LyricsPlugin`          | Sync LRC/VTT lyrics to playback time                |
| `MusicUiPlugin`         | Built-in music player UI                            |
| `MessagePlugin`         | Toast and overlay-message surface                   |
| `KeyHandlerPlugin`      | Keyboard shortcut handling                          |
| `CastSenderPlugin`      | Chromecast handoff                                  |
| `EmbedPlugin`           | postMessage bridge for iframe embeds                |
| `TabLeaderPlugin`       | Single-tab leader election for multi-tab sync       |
| `DrmPlugin`             | DRM/EME support (planned)                           |
| `LiveTranscodingPlugin` | Live transcode from NoMercy server (planned)        |
| `GroupListeningPlugin`  | Synchronized group listening session (planned)      |

The audio-graph plugins (`AudioGraphPlugin`, `CanvasPlugin`, `EqualizerPlugin`, `MixerPlugin`, `SpectrumPlugin`, `VisualizationPlugin`) are re-exported from core for EQ and visualization.
`EqualizerPlugin` and the visualizers require `AudioGraphPlugin`.
See [Audio Graph](/nomercy-music-player/plugins/audio-graph).

For building your own, see [Writing your own plugins](/nomercy-music-player/plugin-development).

Everything below `NMMusicPlayer<T>` is generic, with zero knowledge of your server API, your track shape beyond the typed fields, or any NoMercy infrastructure.
App-specific glue lives in layer-5 consumer plugins.
