# Reference: Music Player Methods

`NMMusicPlayer<T>` implements `IMusicPlayer<T>`, which extends the kit's `IPlayer<MusicEventMap<T>>`. Everything on `IPlayer` (`play()`, `pause()`, `time()`, `volume()`, `queue()`, `addPlugin()`, and the rest of transport, queue, volume, and plugin management) is unchanged kit surface, documented method by method across the [Guided Tour](/nomercy-music-player/tour/transport) rather than duplicated here. This page is the delta: everything that exists, or behaves differently, because the medium is listening.

## Backend & crossfade

| Method | Signature | Notes |
|---|---|---|
| `backend()` | `() => IAudioBackend` | The active backend instance, constructed lazily on first call. See [Adapter: Audio Backend](/nomercy-music-player/plugins-adapters/adapter-audio-backend). |
| `backend(kind)` | `(kind: AudioBackendKind) => Promise<void>` | Swaps backends at runtime (`'audio-element'` / `'webaudio'`), disposing the previous one and emitting `'backend:changed'`. |
| `crossfadeTo(item, opts?)` | `(item: T, opts?: CrossfadeOptions & ActionOptions) => Promise<void>` | Fades the current track out while `item` fades in. Ignored (no-op) while another crossfade is already in flight. See [Crossfade](/nomercy-music-player/tour/crossfade). |
| `isTransitioning()` | `() => boolean` | Whether a `crossfadeTo()` is currently in flight. |
| `setTransitionStrategy(strategy)` | `(strategy: ITransitionStrategy) => void` | Swaps the transition strategy driving the automatic queue-boundary transition (crossfade / gapless / cut) at runtime. `setup()` builds the default from `crossfadeEnabled` / `crossfadeDefaults`, see [Recipe: Crossfade & Gapless Playback](/nomercy-music-player/recipes/crossfade-gapless). |

## Item cursor & queue

`IPlayer` itself is item-type-agnostic. `IMusicPlayer` redeclares `item()`, `queue()`, `peekNext()`, and `peekPrevious()` against the concrete `T` instead (mirroring `IVideoPlayer`), same required behavior as the kit surface, just typed to the music item shape rather than the base one:

| Method | Signature | Notes |
|---|---|---|
| `item()` | `() => T \| undefined` | The current queue item. |
| `item(target, opts?)` | `(target: T \| string \| number, opts?: LoadOptions) => void` | Load an item by reference, id, or index. |
| `queue()` | `() => ReadonlyArray<T>` | Current items as a read-only array. |
| `queue(items, opts?)` | `(items: T[], opts?: ActionOptions) => void` | Replace queue contents. |
| `peekNext()` | `() => T \| undefined` | What `next()` would load, without moving the cursor. |
| `peekPrevious()` | `() => T \| undefined` | What `previous()` would load, without moving the cursor. |

Together with backend access, crossfade, and the transition strategy swap above, this is the entire music-owned method surface, not inherited or shared with `nomercy-video-player`.

## Audio output

| Method | Signature | Notes |
|---|---|---|
| `audioOutputs()` | `() => Promise<MediaDeviceInfo[]>` | Enumerates output devices, no permission prompt. Labels may be empty without a prior permission grant. |
| `selectAudioOutput()` | `() => Promise<MediaDeviceInfo \| null>` | Opens the browser's native output picker. Chrome ≥105 only, throws `BrowserPolicyError` elsewhere. `null` if the user cancels. |
| `audioOutput()` / `audioOutput(deviceId)` | `() => Promise<string \| null>`, `(deviceId: string) => Promise<void>` | Reads the current device id (`null` = system default) / routes playback to `deviceId` via `setSinkId()`. |

See [Audio Output Devices](/nomercy-music-player/tour/audio-output) and [Recipe: Audio Output Switching](/nomercy-music-player/recipes/audio-output-switching).

## Track, quality & chapter selection

Shared kit mixin surface, narrowed to the required, audio-relevant shape here (embedded audio tracks in a multi-track file, adaptive-bitrate quality levels for an HLS audio stream, and chapters for an audiobook or podcast all apply to listening just as they do to watching):

| Method | Signature | Notes |
|---|---|---|
| `audioTracks()` | `() => ReadonlyArray<AudioTrack>` | Embedded audio rendition list (alternate language commentary, for instance). |
| `audioTrack()` / `audioTrack(idx)` | `() => CurrentAudioTrackSelection \| null`, `(idx: number) => Promise<void>` | |
| `qualityLevels()` / `qualityLevels({ includeUnsupported: true })` | `() => ReadonlyArray<QualityLevel>` | Populated once the stream's manifest is parsed, for an adaptive-bitrate audio source. |
| `quality()` / `quality(idx)` | `() => CurrentQualitySelection \| 'auto'`, `(idx: number \| 'auto') => void` | |
| `chapters()` | `() => ReadonlyArray<Chapter>` | From the item's typed `chapters` field, an audiobook or podcast episode's chapter marks. |
| `chapter()` / `chapter(idx)` | `() => Chapter \| null`, `(idx: number) => void` | |
| `seekToChapter(idx, opts?)` / `nextChapter(opts?)` / `previousChapter(opts?)` | `(idx: number, opts?: ActionOptions) => void` | |

## Coming from v1

Method names that were removed or renamed in v2 are not part of the `IMusicPlayer` surface above. To move a v1 app across without rewriting every call at once, see [Migrating from v1](/nomercy-music-player/recipes/migrate-from-v1).
