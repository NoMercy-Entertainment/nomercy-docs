# Custom Plugin (Music)

<Callout type="info">
  This page is being written. The authoritative plugin authoring guide lives at [Plugin Authoring](/nomercy-player-kit/plugin-authoring) in the kit docs. This page covers the music-player-specific additions only.
</Callout>

The kit's `Plugin<TPlayer, TEventMap, TOpts>` base class is the same for both video and music. This page documents what is different when writing a plugin that targets the music player: `IAudioBackend` access, `MusicEventMap` extension, and the `crossfadeTo`/`isTransitioning` surface available inside music-player callbacks.

See [Plugin Authoring](/nomercy-player-kit/plugin-authoring) for the base class, lifecycle hooks, `requires`, `replaces`, and `minCoreVersion`.
