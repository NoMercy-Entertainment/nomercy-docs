# Plugin: Lyrics

`LyricsPlugin` (id `'lyrics'`) wires a track's synced lyrics to the kit's generic cue machinery.

On every `item` change, the plugin runs its pipeline:

1. Resolves a lyrics URL.
2. Fetches it through the auth-aware fetch.
3. Parses it with `resolveCueParser(url)`.
4. Attaches a `CueTracker` that fires as playback crosses each line's window.

[Lyrics](/nomercy-music-player/tour/lyrics) is the walkthrough. [Recipe: Synced Lyrics UI](/nomercy-music-player/recipes/lyrics-sync) builds a scrolling panel.

## Options

| Option | Type | Default | Purpose |
|---|---|---|---|
| `getLyricsUrl` | `(item: MusicPlaylistItem) => string \| undefined` | reads `item.lyricsUrl` | Custom resolver, for a catalogue that derives the lyrics URL rather than storing it directly on the item. |
| `autoFetch` | `boolean` | `true` | Auto-fetch on the `item` event. Set `false` to drive fetching entirely through the explicit `fetchLyrics(url)` method instead. |

## Events

Namespaced onto the player's own bus as `plugin:lyrics:<event>`:

| Event | Payload | Fires when |
|---|---|---|
| `loaded` | `{ count }` | The cue list is fetched, parsed, and the tracker is attached. `count` is the number of lines. |
| `line` | `{ text, ...rest }` | Same payload and timing as `lineEnter`, kept as an alias for a listener that doesn't need the enter/exit distinction. |
| `lineEnter` | `{ text, ...rest }` | A line's timing window starts. |
| `lineExit` | `{ text, ...rest }` | A line's timing window ends. |

## Methods

| Method | Signature | Purpose |
|---|---|---|
| `current()` | `() => LyricPayload \| undefined` | The active line's payload, `undefined` between lines. |
| `all()` | `() => ReadonlyArray<Cue<LyricPayload>>` | Every parsed cue for the current track, empty if none loaded. |
| `clear()` | `() => void` | Tear down the active tracker without disposing the plugin. |
| `fetchLyrics(url)` | `(url: string) => Promise<CueList<LyricPayload> \| undefined>` | Explicit fetch, takes precedence over auto-fetch, resolves once attached. |

## Rules & restrictions

- `item.lyricsUrl` is fetched exactly as given. It is **not** resolved against `baseUrl` the way `item.url` is. Store a fully-qualified URL, or resolve it yourself in a `getLyricsUrl` override. See [Lyrics: lyricsUrl isn't resolved against baseUrl](/nomercy-music-player/tour/lyrics#lyricsurl-isnt-resolved-against-baseurl).
- A missing `item.lyricsUrl`, with no `getLyricsUrl` resolver returning one, clears plugin state quietly. No fetch, no error.

- A fetch or parse failure reports through the plugin's error channel, `plugin:lyrics/no-parser` or `plugin:lyrics/fetch-failed`, rather than throwing. A bad lyrics file never interrupts playback.
- Parsing needs a cue parser registered for that URL's format. A `.lrc` file resolves to the built-in parser. A custom format needs its own `ICueParser` registered first, through `player.registerCueParser()`. See [Core: Cue Parsers](/nomercy-player-core/tour/cue-parsers).
- Add it before `setup()`, like any plugin, so `use()` runs inside the pipeline and the `item` listener is wired before the first track primes.

- Added after `ready()`, `use()` still runs, inline and fire-and-forget. But the `item` listener attaches too late for the loaded track, so lyrics start on the next `item` change or an explicit `fetchLyrics(url)`.

## How to extend it

`LyricsPlugin` isn't designed for subclassing. Its surface is small enough that most customization goes through `opts.getLyricsUrl`, which lets you route to a different sidecar location or format. You can also register an additional `ICueParser` for a lyrics format the kit doesn't parse out of the box:

```ts
import nmplayer from '@nomercy-entertainment/nomercy-music-player';
import { LyricsPlugin } from '@nomercy-entertainment/nomercy-music-player/plugins/lyrics';

const player = nmplayer('player');
player.addPlugin(LyricsPlugin, {
  getLyricsUrl: item => item.lyricsUrl ?? `https://lyrics.example.com/${item.id}.lrc`,
});
player.setup({
  baseUrl: 'https://raw.githubusercontent.com/NoMercy-Entertainment/nomercy-media/master/Music',
  playlist: [
    {
      id: 'ketsa-01-where-dreams-drift',
      name: 'Where Dreams Drift',
      artist: 'Ketsa',
      url: '/K/Ketsa/CC.BY.FREE.TO.USE.FOR.ANYTHING.(2025)/01.Where.Dreams.Drift.mp3',
      lyricsUrl:
        'https://raw.githubusercontent.com/NoMercy-Entertainment/nomercy-media/master/Music/K/Ketsa/CC.BY.FREE.TO.USE.FOR.ANYTHING.(2025)/01.Where.Dreams.Drift.lrc',
    },
  ],
});
```
