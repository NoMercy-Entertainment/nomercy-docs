# Plugin: Media Session

`MediaSessionPlugin` (id `'media-session'`) is a one-method specialization of the kit's [`MediaSessionPlugin`](/nomercy-player-core/plugins-adapters/media-session). The base plugin owns the actual `navigator.mediaSession` wiring:

- Action handlers: `play`, `pause`, `stop`, `previoustrack`, `nexttrack`, `seekbackward`, `seekforward`, `seekto`.
- Position-state sync.
- Artwork resolution through `resolveUrl(url, 'poster')`.

This subclass only overrides `getMetadata()`, how a `MusicPlaylistItem` becomes the OS lock-screen and notification text.

## What the music subclass builds

| MediaSession field | Music source |
|---|---|
| `title` | `item.name` (empty string when unset). |
| `artist` | `item.artist` (empty string when unset). |
| `album` | `item.album` (empty string when unset). |

Artwork comes from the kit base class's shared image priority: `image` → `poster` → `thumbnail` → `cover`.

For music, `item.image` wins when set, and `item.cover` is the fallback. The two middle fields never apply, because `poster` and `thumbnail` are video-only and a `MusicPlaylistItem` does not declare them.

The plugin resolves artwork through the same `resolveUrl` pipeline as every other image on the item. There is nothing music-specific to configure.

## Rules & restrictions

- Reads only fields defined on the canonical `MusicPlaylistItem`. Consumers carrying server-specific fields, such as linked artist/album entities instead of plain strings, should subclass and override `getMetadata()` themselves. Do not expect this built-in to read fields it isn't typed against. The kit deliberately avoids casting to a richer intersection type inside its own built-ins.
- Everything else is identical to the kit base: browser support detection, action handler wiring, and position-state sync. See [Plugin: Media Session (core)](/nomercy-player-core/plugins-adapters/media-session) for options and events.

## How to extend it

```ts
import nmplayer from '@nomercy-entertainment/nomercy-music-player';
import { MediaSessionPlugin } from '@nomercy-entertainment/nomercy-music-player/plugins/media-session';

const player = nmplayer('player');

class MyMediaSessionPlugin extends MediaSessionPlugin {
  protected override getMetadata(item) {
    const base = super.getMetadata(item);
    return {
      ...base,
      artist: item.featuredArtists?.length ? `${base.artist} feat. ${item.featuredArtists.join(', ')}` : base.artist,
    };
  }
}

player.addPlugin(MyMediaSessionPlugin);
```
