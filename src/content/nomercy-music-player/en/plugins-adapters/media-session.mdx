# Plugin: Media Session

## Purpose

`MediaSessionPlugin` (id `'media-session'`) feeds a track's title, artist, and album into the OS "Now Playing" surface: lock-screen controls, hardware media keys, Bluetooth remotes. It is a one-method specialization of the kit's [`MediaSessionPlugin`](/nomercy-player-core/plugins-adapters/media-session), which owns the actual `navigator.mediaSession` wiring. This subclass only overrides `getMetadata()`, how a `MusicPlaylistItem` becomes the lock-screen text.

## Using it

```ts
import nmplayer from '@nomercy-entertainment/nomercy-music-player';
import { MediaSessionPlugin } from '@nomercy-entertainment/nomercy-music-player/plugins/media-session';

const player = nmplayer('player');

player.addPlugin(MediaSessionPlugin);
await player.ready();
```

Subclass and override `getMetadata()` for fields beyond the canonical item, such as linked artist entities instead of plain strings:

```ts
class MyMediaSessionPlugin extends MediaSessionPlugin {
	protected override getMetadata(item) {
		const base = super.getMetadata(item);
		return {
			...base,
			artist: item.featuredArtists?.length ? `${base.artist} feat. ${item.featuredArtists.join(', ')}` : base.artist,
		};
	}
}

player.addPlugin(MyMediaSessionPlugin);
```

## Reference

`getMetadata()` builds:

| MediaSession field | Music source |
|---|---|
| `title` | `item.name` (empty string when unset). |
| `artist` | `item.artist` (empty string when unset). |
| `album` | `item.album` (empty string when unset). |

Artwork uses the kit base class's shared priority (`image` → `poster` → `thumbnail` → `cover`). For a `MusicPlaylistItem`, `poster` and `thumbnail` are never set (they are video-only fields), so `item.image` wins when set and `item.cover` is the fallback. See [Plugin: Media Session (core)](/nomercy-player-core/plugins-adapters/media-session) for options, events, action handlers, and the full artwork chain.
