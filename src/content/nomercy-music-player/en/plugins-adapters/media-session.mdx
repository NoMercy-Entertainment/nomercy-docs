# Plugin: Media Session

## Purpose

`cls MediaSessionPlugin` (id `str media-session`) feeds a track's title, artist and album into the OS "Now Playing" surface: lock-screen controls, hardware media keys, Bluetooth remotes. It is a one-method specialization of the kit's [`cls MediaSessionPlugin`](/nomercy-player-core/plugins-adapters/media-session), which owns the `ts navigator.mediaSession` wiring. This subclass overrides `fn getMetadata`, which is how a `cls MusicPlaylistItem` becomes the lock-screen text.

## Using it

```ts
import nmplayer from '@nomercy-entertainment/nomercy-music-player';
import { MediaSessionPlugin } from '@nomercy-entertainment/nomercy-music-player/plugins/media-session';

const player = nmplayer('player');

player.addPlugin(MediaSessionPlugin);
player.setup({
  baseUrl: 'https://raw.githubusercontent.com/NoMercy-Entertainment/nomercy-media/master/Music',
  playlist: [
    {
      id: 'ketsa-01-where-dreams-drift',
      name: 'Where Dreams Drift',
      artist: 'Ketsa',
      url: '/K/Ketsa/CC.BY.FREE.TO.USE.FOR.ANYTHING.(2025)/01.Where.Dreams.Drift.mp3',
    },
  ],
});
await player.ready();
```

**Start playback and the track name appears on the lock screen**, with the transport buttons there driving the player.

Subclass and override `fn getMetadata` for fields beyond the canonical item, such as a featured-artist list rather than one plain string:

```ts
import type { MusicPlaylistItem } from '@nomercy-entertainment/nomercy-music-player';

interface FeaturedTrack extends MusicPlaylistItem {
  featuredArtists?: string[];
}

class FeaturedMediaSession extends MediaSessionPlugin<FeaturedTrack> {
  protected override getMetadata(item: FeaturedTrack) {
    const base = super.getMetadata(item);
    const featured = item.featuredArtists ?? [];

    if (featured.length === 0) return base;

    return { ...base, artist: `${base.artist} feat. ${featured.join(', ')}` };
  }
}

player.addPlugin(FeaturedMediaSession);
```

## Reference

`fn getMetadata` builds three text fields, and nothing else:

| Now Playing field | Read from |
|---|---|
| `key title` | `key name`, or an empty string when the field is absent |
| `key artist` | `key artist`, or an empty string when the field is absent |
| `key album` | `key album`, or an empty string when the field is absent |

Artwork is the kit base class's job, and it walks `key image`, then `key poster`, then `key thumbnail`, then `key cover`. A music item normally carries only the first and the last, so `key image` wins and `key cover` is the fallback.

That walk stops on the first field that is present rather than the first field that holds a URL. An item with `key image` set to an empty string publishes no artwork at all, even with a real `key cover` beside it, so leave a field out rather than blanking it.

See [Plugin: Media Session (core)](/nomercy-player-core/plugins-adapters/media-session) for options, events, action handlers and the rest of the surface.
