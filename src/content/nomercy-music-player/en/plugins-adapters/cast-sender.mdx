# Plugin: Cast Sender

## Purpose

`CastSenderPlugin` (id `'cast-sender'`) sends a track to a Chromecast receiver: session lifecycle, remote-state mirroring, and resume-on-disconnect. It is a two-method specialization of the kit's [`CastSenderPlugin`](/nomercy-player-core/plugins-adapters/cast-sender). This subclass supplies only the two things that differ per medium: the default MIME type, and how a `MusicPlaylistItem` becomes Cast metadata.

## Using it

```ts
import nmplayer from '@nomercy-entertainment/nomercy-music-player';
import { CastSenderPlugin } from '@nomercy-entertainment/nomercy-music-player/plugins/cast-sender';

const player = nmplayer('player');

player.addPlugin(CastSenderPlugin, { chromecastAppId: 'ABCD1234' });
await player.ready();

await player.getPlugin(CastSenderPlugin)?.connect();
```

Subclass and override `buildMetadata()` when your items carry fields beyond the canonical `MusicPlaylistItem`, such as linked artist/album entities instead of plain strings:

```ts
class MyCastSenderPlugin extends CastSenderPlugin {
	protected override async buildMetadata(item, ctors) {
		const meta = await super.buildMetadata(item, ctors);
		// add app-specific fields on top of the canonical set super() already built
		return meta;
	}
}
```

## Reference

`defaultContentType` defaults to `'audio/mpeg'` here, unless you override it explicitly.

`buildMetadata(item, ctors)` reads only fields already on the canonical `MusicPlaylistItem`, building a `MusicTrackMediaMetadata` (falls back to `GenericMediaMetadata` if the SDK build lacks the music-track constructor):

| Item field | Metadata field |
|---|---|
| `item.name` | `title` |
| `item.artist` (if set) | `artist` |
| `item.album` (if set) | `albumName` |
| `item.image` (falls back to the deprecated `item.cover`) | Resolved through `resolveUrl(item.image ?? item.cover, 'poster')` and set as `images`. |

Options, events, browser restrictions, the volume conversion, and the `transferTo('cast')` boundary are unchanged from the kit. See [Plugin: Cast Sender (core)](/nomercy-player-core/plugins-adapters/cast-sender) for the full surface, including the translation auto-discovery this plugin's own `i18n/` folder plugs into.
