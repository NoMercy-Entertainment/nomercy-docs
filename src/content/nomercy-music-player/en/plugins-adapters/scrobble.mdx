# Plugin: Scrobble

`ScrobblePlugin` (id `'scrobble'`) tracks listened time per track, against the player's own `item`, `time` and `ended` events.

It reports to a configured {`IScrobbler`} backend: `nowPlaying(item)` once per item on cursor change, and `scrobble(item, context)` once accumulated listened time crosses a threshold.

The default scrobbler is a no-op, so the plugin is inert until a real backend is wired in. Time is tracked and never reported. [Recipe: Scrobbling](/nomercy-music-player/recipes/scrobbling) implements one.

## Options

| Option | Type | Default | Purpose |
|---|---|---|---|
| `scrobbler` | `IScrobbler<MusicPlaylistItem>` | `NoopScrobbler` | The reporting backend. |
| `thresholdRatio` | `number` | `0.5` | Fraction of the track's duration counted as "listened enough" — Last.fm's 50% rule. |
| `thresholdSeconds` | `number` | `240` | Absolute listened-seconds ceiling. Whichever of this or `thresholdRatio` is reached first wins — Last.fm's 4-minute rule. |
| `minDurationSeconds` | `number` | `30` | Tracks shorter than this are never scrobbled. |

## Events

Namespaced onto the player's own bus as `plugin:scrobble:<event>`:

| Event | Payload | Fires when |
|---|---|---|
| `nowPlaying` | `{ item }` | Right after `IScrobbler.nowPlaying()` resolves, once per item. |
| `scrobbled` | `{ item, listenedSeconds }` | Right after `IScrobbler.scrobble()` resolves, once per item, the first time the threshold is crossed. |

## The IScrobbler port

```ts
interface IScrobbler<T extends BasePlaylistItem = BasePlaylistItem> {
  readonly id: string;
  scrobble(item: T, context: ScrobbleContext): Promise<void>;
  nowPlaying?(item: T): Promise<void>;
}

interface ScrobbleContext {
  startedAt: number;        // Unix timestamp (seconds) playback started
  listenedSeconds: number;  // total seconds actually listened, seeks excluded
  durationSeconds: number;  // total item duration
  source: 'user' | 'auto' | 'radio';
}
```

`nowPlaying` is optional, a backend with no "currently listening" concept can omit it. `NoopScrobbler`, the shipped default, implements both as immediately-resolving no-ops.

## How listened time is tracked

A normal playback tick advances the `time` event by well under a second; anything ≥2 seconds between ticks is treated as a seek or a track change and doesn't count toward listened time. This means scrubbing back and forth through a track doesn't inflate the listened total the way naively summing every `time` delta would.

## Methods

`ScrobblePlugin` exposes the tracked state read-only, for a UI that wants to show elapsed listened time or badge a track as scrobbled without waiting on the plugin's own events:

| Method | Signature | Notes |
|---|---|---|
| `listened()` | `() => number` | Seconds of listened time accumulated for the current item so far, the same running total `scrobble()` is checked against once it crosses the threshold. |
| `isScrobbled()` | `() => boolean` | Whether the current item already crossed the scrobble threshold. Latches `true` for the rest of that item's playback. |

```ts
const scrobble = player.getPlugin(ScrobblePlugin);
console.log(scrobble?.listened(), scrobble?.isScrobbled());
```

## Rules & restrictions

- A failed `scrobble()` or `nowPlaying()` never interrupts playback. The plugin catches the rejection and reports it through its own error channel, `plugin:scrobble/scrobble-failed` or `plugin:scrobble/now-playing-failed`.
- Once a track is scrobbled it stays scrobbled. `isScrobbled()` latches `true` for the rest of that item's playback, so replaying it without advancing does not scrobble again.
- Tracking resets on every `item` change, including a mid-track `crossfadeTo()`. Listened time never carries across tracks.

## How to extend it

Implement `IScrobbler` against a real service and pass it as `opts.scrobbler`:

```ts
import nmplayer from '@nomercy-entertainment/nomercy-music-player';
import { ScrobblePlugin } from '@nomercy-entertainment/nomercy-music-player/plugins/scrobble';

const player = nmplayer('player');
player.addPlugin(ScrobblePlugin, {
  scrobbler: new MyLastFmScrobbler(sessionKey),
});
player.setup({
  baseUrl: 'https://raw.githubusercontent.com/NoMercy-Entertainment/nomercy-media/master/Music',
  playlist: [
    {
      id: 'ketsa-01-where-dreams-drift',
      name: 'Where Dreams Drift',
      artist: 'Ketsa',
      url: '/K/Ketsa/CC.BY.FREE.TO.USE.FOR.ANYTHING.(2025)/01.Where.Dreams.Drift.mp3',
    },
  ],
});
```
