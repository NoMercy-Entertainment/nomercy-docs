# Plugin: Key Handler

## Purpose

`cls KeyHandlerPlugin` (id `str key-handler`) is the music player's keyboard-binding set. It is a thin subclass of the kit's [`cls KeyHandlerPlugin`](/nomercy-player-core/plugins-adapters/key-handler), which owns scope resolution, the cooldown, input-field awareness and `fn bind`, `fn unbind` and `fn replace`. It inherits every kit default unchanged and overrides one method, `fn addMediaKeys`, to add four listening bindings.

## Using it

```ts
import nmplayer from '@nomercy-entertainment/nomercy-music-player';
import { KeyHandlerPlugin } from '@nomercy-entertainment/nomercy-music-player/plugins/key-handler';

const player = nmplayer('player');

player.addPlugin(KeyHandlerPlugin);
player.setup({
  baseUrl: 'https://raw.githubusercontent.com/NoMercy-Entertainment/nomercy-media/master/Music',
  playlist: [
    {
      id: 'ketsa-01-where-dreams-drift',
      name: 'Where Dreams Drift',
      artist: 'Ketsa',
      url: '/K/Ketsa/CC.BY.FREE.TO.USE.FOR.ANYTHING.(2025)/01.Where.Dreams.Drift.mp3',
    },
  ],
});
await player.ready();
```

**Press `n` and the queue moves to the next track.** Register the plugin before `fn setup`, and await `fn ready` before you expect a key to reach the player.

Add your own bindings on top of the inherited ones by calling `super` first:

```ts
class StudioKeyHandler extends KeyHandlerPlugin {
  protected override addMediaKeys(): void {
    super.addMediaKeys();
    this.bind('l', () => {
      this.player.forward?.(15);
    });
  }
}

player.addPlugin(StudioKeyHandler);
```

Leave out that `super` call and you drop the kit's hardware media keys as well as the four below, because they are installed by the same method.

## Reference

This subclass adds no option fields. See [Plugin: Key Handler (core)](/nomercy-player-core/plugins-adapters/key-handler) for `key scope`, `key bindings`, `key extend`, `key when`, `key cooldownMs` and `key disableMediaControls`.

Inherited from the kit, unchanged:

| Key | Action |
|---|---|
| the space bar | Toggle playback. The binding is registered under `str ' '`, the value a browser puts on `key key`, so a rebinding of your own spells it the same way rather than `str Space`. |
| `str ArrowLeft` and `str ArrowRight` | Seek back and forward five seconds. |
| `str ArrowUp` and `str ArrowDown` | Raise and lower the volume one step. |
| `str m` | Toggle mute. |
| the `str Media*` keys | Play, pause, stop, seek and track change from a physical media key, a headphone control or a remote. |

Added by this subclass:

| Key | Action |
|---|---|
| `str n` | Next item. |
| `str p` | Previous item. |
| `str r` | Cycle the repeat state: off, then all, then one, then off. |
| `str s` | Toggle shuffle. |

`key disableMediaControls` silences the hardware `str Media*` keys only. These four keep firing.

`str r` and `str s` call `fn repeatState` and `fn shuffleState` on the player, so they move the same state a repeat or shuffle button in your own UI reads. There is no separate key-handler state to keep in step.
