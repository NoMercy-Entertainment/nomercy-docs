# Authentication

When your audio sources require an `Authorization` header, pass an `auth` block to `setup()`. The player injects `Authorization: Bearer <token>` on every HLS manifest and segment request.

```ts
import nmMPlayer from '@nomercy-entertainment/nomercy-music-player';

const player = nmMPlayer('main').setup({
  playlist: [
    /* items */
  ],
  auth: {
    bearerToken: () => myAuth.getAccessToken(),
    refreshOnUnauthenticated: async () => {
      await myAuth.refresh();
    },
  },
});

player.on('ready', () => {
  player.item(0, { autoplay: true });
});
```

- On a **401**, the player calls `refreshOnUnauthenticated` once and retries.
- On a **403**, the error propagates — do not retry.

See [Configuration](/nomercy-music-player/configuration) for the full `auth` option shape.
