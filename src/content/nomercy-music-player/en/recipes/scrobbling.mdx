# Recipe: Scrobbling

[Plugin: Scrobble](/nomercy-music-player/plugins-adapters/scrobble) covers the threshold rules and the default no-op backend. This recipe is the other half: implementing a real `IScrobbler` so listens actually go somewhere, Last.fm, ListenBrainz, or your own server's activity log.

## Implementing IScrobbler

Two methods, both `Promise`-returning so the plugin can await network calls without blocking playback on their result:

```ts
import type { IScrobbler, ScrobbleContext } from '@nomercy-entertainment/nomercy-music-player/plugins/scrobble';
import type { MusicPlaylistItem } from '@nomercy-entertainment/nomercy-music-player';

class MyScrobbler implements IScrobbler<MusicPlaylistItem> {
  readonly id = 'my-backend';

  constructor(private readonly authToken: () => string) {}

  async nowPlaying(item: MusicPlaylistItem): Promise<void> {
    await fetch('/api/scrobble/now-playing', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json', Authorization: `Bearer ${this.authToken()}` },
      body: JSON.stringify({ track: item.name, artist: item.artist, album: item.album }),
    });
  }

  async scrobble(item: MusicPlaylistItem, context: ScrobbleContext): Promise<void> {
    await fetch('/api/scrobble', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json', Authorization: `Bearer ${this.authToken()}` },
      body: JSON.stringify({
        track: item.name,
        artist: item.artist,
        album: item.album,
        startedAt: context.startedAt,
        listenedSeconds: context.listenedSeconds,
        source: context.source,
      }),
    });
  }
}
```

`nowPlaying()` is optional on the interface. A backend with no "currently listening to" concept can omit it entirely. `ScrobblePlugin` only calls it when present.

## Wiring it in

```ts
import nmplayer from '@nomercy-entertainment/nomercy-music-player';
import { ScrobblePlugin } from '@nomercy-entertainment/nomercy-music-player/plugins/scrobble';

const player = nmplayer('player');
player.addPlugin(ScrobblePlugin, {
  scrobbler: new MyScrobbler(() => authStore.accessToken),
  thresholdRatio: 0.5,      // Last.fm's 50% rule, the default
  thresholdSeconds: 240,    // Last.fm's 4-minute cap, the default
  minDurationSeconds: 30,   // never scrobble anything shorter than this
});
player.setup({
  baseUrl: 'https://raw.githubusercontent.com/NoMercy-Entertainment/nomercy-media/master/Music',
  playlist: [
    {
      id: 'ketsa-01-where-dreams-drift',
      name: 'Where Dreams Drift',
      artist: 'Ketsa',
      url: '/K/Ketsa/CC.BY.FREE.TO.USE.FOR.ANYTHING.(2025)/01.Where.Dreams.Drift.mp3',
    },
  ],
});
```

Both thresholds default to the real Last.fm rule already. Whichever threshold is reached first wins. Override them only when your service's own rules differ.

## Handling backend failures without breaking playback

A failed `scrobble()` or `nowPlaying()` call never throws back into playback. The plugin catches the failure and reports it through its own error channel instead:

```ts
player.on('plugin:scrobble:scrobbled', ({ item, listenedSeconds }) => {
  console.log(`Scrobbled "${item.name}" after ${listenedSeconds}s`);
});

// Reported errors surface through the player's own error/report channel,
// tagged with codes like `plugin:scrobble/scrobble-failed` — a bad network
// call never interrupts the track that's actually playing.
```

## Reading in-progress state

`listened()` and `isScrobbled()` on the plugin instance read the current item's accumulated listened time and whether it already crossed the threshold. Use them for a small "scrobbling in 0:42..." indicator, instead of only reacting to the final event:

```ts
const scrobble = player.getPlugin(ScrobblePlugin);
const secondsListened = scrobble?.listened() ?? 0;
const alreadyScrobbled = scrobble?.isScrobbled() ?? false;
```
