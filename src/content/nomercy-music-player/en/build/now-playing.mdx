# Build a Player: Now Playing & Lyrics

[Step 4](/nomercy-music-player/build/track-list) added the track list. This is the last step: a now-playing panel and a synced lyric line — the second (and last) thing the native bar has no concept of.

## Cover art reads the canonical field

`item.url` (the track itself) resolves against `baseUrl` automatically. Artwork should read the canonical `image` field first, falling back to the deprecated `cover` for older catalogues — the exact resolution `MusicPreloadStrategy`/`CastSenderPlugin` use inside the package itself, and the same fix the [Quickstart](/nomercy-music-player/quickstart) applies:

```ts
import nmplayer from '@nomercy-entertainment/nomercy-music-player';

const player = nmplayer('player');
const panel = document.querySelector<HTMLElement>('#now-playing')!;

const cover = player.createElement('img', 'my-cover').appendTo(panel).get();
const current = player.item();
cover.src = current?.image ?? current?.cover ?? '';
```

## Plugins register declaratively

Painting a synced lyric line is [`LyricsPlugin`](/nomercy-music-player/tour/lyrics)'s job. `plugins` in `setup()` is the declarative registration path — sugar over calling `addPlugin()` yourself before `setup()`, resolved at the exact same pipeline point, so there's no separate call to sequence:

```ts
import { LyricsPlugin } from '@nomercy-entertainment/nomercy-music-player/plugins/lyrics';

const player = nmplayer('my-container').setup({
  ...config,
  plugins: [LyricsPlugin],
});
await player.ready();
```

## Wiring the panel

`item` updates the cover, title, and artist together, since they all come from the same track. The lyric line is separate, driven by the plugin's own namespaced event:

```ts
const title = panel.querySelector<HTMLElement>('.title')!;
const artist = panel.querySelector<HTMLElement>('.artist')!;
const lyricLine = panel.querySelector<HTMLElement>('.lyric-line')!;

player.on('item', ({ item }) => {
  cover.src = item?.image ?? item?.cover ?? '';
  title.textContent = item?.name ?? '';
  artist.textContent = item?.artist ?? '';
  lyricLine.textContent = ''; // clear until the new track's lyrics resolve
});
player.on('plugin:lyrics:lineEnter', ({ text }) => {
  lyricLine.textContent = text;
});
```
