# Build a Player: Now Playing & Lyrics

[Step 4](/nomercy-music-player/build/track-list) added the track list. This is the last step: a now-playing panel and a synced lyric line, the second (and last) thing the native bar has no concept of.

## Cover art reads the canonical field

`item.url` (the track itself) resolves against `baseUrl` automatically. Artwork should read the canonical `image` field first, falling back to the deprecated `cover` for older catalogues, the exact resolution `MusicPreloadStrategy`/`CastSenderPlugin` use inside the package itself, and the same fix the [Quickstart](/nomercy-music-player/quickstart) applies:

```ts
import nmplayer from '@nomercy-entertainment/nomercy-music-player';
import { Plugin } from '@nomercy-entertainment/nomercy-player-core';

class NowPlayingPanelPlugin extends Plugin {
  static override readonly id = 'now-playing-panel';
  private cover!: HTMLImageElement;

  override use(): void {
    const panel = document.querySelector<HTMLElement>('#now-playing')!;
    this.cover = this.createElement('img', 'my-cover').appendTo(panel).get();

    const current = this.player.item();
    this.cover.src = current?.image ?? current?.cover ?? '';
  }
}

const player = nmplayer('player').addPlugin(NowPlayingPanelPlugin);
```

## Registering the plugin

Painting a synced lyric line is [`LyricsPlugin`](/nomercy-music-player/tour/lyrics)'s job. A shipped plugin registers with `addPlugin()`, exactly like one you wrote yourself (the `plugins: [LyricsPlugin]` entry in `setup()` config is the declarative equivalent, resolved at the same pipeline point):

```ts
import { LyricsPlugin } from '@nomercy-entertainment/nomercy-music-player/plugins/lyrics';

const player = nmplayer('my-container')
  .addPlugin(LyricsPlugin)
  .setup(config);
await player.ready();
```

## Wiring the panel

`item` updates the cover, title and artist together, since all three come from the same track.

The lyric line is separate. It is driven by `LyricsPlugin`'s own namespaced event, subscribed through the typed class-form listener rather than a raw `'plugin:lyrics:lineEnter'` string.

`static readonly requires` guarantees `LyricsPlugin` is loaded before this reads it. It is declared `optional: true`, because the panel still renders without lyrics:

{/* partial */}
```ts
static override readonly requires = [{ plugin: LyricsPlugin, optional: true }];

private title!: HTMLElement;
private artist!: HTMLElement;
private lyricLine!: HTMLElement;

override use(): void {
  // ...cover setup from above...
  const panel = this.cover.parentElement!;
  this.title = panel.querySelector<HTMLElement>('.title')!;
  this.artist = panel.querySelector<HTMLElement>('.artist')!;
  this.lyricLine = panel.querySelector<HTMLElement>('.lyric-line')!;

  this.on('item', ({ item }) => {
    this.cover.src = item?.image ?? item?.cover ?? '';
    this.title.textContent = item?.name ?? '';
    this.artist.textContent = item?.artist ?? '';
    this.lyricLine.textContent = ''; // clear until the new track's lyrics resolve
  });
  this.on(LyricsPlugin, 'lineEnter', ({ text }) => {
    this.lyricLine.textContent = text;
  });
}
```
