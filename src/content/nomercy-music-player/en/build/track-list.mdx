# Build a Player: The Track List

The last two steps had nothing to add. The native bar already covers transport. This step is different: `controls: true` has no concept of a playlist at all, so a track-list toggle is the first thing in this tutorial actually worth hand-building.

## One button, not a bar

The config below is still `controls: true`. Play, pause, seeking and volume stay with the native bar rather than being rebuilt beside it.

What this step adds is one small button, positioned clear of that bar.

It opens a panel built fresh from `queue()` and `index()` on every open, which is the pattern [The Queue](/nomercy-music-player/tour/queue) documents:

```ts
import nmplayer from '@nomercy-entertainment/nomercy-music-player';
import { Plugin } from '@nomercy-entertainment/nomercy-player-core';

class TrackListPlugin extends Plugin {
  static override readonly id = 'track-list';
  private list!: HTMLDivElement;

  override use(): void {
    this.list = this.createElement('div', 'track-list').appendTo(this.player.container).get();
  }

  private addOption(label: string, active: boolean, onSelect: () => void): void {
    const button = this.createButton(`track-${label}`, label, onSelect);
    button.textContent = label;
    if (active) button.setAttribute('aria-current', 'true');
    this.list.appendChild(button);
  }

  renderList(): void {
    this.list.replaceChildren();
    const items = this.player.queue();
    const activeIndex = this.player.index();

    items.forEach((item, index) => {
      this.addOption(item.name, index === activeIndex, () => {
        this.player.item(index, { autoplay: true });
      });
    });
  }
}

const player = nmplayer('player').addPlugin(TrackListPlugin);
```

Each option button is built with `this.createButton`, `Plugin`'s accessible DOM helper. Every entry gets a real `aria-label` for free. DOM construction is a plugin concern, not a player one: `this.createElement`/`this.createButton` live on the plugin you write, not on the `player` instance you talk to.

## Keeping the highlight in sync

A track can change without a click on this menu at all. `next()`, `previous()`, or a manual [`crossfadeTo()`](/nomercy-music-player/tour/crossfade) can all move the cursor. Re-render whenever the queue's `item` event fires and the list happens to be open, instead of only updating on a click inside the menu itself:

{/* partial */}
```ts
override use(): void {
  // ...panel setup from above...

  this.on('item', () => {
    if (this.menuIsOpen) this.renderList();
  });
}
```

`this.on(...)` (not `this.player.on(...)`), the plugin-scoped listener form auto-disposes on teardown, so there's no matching `off()` to remember.
