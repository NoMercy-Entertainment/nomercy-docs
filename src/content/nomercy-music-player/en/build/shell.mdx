# Build a Player: The Shell

This is a five-step tutorial that builds a real UI against a live player: a shell with play/pause, a scrubber, volume, a track list, now-playing and lyrics. Each step's live player below shows exactly that step's result, nothing from later steps. By the end you have one complete, self-contained overlay file.

## No native bar to turn off

Every example on the Guided Tour already builds its own DOM, `nomercy-music-player` ships no chrome at all, not even an optional native bar to switch on. There's nothing to disable here, `player.container` is a bare `<div>` from the first render.

## The DOM helpers

`nomercy-player-core` exposes the same DOM construction helpers the kit itself is built from, `createElement`, `createButton`, `createSVG`, `addClasses`, `removeClasses`, so building an overlay doesn't require a component framework or a CSS toolkit. `createElement(type, id)` returns a fluent builder; `createButton(id, label, onClick)` returns an accessible `<button>` with `aria-label`, `title`, and the click handler already wired:

```ts
const bar = player.createElement('div', 'my-controls')
  .appendTo(player.container)
  .get();

const playPause = player.createButton('my-play-pause', 'Play', () => {
  void player.togglePlayback();
});
bar.appendChild(playPause);
```

`player.container` is the real mounted `<div>`, the same element `setup()` received. Position it `relative` so an absolutely-positioned bar anchors to it instead of the page.

## Wiring the button to state

A play/pause button needs to reflect state it didn't cause, another tab's play, a Connect sync, the track ending. Read `playState()` and subscribe to `'play'`/`'pause'`/`'playing'` (see [Playback State & Events](/nomercy-music-player/tour/state-events)) instead of tracking a local boolean toggled only by the click handler:

```ts
import { PlayState } from '@nomercy-entertainment/nomercy-music-player';

const sync = () => {
  const playing = player.playState() === PlayState.PLAYING;
  playPause.textContent = playing ? '⏸' : '▶';
  playPause.setAttribute('aria-label', playing ? 'Pause' : 'Play');
};
player.on('play', sync);
player.on('pause', sync);
player.on('playing', sync);
sync(); // set the initial label
```
