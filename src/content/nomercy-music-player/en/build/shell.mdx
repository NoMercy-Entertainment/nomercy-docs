# Build a Player: The Shell

This is a five-step tutorial that mounts a real music player and adds the two things it genuinely lacks: a track list and a now-playing panel. Music ships no UI plugin at all — there's no shipped chrome overlay for audio the way there is for video, so steps 1 through 3 are about what the native bar already gives you for free, and steps 4 and 5 build the two things it can't.

## The real chrome is native

`controls: true` renders the browser's own `<audio controls>` bar — the same bar the [Quickstart](/nomercy-music-player/quickstart) mounts. There's no options surface to configure it with; the browser owns its layout and rendering entirely:

```ts
const config: MusicPlayerConfig = {
  baseUrl,
  playlist: songs,
  controls: true,
};
```

`item(0)` loads the first track once `setup()`'s pipeline settles so the bar has something to play — music has no `autoPlay` config field the way video does, since browsers block audio autoplay outside a user gesture anyway.

## What the native bar already covers

Play/pause, seeking, volume, and mute are all in the bar the moment `controls: true` is set. The next two steps ([Scrubber](/nomercy-music-player/build/scrubber), [Volume](/nomercy-music-player/build/volume)) point at the exact kit methods driving it under the hood — useful the day you swap the native bar for a fully custom one, not because there's anything left to add here.
