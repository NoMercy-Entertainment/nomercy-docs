# Pagination

Endpoints that can return a long list take two query parameters: `page` and `take`.

```bash {{ title: 'The second page, 100 at a time' }}
curl -G https://{server-address}:7626/api/v1/genres \
  -H "Authorization: Bearer {token}" \
  -d page=1 \
  -d take=100
```

::properties

::property {{ name: 'page', type: 'integer' }}

Which page to return, counting from zero. A negative value is treated as zero.

::property {{ name: 'take', type: 'integer' }}

How many items on the page. Defaults to 300 and is capped, so a very large value returns the cap rather than the whole table.

::

The endpoint pages say which endpoints accept these. Where they are absent, the endpoint returns its full result in one response.

## Letter pages

Library and music listings page by first letter instead of by number, because that is how the apps present them.

```text
/api/v1/libraries/{libraryId}/letter/{letter}
/api/v1/music/albums/letter/{letter}
```

Titles that do not start with a letter are grouped under `#`.
