# Authentication

Every request carries a token issued by the NoMercy account service. The server validates it, then looks the account up in its own user list.

## Getting a token

Tokens come from the NoMercy identity service, not from your server.

```text
https://auth.nomercy.tv/realms/NoMercyTV/
```

It speaks OpenID Connect, so any standard OIDC client library can obtain a token. The apps use authorization code flow with PKCE on desktop and web, and device code flow where there is no browser, such as a TV.

Point your client at the discovery document and let the library do the rest.

```text
https://auth.nomercy.tv/realms/NoMercyTV/.well-known/openid-configuration
```

## Sending it

Put the token in the `Authorization` header.

```bash {{ title: 'Bearer token' }}
curl https://{server-address}:7626/api/v1/libraries \
  -H "Authorization: Bearer {token}"
```

Where a header cannot be set, such as a browser opening a SignalR websocket, the token may travel as a query parameter instead.

```text
?access_token={token}
```

## What the server checks

Three things, in order.

**The token is genuine.** Signature, issuer and audience are verified against the identity service. Signing keys are cached, so a server that has lost its internet connection can still validate a token it has seen keys for.

**The token is for the API.** It has to carry the API scope.

**The account exists here.** The subject of the token has to match a user on this server. One identity service serves every NoMercy install, so this last check is what keeps your server yours: a token from someone else's account is a valid token and still gets a 401 here.

## Permissions

Passing authentication answers "who are you". Each endpoint then asks "may you do this".

::properties

::property {{ name: 'MediaAccess' }}

Allowed to use the server: browse libraries, play, manage own playlists.

::property {{ name: 'OpticalAccess' }}

Allowed to drive the disc drive: probe, play and rip a disc.

::property {{ name: 'Moderator' }}

Allowed to manage the server: libraries, encoding, tasks, logs, users.

::property {{ name: 'Owner' }}

The account that owns the server. Satisfies every other permission.

::

Each endpoint page names the permission it needs. Which switches a user holds is set in the dashboard, described in [Users](/nomercy-media-server/users).
