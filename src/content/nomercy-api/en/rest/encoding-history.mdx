# Encoding history

Every finished encode leaves a row: what was encoded, with which profile, how long it took and what came out. It is the record you read when you want to know whether a setting actually helped.

| Method | Path | Needs |
|--------|------|-------|
| GET | `/api/v1/dashboard/encoding/history` | Moderator |
| GET | `/api/v1/dashboard/encoding/history/stats` | Moderator |
| DELETE | `/api/v1/dashboard/encoding/history/{id}` | Moderator |
| POST | `/api/v1/dashboard/encoding/history/purge` | Owner |

The listing takes `pageSize` and `pageIndex`.

`stats` summarises the rows rather than returning them, which is what the dashboard charts.

`purge` clears history in bulk and is owner-only. It removes the record, not the encoded files.
