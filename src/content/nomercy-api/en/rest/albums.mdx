# Albums

Albums carry a MusicBrainz release id.

## Reading

| Method | Path | Needs |
|--------|------|-------|
| GET | `/api/v1/music/albums/letter/{letter}` | MediaAccess |
| GET | `/api/v1/music/albums/{id}` | MediaAccess |

Albums page by first letter, with `#` for anything that does not start with one. The listing also takes `page` and `take`.

## User actions

| Method | Path | Needs |
|--------|------|-------|
| POST | `/api/v1/music/albums/{id}/like` | MediaAccess |

## Managing

| Method | Path | Needs |
|--------|------|-------|
| PATCH | `/api/v1/music/albums/{id}` | Moderator |
| POST | `/api/v1/music/albums/{id}/cover` | Moderator |
| POST | `/api/v1/music/albums/{id}/rescan` | Moderator |

`cover` takes an uploaded image as form data.
