# Artists

Artists are identified by a MusicBrainz id, so the same artist is the same id across servers.

## Reading

| Method | Path | Needs |
|--------|------|-------|
| GET | `/api/v1/music/artists/letter/{letter}` | MediaAccess |
| GET | `/api/v1/music/artists/{id}` | MediaAccess |

Artists are browsed by first letter rather than by page number, because that is how the music view presents them. Names that do not start with a letter are grouped under `#`. The listing also takes `page` and `take`.

## User actions

| Method | Path | Needs |
|--------|------|-------|
| POST | `/api/v1/music/artists/{id}/like` | MediaAccess |

## Managing

| Method | Path | Needs |
|--------|------|-------|
| PATCH | `/api/v1/music/artists/{id}` | Moderator |
| POST | `/api/v1/music/artists/{id}/cover` | Moderator |
| POST | `/api/v1/music/artists/{id}/rescan` | Moderator |
| DELETE | `/api/v1/music/artists/{id}` | Moderator |

`cover` takes an uploaded image as form data.
