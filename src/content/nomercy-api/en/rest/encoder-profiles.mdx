# Encoder profiles

A profile decides what the encoder does with a file. This is the current surface for working with them.

Built-in profiles come with the server and cannot be edited. To change one, clone it and edit the clone.

## Reading

| Method | Path | Needs |
|--------|------|-------|
| GET | `/api/v1/encoder/profiles` | Moderator |
| GET | `/api/v1/encoder/profiles/{id}` | Moderator |
| GET | `/api/v1/encoder/profiles/{id}/resolved` | Moderator |
| GET | `/api/v1/encoder/profiles/tags` | Moderator |

The listing takes `pageSize`, `pageIndex` and an optional `tag`. Built-in profiles are returned first.

A profile can inherit from another, so what is stored is not always the whole picture. `resolved` returns it with everything inherited filled in, which is what the encoder will actually use.

## Building one

| Method | Path | Needs |
|--------|------|-------|
| POST | `/api/v1/encoder/profiles` | Moderator |
| PUT | `/api/v1/encoder/profiles/{id}` | Moderator |
| POST | `/api/v1/encoder/profiles/{parentId}/clone` | Moderator |
| DELETE | `/api/v1/encoder/profiles/{id}` | Moderator |

## Checking before you commit

| Method | Path | Needs |
|--------|------|-------|
| POST | `/api/v1/encoder/profiles/validate` | Moderator |
| POST | `/api/v1/encoder/profiles/{id}/preview` | Moderator |

`validate` says whether a profile can work at all. `preview` shows what it would do to a given source, which is the honest answer to "will this re-encode or copy".

## Sharing

| Method | Path | Needs |
|--------|------|-------|
| GET | `/api/v1/encoder/profiles/{id}/export` | Moderator |
| POST | `/api/v1/encoder/profiles/import` | Moderator |

An exported profile can be signed. On import the signature is checked against the publishers you trust; importing an unsigned one is a deliberate choice, made with `trust_unsigned`.

## Deprecated routes

`/api/v1/dashboard/encoding/presets` and `/api/v1/dashboard/encoderprofiles` are deprecated. [Encoding presets](/nomercy-api/rest/encoding-presets) lists which route here to call in place of each.
