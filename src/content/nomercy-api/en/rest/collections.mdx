# Collections

A collection is a film series that TheMovieDB groups, such as a trilogy. It behaves like a film: same actions, same ids, one level up.

## Reading

| Method | Path | Needs |
|--------|------|-------|
| GET | `/api/v1/collection` | MediaAccess |
| GET | `/api/v1/collection/{id}` | MediaAccess |
| GET | `/api/v1/collection/{id}/available` | MediaAccess |
| GET | `/api/v1/collection/{id}/watch` | MediaAccess |

The listing takes `page` and `take`. See [Pagination](/nomercy-api/pagination).

## User actions

| Method | Path | Needs |
|--------|------|-------|
| POST | `/api/v1/collection/{id}/like` | MediaAccess |
| POST | `/api/v1/collection/{id}/watch-list` | MediaAccess |

## Managing

| Method | Path | Needs |
|--------|------|-------|
| POST | `/api/v1/collection/{id}/add` | Moderator |
| POST | `/api/v1/collection/{id}/refresh` | Moderator |
| POST | `/api/v1/collection/{id}/rescan` | Moderator |
| DELETE | `/api/v1/collection/{id}` | Moderator |

Adding a collection brings in the films it contains, so it saves adding each one.
