# Specials

A special is a collection you build yourself: films and episodes in a deliberate order, such as a viewing order across two series. It is the one grouping the metadata sources cannot give you.

Its id is generated by your server, so it exists only there.

## Reading

| Method | Path | Needs |
|--------|------|-------|
| GET | `/api/v1/specials` | MediaAccess |
| GET | `/api/v1/specials/{id}` | MediaAccess |
| GET | `/api/v1/specials/{id}/available` | MediaAccess |
| GET | `/api/v1/specials/{id}/watch` | MediaAccess |

The listing takes `page` and `take`. See [Pagination](/nomercy-api/pagination).

## User actions

| Method | Path | Needs |
|--------|------|-------|
| POST | `/api/v1/specials/{id}/like` | MediaAccess |
| POST | `/api/v1/specials/{id}/watch-list` | MediaAccess |

## Managing

| Method | Path | Needs |
|--------|------|-------|
| POST | `/api/v1/specials/{id}/rescan` | Moderator |

Building and editing a special is a dashboard job with its own endpoints, under `/api/v1/dashboard/specials`. Those add and remove items and set their order.
