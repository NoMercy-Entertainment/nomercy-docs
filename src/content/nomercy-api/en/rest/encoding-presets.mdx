# Encoding presets

Every route under `/api/v1/dashboard/encoding/presets` is deprecated. It answers,
so code calling it keeps working. Write new code against [Encoder profiles](/nomercy-api/rest/encoder-profiles).

## Which route to call

| Deprecated | Call instead |
|-----|-----|
| `GET /dashboard/encoding/presets` | `GET /encoder/profiles` |
| `GET /dashboard/encoding/presets/{id}` | `GET /encoder/profiles/{id}` |
| `POST /dashboard/encoding/presets` | `POST /encoder/profiles` |
| `PUT /dashboard/encoding/presets/{id}` | `PUT /encoder/profiles/{id}` |
| `DELETE /dashboard/encoding/presets/{id}` | `DELETE /encoder/profiles/{id}` |
| `POST /dashboard/encoding/presets/{id}/clone` | `POST /encoder/profiles/{id}/clone` |
| `GET /dashboard/encoding/presets/{id}/resolve` | `GET /encoder/profiles/{id}/resolve` |
| `GET /dashboard/encoding/presets/{id}/export` | `GET /encoder/profiles/{id}/export` |
| `POST /dashboard/encoding/presets/import` | `POST /encoder/profiles/import` |
| `POST /dashboard/encoding/presets/validate` | `POST /encoder/profiles/validate` |
| `POST /dashboard/encoding/presets/{id}/preview` | `POST /encoder/profiles/{id}/preview` |
| `GET /dashboard/encoding/presets/tags` | `GET /encoder/profiles/tags` |

All paths above are relative to `/api/v1`, and all need Moderator.

`/api/v1/dashboard/encoderprofiles` is deprecated too. Its create route answers
410 and names the route to call in the response.
