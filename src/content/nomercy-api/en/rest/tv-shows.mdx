# TV Shows

A series is addressed by its TheMovieDB series id. Seasons and episodes are returned inside the series rather than addressed on their own.

## Reading

| Method | Path | Needs |
|--------|------|-------|
| GET | `/api/v1/tv/{id}` | MediaAccess |
| GET | `/api/v1/tv/{id}/available` | MediaAccess |
| GET | `/api/v1/tv/{id}/watch` | MediaAccess |
| GET | `/api/v1/tv/{id}/missing` | MediaAccess |

`missing` lists episodes the series is known to have and the server does not hold. It is the quickest way to see a gap in a season.

## User actions

| Method | Path | Needs |
|--------|------|-------|
| POST | `/api/v1/tv/{id}/like` | MediaAccess |
| POST | `/api/v1/tv/{id}/watch-list` | MediaAccess |

## Managing

| Method | Path | Needs |
|--------|------|-------|
| POST | `/api/v1/tv/{id}/add` | Moderator |
| POST | `/api/v1/tv/{id}/refresh` | Moderator |
| POST | `/api/v1/tv/{id}/rescan` | Moderator |
| DELETE | `/api/v1/tv/{id}` | Moderator |

`add` and `refresh` both take an optional `libraryId`.

Anime lives here too. An anime series is a series with an anime library behind it, so it uses these same endpoints.
