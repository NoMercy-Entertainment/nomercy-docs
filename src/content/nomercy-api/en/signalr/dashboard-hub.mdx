# Dashboard hub

```text
wss://{server-address}:7626/dashboardHub?access_token={token}
```

The dashboard's live feed: processor, memory and disk as they move, plus log lines as they are written.

A moderator connecting joins the moderators group and receives what is broadcast to it.

## Resource monitoring

```text
StartResources()
StopResources()
```

Both need Moderator.

Measuring costs something, so it runs only while a dashboard is watching. Start it when the page opens, stop it when the page leaves.

The server also stops on its own once the last dashboard connection has gone, so a client that closes abruptly leaves nothing running.
