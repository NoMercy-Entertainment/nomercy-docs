# NoMercy API

## Start here {{ anchor: false }}

Read [Overview](/nomercy-api/overview) for the base address and the response shape, then [Authentication](/nomercy-api/authentication) for the token. Between them they cover everything the reference pages assume. {{ className: 'lead' }}

Each endpoint page lists the method, the path, and the permission it needs. [Errors](/nomercy-api/errors) explains what a rejection looks like, and [Pagination](/nomercy-api/pagination) how to walk a long list.
