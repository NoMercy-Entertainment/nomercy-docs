# Skipper Plugin

`SkipperPlugin` reads structured skip range data from each playlist item and provides an API to skip intros, recaps, and credits programmatically or via user interaction.

---

## Setup

```ts
import { SkipperPlugin } from '@nomercy-entertainment/nomercy-video-player';

player.addPlugin(SkipperPlugin);
```

---

## Providing skip ranges

Add a `skippers` field to each playlist item:

```ts
player.setup({
  queue: [
    {
      id: '1',
      url: '...ep1.m3u8',
      skippers: {
        intro:   { start: 12,   end: 103 },   // seconds
        recap:   { start: 0,    end: 42 },
        credits: { start: 1380, end: 1440 },
      },
    },
  ],
});
```

All three ranges (`intro`, `recap`, `credits`) are optional.

---

## Querying skip ranges

```ts
const skipper = player.getPlugin(SkipperPlugin);

skipper.skippers();       // all ranges for the current item
skipper.currentSkipper(); // range active at currentTime(), or undefined if not in a range
```

---

## Skipping

```ts
skipper.skip('intro');    // seek to intro.end
skipper.skip('credits');  // seek to credits.end
skipper.skip('recap');    // seek to recap.end
skipper.skip();           // skip whichever range currentTime() is inside
```

`skip()` without a kind argument is the typical binding for a "Skip" button — it skips whatever the current time falls inside.

---

## Events

```ts
import { SkipperPlugin } from '@nomercy-entertainment/nomercy-video-player';

player.on(SkipperPlugin, 'skipActivated', ({ kind, range }) => {
  console.log(`Skipped ${kind}: ${range.start}s → ${range.end}s`);
});

player.on(SkipperPlugin, 'enteredSkipRange', ({ kind, range }) => {
  showSkipButton(kind);
});

player.on(SkipperPlugin, 'exitedSkipRange', ({ kind }) => {
  hideSkipButton(kind);
});
```

Use `enteredSkipRange` and `exitedSkipRange` to show and hide a skip button in the UI when the current time enters or exits a marked range.

---

## Building a skip button

```ts
const skipper = player.getPlugin(SkipperPlugin);

player.on(SkipperPlugin, 'enteredSkipRange', ({ kind }) => {
  skipButton.style.display = 'block';
  skipButton.textContent = kind === 'intro' ? 'Skip Intro' : 'Skip Credits';
  skipButton.onclick = () => skipper.skip(kind);
});

player.on(SkipperPlugin, 'exitedSkipRange', () => {
  skipButton.style.display = 'none';
});
```

---

## DesktopUiPlugin integration

`DesktopUiPlugin` renders a "Skip Intro" / "Skip Credits" button automatically when `SkipperPlugin` is registered and the current time is inside a marked range. No additional wiring needed.

```ts
player
  .addPlugin(DesktopUiPlugin)
  .addPlugin(SkipperPlugin);
```
