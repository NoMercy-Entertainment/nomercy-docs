# Custom Adapters

The video player uses four adapter ports for pluggable storage and data loading. This page shows how to implement custom adapters for each port.

**Prerequisites:** Read [Adapters — Video Backend](/nomercy-video-player/adapters/video-backend), [Adapters — Chapter Source](/nomercy-video-player/adapters/chapter-source), [Adapters — Thumbnail Source](/nomercy-video-player/adapters/thumbnail-source), and [Adapters — Subtitle Style Store](/nomercy-video-player/adapters/subtitle-style-store) first — they cover the interface contracts. This page focuses on non-trivial implementations.

## ISubtitleStyleStore — IndexedDB backend

The default `StorageBackedSubtitleStyleStore` writes to `localStorage`. For larger style objects or cross-tab sync, use IndexedDB:

```ts
import type {
  ISubtitleStyleStore,
  SubtitleStyle,
} from '@nomercy-entertainment/nomercy-video-player';

const DB_NAME = 'player-preferences';
const STORE_NAME = 'subtitle-styles';

class IndexedDbSubtitleStyleStore implements ISubtitleStyleStore {
  private dbPromise: Promise<IDBDatabase>;

  constructor() {
    this.dbPromise = this.openDb();
  }

  private openDb(): Promise<IDBDatabase> {
    return new Promise((resolve, reject) => {
      const request = indexedDB.open(DB_NAME, 1);
      request.onupgradeneeded = () => {
        request.result.createObjectStore(STORE_NAME);
      };
      request.onsuccess = () => resolve(request.result);
      request.onerror = () => reject(request.error);
    });
  }

  async get(): Promise<SubtitleStyle | null> {
    const db = await this.dbPromise;
    return new Promise((resolve, reject) => {
      const transaction = db.transaction(STORE_NAME, 'readonly');
      const request = transaction.objectStore(STORE_NAME).get('default');
      request.onsuccess = () => resolve(request.result ?? null);
      request.onerror = () => reject(request.error);
    });
  }

  async set(style: SubtitleStyle): Promise<void> {
    const db = await this.dbPromise;
    return new Promise((resolve, reject) => {
      const transaction = db.transaction(STORE_NAME, 'readwrite');
      const request = transaction.objectStore(STORE_NAME).put(style, 'default');
      request.onsuccess = () => resolve();
      request.onerror = () => reject(request.error);
    });
  }
}

player.setup({
  subtitleStyleStore: new IndexedDbSubtitleStyleStore(),
});
```

## IChapterSource — cache-aside pattern

When chapters come from an API, avoid refetching per-item with a simple cache:

```ts
import type {
  IChapterSource,
  Chapter,
  VideoPlaylistItem,
} from '@nomercy-entertainment/nomercy-video-player';

class CachedApiChapterSource implements IChapterSource {
  private cache = new Map<string, Chapter[]>();

  async load(item: VideoPlaylistItem): Promise<Chapter[]> {
    if (this.cache.has(item.id)) {
      return this.cache.get(item.id)!;
    }

    const response = await fetch(`/api/v1/chapters/${item.id}`, {
      headers: { Authorization: `Bearer ${await getToken()}` },
    });

    if (!response.ok) return []; // player handles empty chapters gracefully

    const data: Array<{ id: string; start_ms: number; end_ms: number; title: string }> =
      await response.json();

    const chapters: Chapter[] = data.map((ch) => ({
      id: ch.id,
      startTime: ch.start_ms / 1000,
      endTime: ch.end_ms / 1000,
      title: ch.title,
    }));

    this.cache.set(item.id, chapters);
    return chapters;
  }

  // Call this when the queue changes to prevent stale data:
  invalidate(itemId: string): void {
    this.cache.delete(itemId);
  }
}
```

## IThumbnailSource — sprite-sheet from API

When your server generates preview sprites on demand instead of serving a static VTT file:

```ts
import type {
  IThumbnailSource,
  ThumbnailFrame,
  VideoPlaylistItem,
} from '@nomercy-entertainment/nomercy-video-player';

class ApiThumbnailSource implements IThumbnailSource {
  async getFrameAtTime(
    item: VideoPlaylistItem,
    timeSeconds: number,
  ): Promise<ThumbnailFrame | null> {
    const response = await fetch(`/api/v1/thumbnails/${item.id}?t=${Math.floor(timeSeconds)}`);

    if (!response.ok) return null;

    const data: { url: string; x: number; y: number; width: number; height: number } =
      await response.json();

    return {
      url: data.url,
      x: data.x,
      y: data.y,
      width: data.width,
      height: data.height,
    };
  }
}

player.setup({
  thumbnailSource: new ApiThumbnailSource(),
});
```

The player calls `getFrameAtTime` when the user hovers over the seek bar. Keep the response fast (under 100 ms) — debounce or pre-fetch frames around the current hover position on the server side.

## IStorage (kit) — MemoryStorageBackend

The kit's `IStorage` port controls where plugin state (volume preference, subtitle index, repeat mode) is persisted. For testing or SSR environments where `localStorage` is unavailable:

```ts
import { MemoryStorageBackend } from '@nomercy-entertainment/nomercy-player-core';

player.setup({
  storage: new MemoryStorageBackend(),
});
```

For a cross-tab storage adapter, see [Kit — Storage](/nomercy-player-kit/storage).
