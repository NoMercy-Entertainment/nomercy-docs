# Custom Adapters

The video player uses four adapter ports for pluggable storage and data loading.
This page shows how to implement custom adapters for each port.

**Prerequisites:** Read [Adapters, Video Backend](/nomercy-video-player/adapters/video-backend), [Adapters, Chapter Source](/nomercy-video-player/adapters/chapter-source), [Adapters, Thumbnail Source](/nomercy-video-player/adapters/thumbnail-source), and [Adapters, Subtitle Style Store](/nomercy-video-player/adapters/subtitle-style-store) first, as they cover the interface contracts.
This page focuses on non-trivial implementations.

## ISubtitleStyleStore, IndexedDB backend

The default `StorageBackedSubtitleStyleStore` writes to `localStorage`.
For larger style objects or cross-tab sync, use IndexedDB:

```ts
import type {
  ISubtitleStyleStore,
  SubtitleStyle,
} from '@nomercy-entertainment/nomercy-video-player';

const DB_NAME = 'player-preferences';
const STORE_NAME = 'subtitle-styles';

class IndexedDbSubtitleStyleStore implements ISubtitleStyleStore {
  private dbPromise: Promise<IDBDatabase>;

  constructor() {
    this.dbPromise = this.openDb();
  }

  private openDb(): Promise<IDBDatabase> {
    return new Promise((resolve, reject) => {
      const request = indexedDB.open(DB_NAME, 1);
      request.onupgradeneeded = () => {
        request.result.createObjectStore(STORE_NAME);
      };
      request.onsuccess = () => resolve(request.result);
      request.onerror = () => reject(request.error);
    });
  }

  async load(): Promise<SubtitleStyle | null> {
    const db = await this.dbPromise;
    return new Promise((resolve, reject) => {
      const transaction = db.transaction(STORE_NAME, 'readonly');
      const request = transaction.objectStore(STORE_NAME).get('default');
      request.onsuccess = () => resolve(request.result ?? null);
      request.onerror = () => reject(request.error);
    });
  }

  async save(style: SubtitleStyle): Promise<void> {
    const db = await this.dbPromise;
    return new Promise((resolve, reject) => {
      const transaction = db.transaction(STORE_NAME, 'readwrite');
      const request = transaction.objectStore(STORE_NAME).put(style, 'default');
      request.onsuccess = () => resolve();
      request.onerror = () => reject(request.error);
    });
  }
}

player.setup({
  subtitleStyleStore: new IndexedDbSubtitleStyleStore(),
});
```

## IChapterSource, cache-aside pattern

When chapters come from an API, avoid refetching per-item with a simple cache:

```ts
import { authFetch } from '@nomercy-entertainment/nomercy-player-core';
import type {
  IChapterSource,
  Chapter,
  VideoPlaylistItem,
} from '@nomercy-entertainment/nomercy-video-player';

class CachedApiChapterSource implements IChapterSource {
  private cache = new Map<string, Chapter[]>();

  async load(item: VideoPlaylistItem): Promise<Chapter[]> {
    if (this.cache.has(item.id)) {
      return this.cache.get(item.id)!;
    }

    let chapterData: Array<{ id: string; start_ms: number; end_ms: number; title: string }>;

    try {
      chapterData = await authFetch<Array<{ id: string; start_ms: number; end_ms: number; title: string }>>({
        url: `/api/v1/chapters/${item.id}`,
        responseType: 'json',
        signal: AbortSignal.timeout(10_000),
      });
    } catch {
      return [];
    }

    const chapters: Chapter[] = chapterData.map((entry, index) => ({
      index,
      start: entry.start_ms / 1000,
      end: entry.end_ms / 1000,
      title: entry.title,
    }));

    this.cache.set(item.id, chapters);

    return chapters;
  }

  // Call this when the queue changes to prevent stale data:
  invalidate(itemId: string): void {
    this.cache.delete(itemId);
  }
}
```

## IThumbnailSource, sprite-sheet from API

When your server generates preview sprites on demand instead of serving a static VTT file:

```ts
import { authFetch } from '@nomercy-entertainment/nomercy-player-core';
import type {
  IThumbnailSource,
  ThumbnailFrame,
  VideoPlaylistItem,
} from '@nomercy-entertainment/nomercy-video-player';

class ApiThumbnailSource implements IThumbnailSource {
  private cache: ThumbnailFrame[] = [];
  private currentItemId: string | undefined;

  async load(item: VideoPlaylistItem): Promise<boolean> {
    if (this.currentItemId === item.id) return this.cache.length > 0;
    this.currentItemId = item.id;
    this.cache = [];

    let frames: Array<{
      url: string;
      x: number;
      y: number;
      width: number;
      height: number;
      start: number;
      end: number;
    }>;

    try {
      frames = await authFetch<Array<{
        url: string;
        x: number;
        y: number;
        width: number;
        height: number;
        start: number;
        end: number;
      }>>({
        url: `/api/v1/thumbnails/${item.id}`,
        responseType: 'json',
        signal: AbortSignal.timeout(10_000),
      });
    } catch {
      return false;
    }

    this.cache = frames.map((frame) => ({
      spriteUrl: frame.url,
      x: frame.x,
      y: frame.y,
      w: frame.width,
      h: frame.height,
      start: frame.start,
      end: frame.end,
    }));

    return this.cache.length > 0;
  }

  lookup(timeSeconds: number): ThumbnailFrame | null {
    return this.cache.find((frame) => timeSeconds >= frame.start && timeSeconds < frame.end) ?? null;
  }

  unload(): void {
    this.cache = [];
    this.currentItemId = undefined;
  }
}

player.setup({
  thumbnailSource: new ApiThumbnailSource(),
});
```

`lookup()` is called synchronously on every scrub hover event.
`load()` is called once per playlist item when it loads, so fetch and cache all frames there.
Keep `lookup()` a pure array scan with no I/O.

## IStorage (core), MemoryStorageBackend

The player core's `IStorage` port controls where plugin state (volume preference, subtitle index, repeat mode) is persisted.
For testing or SSR environments where `localStorage` is unavailable:

```ts
import { MemoryStorageBackend } from '@nomercy-entertainment/nomercy-player-core';

player.setup({
  storage: new MemoryStorageBackend(),
});
```

For a cross-tab storage adapter, see [Core, Storage](/nomercy-player-core/storage).
