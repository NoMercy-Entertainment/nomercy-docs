## fullscreenState

```ts
player.fullscreenState(): FullscreenState
player.fullscreenState(state: FullscreenState | boolean): void
```

Read or set fullscreen state. Passing `true` is equivalent to `FullscreenState.ON`.

```ts
import { FullscreenState } from '@nomercy-entertainment/nomercy-video-player';

const state = player.fullscreenState();  // 'off' | 'on'
player.fullscreenState(true);            // enter fullscreen
player.fullscreenState(FullscreenState.OFF); // exit fullscreen
```

## toggleFullscreen

```ts
player.toggleFullscreen(): void
```

Toggle between `FullscreenState.ON` and `FullscreenState.OFF`.

## pipState

```ts
player.pipState(): PipState
player.pipState(state: PipState | boolean): void
```

Read or set Picture-in-Picture state.

```ts
import { PipState } from '@nomercy-entertainment/nomercy-video-player';

player.pipState(true);   // enter PiP
player.pipState(false);  // exit PiP
```

## togglePip

```ts
player.togglePip(): void
```

Toggle between `PipState.ON` and `PipState.OFF`.

## theaterState

```ts
player.theaterState(): TheaterState
player.theaterState(state: TheaterState | boolean): void
```

Read or set theater mode (wider layout). `theaterDefault: true` in config starts the player in theater mode.

## toggleTheater

```ts
player.toggleTheater(): void
```

Toggle between `TheaterState.ON` and `TheaterState.OFF`.

## subtitleState

```ts
player.subtitleState(): SubtitleState
```

Returns `SubtitleState.ON` when any subtitle track is active, `SubtitleState.OFF` otherwise. Read-only — use `player.currentSubtitle(idx)` to change the active track.

## Events

All state methods emit corresponding events when the value changes:

| Method | Event | Payload |
|---|---|---|
| `fullscreenState(state)` | `'fullscreen'` | `{ active: boolean }` |
| `pipState(state)` | `'pip'` | `{ active: boolean }` |
| `theaterState(state)` | `'theater'` | `{ active: boolean }` |

## Example — theater toggle button

```ts
import nmplayer from '@nomercy-entertainment/nomercy-video-player';
import { TheaterState } from '@nomercy-entertainment/nomercy-video-player';

const player = nmplayer('player').setup({
  theaterDefault: false,
  playlist: [{ title: 'Tears of Steel', url: 'https://raw.githubusercontent.com/NoMercy-Entertainment/nomercy-media/master/Films/Tears.of.Steel.(2012)/Tears.of.Steel.(2012).NoMercy.m3u8' }],
});

document.getElementById('theater-btn')?.addEventListener('click', () => {
  player.toggleTheater();
});

player.on('theater', ({ active }) => {
  document.getElementById('theater-btn')?.setAttribute(
    'aria-pressed',
    String(active),
  );
});
```
