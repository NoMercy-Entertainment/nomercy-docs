## Plugin id

`'cast-sender'`

## Import

```ts
import { CastSenderPlugin } from '@nomercy-entertainment/nomercy-video-player/plugins';
import type {
  CastSenderOptions,
  CastSenderEvents,
} from '@nomercy-entertainment/nomercy-video-player/plugins';
```

## Prerequisites

The Google Cast SDK script must be loaded before the plugin's `use()` runs:

```html
<script src="https://www.gstatic.com/cv/js/sender/v1/cast_sender.js?loadCastFramework=1"></script>
```

## What it does

`CastSenderPlugin` is a thin video-specific override of the kit's shared `CastSenderPlugin`. It provides the full Chromecast CAF (Cast Application Framework) sender integration for video:

- Probes for the Google Cast SDK at startup
- Manages Cast session lifecycle (connect, disconnect, resume on reconnect)
- Mirrors `RemotePlayer` events back to the local player event bus so `currentTime()`, `playState()`, and `volume()` stay accurate while casting
- Builds `TvShowMediaMetadata` (when `item.show` is set) or `GenericMediaMetadata` from the video item's `title`, `show`, `season`, `episode`, and `poster` fields
- Resolves poster URLs through the kit's auth fetch pipeline (respects `imageBasePath`)
- Forwards `play()`, `pause()`, `stop()`, `currentTime(t)`, `next()`, and `previous()` to the Cast receiver while a session is active

## Options

`CastSenderOptions` is defined in `@nomercy-entertainment/nomercy-player-core`. Key fields:

| Option                    | Type      | Default | Description                                                                        |
| ------------------------- | --------- | ------- | ---------------------------------------------------------------------------------- |
| `chromecastAppId`         | `string`  | —       | Chromecast receiver app ID. Defaults to the built-in NoMercy receiver app ID.      |
| `resumeLocalOnDisconnect` | `boolean` | `true`  | Resume local playback after Cast disconnects, restoring the receiver's last position |
| `enableAirPlay`           | `boolean` | `false` | Allow AirPlay sender on Safari                                                     |
| `live`                    | `boolean` | `false` | Treat the stream as a live (unbounded) source                                      |

## Events

`CastSenderEvents` is defined in `@nomercy-entertainment/nomercy-player-core`:

| Event                   | Payload                                             | Description                                  |
| ----------------------- | --------------------------------------------------- | -------------------------------------------- |
| `'cast:available'`      | `{ devices: number }`                               | Cast API loaded; `devices` = receiver count  |
| `'cast:connecting'`     | `{ deviceName: string }`                            | Attempting to connect to a receiver          |
| `'cast:connected'`      | `{ deviceName: string }`                            | Session established                          |
| `'cast:disconnected'`   | `void`                                              | Session ended                                |
| `'cast:remote-state'`   | `{ time: number; state: 'playing' \| 'paused' \| 'buffering' }` | Receiver playback state mirrored |
| `'cast:media-changed'`  | `{ contentId: string }`                             | Active media item changed on receiver        |
| `'cast:error'`          | `{ error: Error }`                                  | Cast SDK or session error                    |
| `'unsupported'`         | `{ reason: string }`                                | Cast SDK not available in this environment   |

## Registration

```ts
import nmplayer from '@nomercy-entertainment/nomercy-video-player';
import { CastSenderPlugin } from '@nomercy-entertainment/nomercy-video-player/plugins';

const player = nmplayer('player')
  .addPlugin(CastSenderPlugin, { chromecastAppId: 'CC1AD845' })
  .setup({
    baseUrl: 'https://raw.githubusercontent.com/NoMercy-Entertainment/nomercy-media/master/Films',
    playlist: [
      {
        title: 'Tears of Steel',
        url: '/Tears.of.Steel.(2012)/Tears.of.Steel.(2012).NoMercy.m3u8',
        image: 'https://image.tmdb.org/t/p/w780/aB67tezxbHnbiTW6Vt0VQ5tBnxv.jpg',
        show: 'Blender Foundation',
      },
    ],
  });

player.on('cast:connected', ({ deviceName }) => {
  console.log('Casting to:', deviceName);
});

player.on('cast:disconnected', () => {
  // local playback resumes automatically
});
```

## Custom receiver

If you have a custom Cast receiver app, pass its application id:

```ts
player.addPlugin(CastSenderPlugin, {
  chromecastAppId: 'ABCD1234',
});
```

The receiver must support the same playlist item shape (`url`, `title`, `subtitles`, etc.) or a mapped equivalent. Coordinate with your receiver implementation.

## Metadata building

The video CastSenderPlugin overrides `buildMetadata()` to pick between `TvShowMediaMetadata` and `GenericMediaMetadata`:

- When `item.show` is a non-empty string: uses `TvShowMediaMetadata` with `seriesTitle`, `season`, and `episode` populated.
- Otherwise: uses `GenericMediaMetadata` with `title` and an optional `subtitle` from `item.show`.

Poster artwork is resolved via `this.resolveUrl(item.poster, 'poster')` — the kit's auth pipeline applies.

## nomercy-cast-player

The NoMercy cast receiver (`nomercy-cast-player`) is a Vue 3 app designed to work with this plugin. It is slated for a full rewrite to v2 in a future release.
