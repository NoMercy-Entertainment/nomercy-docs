`KeyHandlerPlugin` is the video-player's keyboard binding layer. It subclasses the kit's base `KeyHandlerPlugin` and adds the full v1 binding set — playback, modifier-aware seeks, volume, chapters, subtitle/audio cycling, fullscreen, speed, frame advance, and TV color buttons. Register it on any deployment where keyboard control is needed; `DesktopUiPlugin` bundles it automatically, so register it separately only when building a custom UI without `DesktopUiPlugin`.

## Plugin id

`'video-key-handler'`

## Import

```ts
import { KeyHandlerPlugin } from '@nomercy-entertainment/nomercy-video-player/plugins';
```

## What it does

`KeyHandlerPlugin` is a video-specific subclass of the kit's base `KeyHandlerPlugin`. It adds the full v1 keyboard binding set on top of the kit's cooldown / scope / `when` / cleanup infrastructure. All bindings are modifier-aware.

The plugin binds the following groups by default:

| Group          | Keys                                                                                |
| -------------- | ----------------------------------------------------------------------------------- |
| Playback       | `Space`, `MediaPlay`, `MediaPause`, `MediaPlayPause`, `MediaStop`                   |
| Navigation     | `ArrowLeft` (rewind), `ArrowRight` (forward) — disabled on TV                       |
| Volume         | `ArrowUp` / `ArrowDown` (on desktop only), `m` (mute)                               |
| Media keys     | `Subtitle` / `5` / `v` → `cycleSubtitles`; `Audio` / `2` / `b` → `cycleAudioTracks` |
| Modifier seeks | `Shift+Arrow` ±3s, `Alt+Arrow` ±10s, `Ctrl+Arrow` ±60s                              |
| Quick skip     | `1`→120s, `3`→30s, `6`→60s, `9`→90s; TV color buttons `F0`–`F3`                     |
| Next / Prev    | `MediaTrackNext`, `MediaTrackPrevious`, `n`, `p`                                    |
| Chapters       | `Shift+N` (next), `Shift+P` (previous)                                              |
| Fullscreen     | `f`, `F11`, `Escape`                                                                |
| Speed          | `]` faster, `[` slower, `=` reset                                                   |
| Frame advance  | `e` — advances ~1/30s when paused                                                   |
| Show time      | `t` — OSD message with current / remaining time                                     |
| Subtitle size  | `+` / `-` — emits `'subtitle-size-up'` / `'subtitle-size-down'`                     |
| Aspect ratio   | `a`, `BrowserFavorites` → `cycleAspectRatio()`                                      |
| Stop           | `s`                                                                                 |
| Help           | `?` → emits `'plugin:desktop-ui:shortcuts-toggle'`                                  |

## Options

`KeyHandlerPlugin` inherits `KeyHandlerOptions` from the kit base class. No video-specific options are added.

```ts
interface KeyHandlerOptions<P> {
  /** Where the keydown listener is attached. Default 'document'. */
  scope?: 'document' | 'container' | HTMLElement;
  /** Extra bindings merged on top of the default groups. Same combo wins over the default. */
  bindings?: Record<string, (player: P) => void>;
  /** When false, default bindings are cleared before opts.bindings is applied. Default true. */
  extend?: boolean;
  /** Gate predicate — return false to suppress all key handling for that event. */
  when?: (e: KeyboardEvent) => boolean;
  /** Minimum milliseconds between consecutive fires of the same key. Default 300. */
  cooldownMs?: number;
  /** When true, hardware media keys (MediaPlay, MediaPause, etc.) are silently ignored. Default false. */
  disableMediaControls?: boolean;
}
```

| Option                 | Type                              | Default      | Description                                                              |
| ---------------------- | --------------------------------- | ------------ | ------------------------------------------------------------------------ |
| `scope`                | `'document' \| 'container' \| HTMLElement` | `'document'` | Where the keydown listener is attached                      |
| `bindings`             | `Record<string, fn>`              | `{}`         | Additional combos merged on top of the video default groups              |
| `extend`               | `boolean`                         | `true`       | `false` clears all defaults before `bindings` is applied                 |
| `when`                 | `(e: KeyboardEvent) => boolean`   | —            | Return `false` to suppress all keys for that event                       |
| `cooldownMs`           | `number`                          | `300`        | Minimum ms between consecutive fires of the same key                     |
| `disableMediaControls` | `boolean`                         | `false`      | Suppress hardware media key handling (MediaPlay, MediaPause, etc.)       |

The `disableControls` and `disableMediaControls` flags in `VideoPlayerConfig` are also respected — pass them in `setup()` rather than in the plugin options when the intent is to disable globally.

## Registration

```ts
import nmplayer from '@nomercy-entertainment/nomercy-video-player';
import { KeyHandlerPlugin } from '@nomercy-entertainment/nomercy-video-player/plugins';

const player = nmplayer('player')
  .addPlugin(KeyHandlerPlugin)
  .setup({
    baseUrl: 'https://raw.githubusercontent.com/NoMercy-Entertainment/nomercy-media/master/Films',
    playlist: [
      {
        title: 'Big Buck Bunny',
        url: '/Big.Buck.Bunny.(2008)/Big.Buck.Bunny.(2008).NoMercy.m3u8',
      },
    ],
  });
```

## Disabling controls

Set `disableControls: true` in `VideoPlayerConfig` to suppress all bindings. Set `disableMediaControls: true` to suppress only the `MediaPlay` / `MediaPause` / `MediaStop` media keys:

```ts
player.setup({
  disableMediaControls: false,
  disableControls: false,
  playlist: [...],
});
```

## Subclassing

All binding groups are `protected` methods — subclass `KeyHandlerPlugin` and override any group without rewriting the rest:

```ts
import { KeyHandlerPlugin as BaseKeyHandler } from '@nomercy-entertainment/nomercy-video-player/plugins';

class MyKeyHandler extends BaseKeyHandler {
  protected override addNavigationKeys(): void {
    // Custom seek distances
    this.bind('ArrowLeft', () => {
      void this.player.rewind?.(30);
    });
    this.bind('ArrowRight', () => {
      void this.player.forward?.(30);
    });
  }
}
```

## OSD messages

Bindings that change state (speed change, aspect ratio cycle) use `this.message(text)` to emit an OSD notification. This calls `player.displayMessage(text)` if present, and always emits `'display-message'` on the player so a custom OSD widget can subscribe:

```ts
player.on('display-message', ({ text }) => {
  showOsd(text);
});
```
