# Auto Advance

`AutoAdvancePlugin` listens to the player's `ended` event and calls `player.next()` so the queue moves forward automatically when each item finishes.
Register it whenever you want binge-style queue playback.
Do not register it when an external orchestrator, such as Cast sync or a NoMercy Connect socket, drives `next()`, because that would produce duplicate advances.

```ts
import nmplayer from '@nomercy-entertainment/nomercy-video-player';
import { AutoAdvancePlugin } from '@nomercy-entertainment/nomercy-video-player/plugins';
```

Plugin id: `'auto-advance'`

## Options

| Option | Type | Default | Description |
| ------ | ---- | ------- | ----------- |
| `enabled` | `boolean` | `true` | Runtime toggle. Set to `false` to suspend auto-advance without unregistering the plugin. |

## Methods

### advance

```ts
advance(): Promise<void>
```

Force-advances to the next item immediately, regardless of whether the `ended` event has fired.
Useful for a "skip" button that needs to bypass the natural end-of-item trigger.

```ts
const plugin = player.getPlugin(AutoAdvancePlugin);

void plugin?.advance();
```

## Registration

```ts
import nmplayer from '@nomercy-entertainment/nomercy-video-player';
import { AutoAdvancePlugin } from '@nomercy-entertainment/nomercy-video-player/plugins';

const player = nmplayer('player')
  .addPlugin(AutoAdvancePlugin, { enabled: true })
  .setup({
    baseUrl: 'https://raw.githubusercontent.com/NoMercy-Entertainment/nomercy-media/master/Films',
    playlist: [
      {
        title: 'Sintel',
        url: '/Sintel.(2010)/Sintel.(2010).NoMercy.m3u8',
      },
      {
        title: 'Big Buck Bunny',
        url: '/Big.Buck.Bunny.(2008)/Big.Buck.Bunny.(2008).NoMercy.m3u8',
      },
      {
        title: 'Tears of Steel',
        url: '/Tears.of.Steel.(2012)/Tears.of.Steel.(2012).NoMercy.m3u8',
      },
    ],
  });
```

To suspend auto-advance at runtime, for example while showing a binge-watching prompt, retrieve the plugin instance and call `options()` with a partial update:

```ts
const plugin = player.getPlugin(AutoAdvancePlugin);

if (plugin) {
  plugin.options({ enabled: false });

  // Re-enable after the user confirms.
  plugin.options({ enabled: true });
}
```
