`TouchZonesPlugin` renders a transparent tap-zone overlay that intercepts touch events before they reach the video element. Register it alongside `DesktopUiPlugin` for mobile or hybrid pointer/touch deployments. It provides double-tap to seek on the left/right edges, single-tap to toggle controls, and centre double-tap to toggle fullscreen.

## Plugin id

`'touch-zones'`

## Import

```ts
import { TouchZonesPlugin } from '@nomercy-entertainment/nomercy-video-player/plugins';
import type { TouchZonesOptions } from '@nomercy-entertainment/nomercy-video-player/plugins';
```

## What it does

`TouchZonesPlugin` renders a transparent tap-zone overlay that sits at `z-index: 10` — above the video element but below the DesktopUi controls overlay at `z-index: 20`. Pointer events on the tap zones are intercepted before they reach the video element, but control buttons on the desktop-ui layer remain clickable.

### Layout

A 3-column × 6-row CSS grid:

| Column      | Content                      |
| ----------- | ---------------------------- |
| Left third  | Seek backward zone           |
| Centre      | Play/pause + fullscreen zone |
| Right third | Seek forward zone            |

On mobile (detected via `ontouchstart` / `maxTouchPoints`), two extra zones appear in the centre column:

- Rows 1–2: volume up
- Rows 5–6: volume down

The play/pause zone is compressed to rows 3–5 on mobile.

### Tap behaviour

| Zone                 | Single tap                  | Double tap                  |
| -------------------- | --------------------------- | --------------------------- |
| Left                 | Show/hide controls (toggle) | Seek backward `seekSeconds` |
| Right                | Show/hide controls (toggle) | Seek forward `seekSeconds`  |
| Centre               | Toggle play/pause           | Toggle fullscreen           |
| Volume up (mobile)   | Show/hide controls          | Volume up                   |
| Volume down (mobile) | Show/hide controls          | Volume down                 |

### Seek feedback indicator

Each seek zone shows a floating circular indicator on double-tap: a chevron icon and a cumulative label (e.g. `+30s` after three rapid taps). The indicator auto-collapses 1 second after the last tap in a burst.

## Options

```ts
interface TouchZonesOptions {
  /** Milliseconds between taps that still counts as a double-tap. Default 300. */
  doubleTapThreshold?: number;
  /** @deprecated Use doubleTapThreshold. */
  doubleClickDelay?: number;
  /** Seconds to seek on double-tap. Default 10. */
  seekSeconds?: number;
}
```

| Option               | Type     | Default | Description                                                |
| -------------------- | -------- | ------- | ---------------------------------------------------------- |
| `doubleTapThreshold` | `number` | `300`   | Maximum milliseconds between taps for double-tap detection |
| `seekSeconds`        | `number` | `10`    | Seconds to seek on a double-tap                            |

## Registration

```ts
import nmplayer from '@nomercy-entertainment/nomercy-video-player';
import {
  DesktopUiPlugin,
  TouchZonesPlugin,
} from '@nomercy-entertainment/nomercy-video-player/plugins';

const player = nmplayer('player')
  .addPlugin(DesktopUiPlugin)
  .addPlugin(TouchZonesPlugin, { seekSeconds: 10 })
  .setup({
    baseUrl: 'https://raw.githubusercontent.com/NoMercy-Entertainment/nomercy-media/master/Films',
    playlist: [
      {
        title: 'Sintel',
        url: '/Sintel.(2010)/Sintel.(2010).NoMercy.m3u8',
      },
    ],
  });
```

Register TouchZonesPlugin after DesktopUiPlugin to ensure the `z-index` layering is correct.

## Integration with DesktopUi

The TouchZonesPlugin emits `player.emit('activity', { active })` to notify DesktopUiPlugin to show or hide the controls overlay. Both plugins coordinate via this shared activity event — the controls auto-hide timer in DesktopUi resets on each `activity: true` emission.
