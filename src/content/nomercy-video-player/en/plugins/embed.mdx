## Plugin id

`'embed'`

## Import

```ts
import { EmbedPlugin } from '@nomercy-entertainment/nomercy-video-player/plugins';
import type {
  EmbedOptions,
  EmbedCommand,
  EmbedEventMessage,
} from '@nomercy-entertainment/nomercy-video-player/plugins';
```

## What it does

`EmbedPlugin` is a direct re-export of the kit's shared `EmbedPlugin`. It provides a `postMessage`-based control API that allows a parent page to control a player embedded in an `<iframe>`.

When registered, the plugin listens for `window.message` events from the parent frame. Commands arriving as `EmbedCommand` objects are dispatched to the local player. Player events are forwarded back to the parent as `EmbedEventMessage` objects.

This plugin is intended for embedding the player in third-party contexts — for example, a CMS widget, a dashboard embed, or a no-code page builder.

## Options

```ts
interface EmbedOptions {
  /**
   * Allowed origin(s) for postMessage. Use '*' for any origin (not recommended for production).
   * A single string or an array of strings. Omitting means no origins are allowed to send commands.
   */
  allowedOrigins?: string | string[];
  /** Player event names to forward to the host page. Defaults to ready/play/pause/ended/time/volume/mute. */
  forwardEvents?: string[];
  /** Apply iframe UI adjustments (smaller controls etc.). Defaults to true inside an iframe. */
  applyIframeTweaks?: boolean;
}
```

| Option            | Type                  | Default | Description                                                                                        |
| ----------------- | --------------------- | ------- | -------------------------------------------------------------------------------------------------- |
| `allowedOrigins`  | `string \| string[]`  | `[]`    | Origin(s) allowed to send commands. Empty = accept nothing. `'*'` = accept any (dev only)         |
| `forwardEvents`   | `string[]`            | see above | Player events forwarded to host page as `nm:event` messages                                     |
| `applyIframeTweaks` | `boolean`           | `true` in iframe | Suppress popout button and apply compact controls when embedded                         |

## EmbedCommand

Commands sent from the parent page to the embedded player. All commands use `type: 'nm:command'` as the envelope:

| Command                                               | Description                     |
| ----------------------------------------------------- | ------------------------------- |
| `{ type: 'nm:command', action: 'play' }`              | Call `player.play()`            |
| `{ type: 'nm:command', action: 'pause' }`             | Call `player.pause()`           |
| `{ type: 'nm:command', action: 'stop' }`              | Call `player.stop()`            |
| `{ type: 'nm:command', action: 'seek', time: number }`| Seek to `time` seconds          |
| `{ type: 'nm:command', action: 'volume', level: number }` | Set volume `level` (0–100)  |
| `{ type: 'nm:command', action: 'mute' }`              | Mute audio                      |
| `{ type: 'nm:command', action: 'unmute' }`            | Unmute audio                    |
| `{ type: 'nm:command', action: 'next' }`              | Advance to next queue item      |
| `{ type: 'nm:command', action: 'previous' }`          | Return to previous queue item   |

## Registration

```ts
import nmplayer from '@nomercy-entertainment/nomercy-video-player';
import { EmbedPlugin } from '@nomercy-entertainment/nomercy-video-player/plugins';

// Inside the iframe:
const player = nmplayer('player')
  .addPlugin(EmbedPlugin, { allowedOrigins: 'https://example.com' })
  .setup({
    baseUrl: 'https://raw.githubusercontent.com/NoMercy-Entertainment/nomercy-media/master/Films',
    playlist: [
      {
        title: 'Sintel',
        url: '/Sintel.(2010)/Sintel.(2010).NoMercy.m3u8',
      },
    ],
  });
```

```js
// In the parent page:
const iframe = document.querySelector('iframe');

iframe.contentWindow.postMessage(
  { type: 'nm:command', action: 'play' },
  'https://player.example.com',
);
iframe.contentWindow.postMessage(
  { type: 'nm:command', action: 'seek', time: 120 },
  'https://player.example.com',
);
```
