## Plugin id

`'embed'`

## Import

```ts
import { EmbedPlugin } from '@nomercy-entertainment/nomercy-video-player/plugins';
import type {
  EmbedOptions,
  EmbedCommand,
  EmbedEventMessage,
} from '@nomercy-entertainment/nomercy-video-player/plugins';
```

## What it does

`EmbedPlugin` is a direct re-export of the kit's shared `EmbedPlugin`. It provides a `postMessage`-based control API that allows a parent page to control a player embedded in an `<iframe>`.

When registered, the plugin listens for `window.message` events from the parent frame. Commands arriving as `EmbedCommand` objects are dispatched to the local player. Player events are forwarded back to the parent as `EmbedEventMessage` objects.

This plugin is intended for embedding the player in third-party contexts — for example, a CMS widget, a dashboard embed, or a no-code page builder.

## Options

```ts
interface EmbedOptions {
  /** Allowed origin for postMessage. Use '*' for any origin (not recommended for production). */
  allowedOrigin?: string;
}
```

| Option          | Type     | Default | Description                                                                           |
| --------------- | -------- | ------- | ------------------------------------------------------------------------------------- |
| `allowedOrigin` | `string` | `'*'`   | Restricts which parent origins can send commands. Use a specific origin in production |

## EmbedCommand

Commands sent from the parent page to the embedded player:

| Command                                   | Description                 |
| ----------------------------------------- | --------------------------- |
| `{ type: 'play' }`                        | Call `player.play()`        |
| `{ type: 'pause' }`                       | Call `player.pause()`       |
| `{ type: 'stop' }`                        | Call `player.stop()`        |
| `{ type: 'seek', time: number }`          | Seek to `time` seconds      |
| `{ type: 'volume', level: number }`       | Set volume to `level` (0–1) |
| `{ type: 'mute' }`                        | Mute audio                  |
| `{ type: 'unmute' }`                      | Unmute audio                |
| `{ type: 'fullscreen', active: boolean }` | Enter or exit fullscreen    |

## Registration

```ts
import nmplayer from '@nomercy-entertainment/nomercy-video-player';
import { EmbedPlugin } from '@nomercy-entertainment/nomercy-video-player/plugins';

// Inside the iframe:
const player = nmplayer('player')
  .addPlugin(EmbedPlugin, { allowedOrigin: 'https://example.com' })
  .setup({
    baseUrl: 'https://raw.githubusercontent.com/NoMercy-Entertainment/nomercy-media/master/Films',
    playlist: [
      {
        title: 'Sintel',
        url: '/Sintel.(2010)/Sintel.(2010).NoMercy.m3u8',
      },
    ],
  });
```

```js
// In the parent page:
const iframe = document.querySelector('iframe');

iframe.contentWindow.postMessage({ type: 'play' }, 'https://player.example.com');
iframe.contentWindow.postMessage({ type: 'seek', time: 120 }, 'https://player.example.com');
```
