## Plugin id

`'tab-leader'`

## Import

```ts
import { TabLeaderPlugin } from '@nomercy-entertainment/nomercy-video-player/plugins';
import type { TabLeaderOptions } from '@nomercy-entertainment/nomercy-video-player/plugins';
```

## What it does

`TabLeaderPlugin` is a direct re-export of the kit's shared `TabLeaderPlugin`. It uses the **Web Locks API** (`navigator.locks`) to ensure only one tab plays at a time on the same origin.

How it works:

1. On `use()` the plugin calls `navigator.locks.request(key, callback)`.
2. The browser gives the lock to the first tab that requests it. That tab emits `'leader-acquired'` and becomes the active player.
3. Other tabs queue behind it. When the leader tab closes or calls `releaseLock()`, the browser hands the lock to the next queued tab.

In environments without `navigator.locks` (Safari < 15.4) the plugin emits `'unsupported'` and becomes a no-op — playback is unaffected.

## Options

```ts
interface TabLeaderOptions {
  /**
   * What to do when this tab loses leadership.
   * 'pause' (default) — calls player.pause().
   * 'mute' — calls player.mute() so audio stops but buffering continues.
   */
  onLost?: 'pause' | 'mute';
  /**
   * When true, the tab attempts to reclaim leadership whenever it becomes
   * visible (document.visibilitychange). Default true.
   */
  handoffOnVisible?: boolean;
  /**
   * Override the lock key. Defaults to 'nomercy-player-leader' (global to the origin).
   * Return a per-player or per-session string to scope leadership narrowly.
   */
  getLockKey?: () => string;
}
```

| Option             | Type               | Default                    | Description                                                        |
| ------------------ | ------------------ | -------------------------- | ------------------------------------------------------------------ |
| `onLost`           | `'pause' \| 'mute'` | `'pause'`                 | Action to take when this tab loses the leader lock                 |
| `handoffOnVisible` | `boolean`          | `true`                     | Re-request the lock when the tab becomes visible                   |
| `getLockKey`       | `() => string`     | `'nomercy-player-leader'`  | Factory returning the lock key — use to scope to a specific player |

## Events

```ts
interface TabLeaderEvents {
  'leader-acquired': void;
  'leader-released': void;
  'leader-lost': { reason: 'visibility' | 'request' | 'browser' };
  'leader-requested': void;
  'unsupported': void;
}
```

| Event                                | Payload                                         | Description                                                   |
| ------------------------------------ | ----------------------------------------------- | ------------------------------------------------------------- |
| `'leader-acquired'`                  | `void`                                          | This tab now holds the lock and is the active player          |
| `'leader-released'`                  | `void`                                          | Lock released voluntarily via `releaseLock()` or dispose      |
| `'leader-lost'`                      | `{ reason: 'visibility' \| 'request' \| 'browser' }` | Lock lost involuntarily                               |
| `'leader-requested'`                 | `void`                                          | A lock-acquire attempt is in progress                         |
| `'unsupported'`                      | `void`                                          | Web Locks not available; plugin is inert                      |

## Registration

```ts
import nmplayer from '@nomercy-entertainment/nomercy-video-player';
import { TabLeaderPlugin } from '@nomercy-entertainment/nomercy-video-player/plugins';

const player = nmplayer('player')
  .addPlugin(TabLeaderPlugin, { onLost: 'pause' })
  .setup({
    baseUrl: 'https://raw.githubusercontent.com/NoMercy-Entertainment/nomercy-media/master/Films',
    playlist: [
      {
        url: '/Sintel.(2010)/Sintel.(2010).NoMercy.m3u8',
      },
    ],
  });

player.on('plugin:tab-leader:leader-acquired', () => {
  console.log('This tab is the leader');
});

player.on('plugin:tab-leader:leader-lost', ({ reason }) => {
  console.log('Lost leadership:', reason);
});
```

## Scoping to a specific player

By default the lock key is global to the origin — one tab plays at a time across all instances. Pass `getLockKey` to scope it to a server ID or session:

```ts
player.addPlugin(TabLeaderPlugin, {
  getLockKey: () => `nomercy-leader-${serverId}`,
});
```

## Methods

### isLeader

```ts
plugin.isLeader(): boolean
```

Returns `true` when this tab currently holds the lock.

### requestLock

```ts
plugin.requestLock(): Promise<void>
```

Queue a lock-acquire request. Resolves when the lock is granted. Calling while an election is already in progress is a no-op.

### releaseLock

```ts
plugin.releaseLock(): void
```

Voluntarily release the leader lock. Emits `'leader-released'`. The next queued tab acquires the lock immediately.
