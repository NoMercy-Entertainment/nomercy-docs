## Plugin id

`'live-transcoding'`

## Import

```ts
import { LiveTranscodingPlugin } from '@nomercy-entertainment/nomercy-video-player/plugins';
import type { LiveTranscodingOptions, LiveTranscodingEvents } from '@nomercy-entertainment/nomercy-video-player/plugins';
```

## What it does

`LiveTranscodingPlugin` coordinates the player with a server that transcodes video on-demand, segment by segment. It:

- Opens a WebSocket to a transcoding control endpoint (auto-closed on dispose)
- Gates `beforeLoad` until the server reports the requested position is encoded
- Gates `beforeSeek` — if the seek target is ahead of the transcoder's write head, waits (up to `seekTimeoutMs`) before releasing the player
- Applies loader backpressure when the buffer is full
- Exposes `transcodedTo()` for the current transcoder write head position

Without a control URL the plugin is completely inert — no connections are opened and no gates are applied.

## Options

```ts
interface LiveTranscodingOptions {
  /** Server endpoint that owns the transcoding job lifecycle (WebSocket). */
  controlUrl?: string;
  /** Alias of controlUrl. Either one works. */
  wsUrl?: string;
  /** Polling fallback interval in ms for environments without WebSocket. */
  pollIntervalMs?: number;
  /** Seconds of buffer beyond currentTime before resuming after backpressure. */
  resumeAheadSeconds?: number;
  /** Max seconds to wait for the transcoder to reach the seek target. Default 10000. */
  seekTimeoutMs?: number;
  /** Quality / bitrate preference hint sent to the encoder. */
  preferredHeight?: number;
}
```

| Option | Type | Default | Description |
|---|---|---|---|
| `controlUrl` | `string` | — | WebSocket URL of the transcoding server |
| `wsUrl` | `string` | — | Alias for `controlUrl` |
| `seekTimeoutMs` | `number` | `10000` | Seek gate timeout in milliseconds |
| `preferredHeight` | `number` | — | Preferred output height hint sent to the encoder |

## Events

```ts
interface LiveTranscodingEvents {
  'job:started':        { jobId: string; sourceUrl: string };
  'job:progress':       { jobId: string; transcodedSeconds: number; totalSeconds?: number; variantsReady: string[] };
  'job:variant-ready':  { jobId: string; variant: string; bandwidth: number };
  'job:ready-to-play':  { jobId: string };
  'job:error':          { jobId: string; error: Error };
  'job:complete':       { jobId: string };
  'backpressure:apply': { reason: 'buffer-full' | 'encoder-stall' };
  'backpressure:release': void;
}
```

## Server message protocol

The server sends JSON messages over the WebSocket. The plugin recognises the following `type` values:

| `type` | Effect |
|---|---|
| `'started'` | Emits `'job:started'`. Sets `currentJobId`. |
| `'progress'` | Updates `transcodedTo` state. Emits `'job:progress'`. Releases any pending seek gate if the target is now reachable. |
| `'ready-to-play'` | Emits `'job:ready-to-play'`. |
| `'complete'` | Emits `'job:complete'`. |

## Registration

```ts
import nmplayer from '@nomercy-entertainment/nomercy-video-player';
import { LiveTranscodingPlugin } from '@nomercy-entertainment/nomercy-video-player/plugins';

const player = nmplayer('player')
  .addPlugin(LiveTranscodingPlugin, {
    controlUrl: 'wss://encode.nomercy.tv/jobs/sintel',
    seekTimeoutMs: 15_000,
  })
  .setup({
    playlist: [{
      title: 'Sintel',
      url: 'https://raw.githubusercontent.com/NoMercy-Entertainment/nomercy-media/master/Films/Sintel.(2010)/Sintel.(2010).NoMercy.m3u8',
    }],
  });

player.on('plugin:live-transcoding:job:progress', ({ transcodedSeconds }) => {
  console.log('Transcoded to:', transcodedSeconds, 's');
});
```

## Methods

### transcodedTo

```ts
plugin.transcodedTo(): number
```

Returns the current transcoder write head in seconds. Updated by `'progress'` messages from the server.
