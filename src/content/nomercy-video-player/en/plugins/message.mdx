## Plugin id

`'message'`

## Import

```ts
import { MessagePlugin } from '@nomercy-entertainment/nomercy-video-player/plugins';
import type { MessageOptions } from '@nomercy-entertainment/nomercy-video-player/plugins';
```

## What it does

`MessagePlugin` is a direct re-export of the kit's shared `MessagePlugin`. It provides a lightweight broadcast channel between player instances that live in different tabs or iframes but share the same origin.

Use cases:

- Pausing all other tabs when a video starts playing in one tab
- Notifying a dashboard that playback state changed
- Coordinating multiple embedded players on the same page

The plugin uses the `BroadcastChannel` API when available and falls back to `localStorage` events for older browsers.

## Options

```ts
interface MessageOptions {
  /** BroadcastChannel name. All players with the same channel name receive each other's messages. */
  channel?: string;
}
```

| Option    | Type     | Default            | Description                                                             |
| --------- | -------- | ------------------ | ----------------------------------------------------------------------- |
| `channel` | `string` | `'nomercy-player'` | Channel name. Players on the same channel receive each other's messages |

## Registration

```ts
import nmplayer from '@nomercy-entertainment/nomercy-video-player';
import { MessagePlugin } from '@nomercy-entertainment/nomercy-video-player/plugins';

const player = nmplayer('player')
  .addPlugin(MessagePlugin, { channel: 'nomercy-player' })
  .setup({
    playlist: [
      {
        url: 'https://raw.githubusercontent.com/NoMercy-Entertainment/nomercy-media/master/Films/Sintel.(2010)/Sintel.(2010).NoMercy.m3u8',
      },
    ],
  });
```

When this player starts playing, other player instances on the same channel receive a `'play'` message and can pause themselves:

```ts
// In another tab / instance
player.on('message', ({ type, payload }) => {
  if (type === 'play') {
    player.pause();
  }
});
```
