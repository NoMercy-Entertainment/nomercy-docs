## Plugin id

`'message'`

## Import

```ts
import { MessagePlugin } from '@nomercy-entertainment/nomercy-video-player/plugins';
import type { MessageOptions, MessageInput } from '@nomercy-entertainment/nomercy-video-player/plugins';
```

## What it does

`MessagePlugin` is a direct re-export of the kit's shared `MessagePlugin`. It provides a toast and persistent overlay surface inside the player container. Other plugins (for example `KeyHandlerPlugin`) call `player.displayMessage(text)` to show OSD notifications such as "Speed: 1.5×" or "Subtitles off". Consumer code can also call the plugin directly via `player.getPlugin(MessagePlugin)`.

Two display modes:

- **Transient** (`show`, `queue`) — text appears for a configurable duration then hides automatically. A new call replaces any in-flight toast and resets the timer.
- **Persistent** (`displayPersistent`, `removePersistent`) — a named overlay element that stays until explicitly removed. Useful for blocking states such as an autoplay-blocked "Tap to play" prompt.

The toast surface carries `role="status"` and `aria-live="polite"` so screen readers announce changes without stealing focus.

## Options

```ts
interface MessageOptions {
  /** Default display duration in milliseconds for transient toasts. Default 3000. */
  durationMs?: number;
  /** CSS selector used to locate an existing mount element. When absent the plugin creates a div inside the player container. */
  mountSelector?: string;
}
```

| Option          | Type     | Default | Description                                                                    |
| --------------- | -------- | ------- | ------------------------------------------------------------------------------ |
| `durationMs`    | `number` | `3000`  | Default display duration for transient toasts when no per-message value is set |
| `mountSelector` | `string` | —       | CSS selector for an existing element to use as the toast surface               |

## Registration

```ts
import nmplayer from '@nomercy-entertainment/nomercy-video-player';
import { MessagePlugin } from '@nomercy-entertainment/nomercy-video-player/plugins';

const player = nmplayer('player')
  .addPlugin(MessagePlugin, { durationMs: 2500 })
  .setup({
    baseUrl: 'https://raw.githubusercontent.com/NoMercy-Entertainment/nomercy-media/master/Films',
    playlist: [
      {
        title: 'Sintel',
        url: '/Sintel.(2010)/Sintel.(2010).NoMercy.m3u8',
      },
    ],
  });
```

## Methods

### show

```ts
plugin.show(text: string, ms?: number): void
```

Display a transient toast for `ms` milliseconds (defaults to `opts.durationMs ?? 3000`). Replaces any currently visible toast immediately.

### hide

```ts
plugin.hide(): void
```

Hide the current toast and cancel any pending auto-hide timer.

### displayMessage

```ts
plugin.displayMessage(data: MessageInput, ms?: number): void
```

Accepts a plain string or a `{ text, durationMs? }` object. Kept for compatibility with callers that pass structured message objects; prefer `show()` for new call sites.

### queue

```ts
plugin.queue(messages: ReadonlyArray<MessageInput>): void
```

Play a sequence of messages back-to-back, each for its own duration. Calling `queue()` again or `clear()` cancels any in-flight run immediately.

```ts
const msg = player.getPlugin(MessagePlugin);
msg?.queue([
  'Loading…',
  { text: 'Almost there!', durationMs: 1500 },
  'Done.',
]);
```

### clear

```ts
plugin.clear(): void
```

Cancel any in-flight `queue()`, hide the current toast, and reset all pending timers. Persistent messages are unaffected.

### displayPersistent

```ts
plugin.displayPersistent(text: string, id: string): void
```

Display a named persistent overlay. If a persistent message with `id` already exists its text is updated in-place.

### removePersistent

```ts
plugin.removePersistent(id: string): void
```

Remove a persistent message by its `id`. No-ops when no message with that id exists.

## Showing a toast from consumer code

```ts
player.on('ended', () => {
  const msg = player.getPlugin(MessagePlugin);
  msg?.show('Playback complete', 3000);
});
```

The `KeyHandlerPlugin` uses `player.displayMessage(text)` internally for OSD notifications (speed changes, aspect ratio, etc.). Registering `MessagePlugin` is all that is needed to receive those.
