## Plugin id

`'desktop-ui'`

## Import

```ts
import { DesktopUiPlugin } from '@nomercy-entertainment/nomercy-video-player/plugins';
import type { DesktopUiOptions } from '@nomercy-entertainment/nomercy-video-player/plugins';
```

## What it does

`DesktopUiPlugin` renders the complete video player controls overlay as a DOM tree mounted inside `.nomercyplayer`. It is a v2-native rewrite of the v1 desktop UI and provides:

- Top bar — title, show/season/episode info, back button
- Progress bar — with chapter markers, buffer indicator, scrubber, hover-time label, and sprite thumbnail preview
- Control bar — play/pause, skip buttons, volume slider, mute toggle, speed selector, subtitle/audio/quality menus, theater, PiP, fullscreen
- Menu panes — speed picker, quality picker, subtitle picker, audio picker, playlist, subtitle style settings, aspect ratio selector
- Seek-feedback animations
- Activity detection — controls auto-hide after inactivity; tap/move to reveal
- Keyboard shortcut sheet (toggle with `?`)

The back button in the top bar only renders when at least one `'back'` event listener is registered.

Hover thumbnails on the progress bar use the `previewSpriteUrl` from the active playlist item automatically — no extra configuration needed.

## CSS state classes

State CSS classes are applied to `.nomercyplayer` (the player's container element):

| State                  | CSS class on `.nomercyplayer` |
| ---------------------- | ----------------------------- |
| Playing                | `nm-playing`                  |
| Paused                 | `nm-paused`                   |
| Buffering              | `nm-buffering`                |
| Ended                  | `nm-ended`                    |
| Fullscreen             | `nm-fullscreen`               |
| PiP active             | `nm-pip`                      |
| Theater mode           | `nm-theater`                  |
| Controls visible       | `nm-controls-visible`         |
| Controls hidden (idle) | `nm-controls-hidden`          |
| Subtitles on           | `nm-subtitles-on`             |

Do not add `nm-` or `nmplayer-` prefixed classes to child elements from outside the plugin.

## Inactivity hiding

Controls auto-hide after 4 seconds of inactivity. Mouse movement, keyboard input, or touch interaction resets the timer.

## Options

```ts
interface DesktopUiOptions {
  /** Hide the title bar at the top of the player. Default: false. */
  hideTitle?: boolean;
  /** Disable click/tap on the video area to toggle pause. Default: false. */
  disableClickToPause?: boolean;
  /** Milliseconds of inactivity before controls hide. Default: 4000. */
  inactivityMs?: number;
  /** Base URL prepended to relative image paths in the player UI. */
  imageBaseUrl?: string;
  /** Per-button opt-in / opt-out overrides. */
  buttons?: DesktopUiButtonOptions;
}
```

## Registration

```ts
import nmplayer from '@nomercy-entertainment/nomercy-video-player';
import {
  DesktopUiPlugin,
  SubtitleOverlayPlugin,
} from '@nomercy-entertainment/nomercy-video-player/plugins';

const player = nmplayer('player')
  .addPlugin(DesktopUiPlugin)
  .addPlugin(SubtitleOverlayPlugin)
  .setup({
    baseUrl: 'https://raw.githubusercontent.com/NoMercy-Entertainment/nomercy-media/master/Films',
    playlist: [
      {
        title: 'Sintel',
        url: '/Sintel.(2010)/Sintel.(2010).NoMercy.m3u8',
        image: 'https://image.tmdb.org/t/p/w780/q2bVM5z90tCGbmXYtq2J38T5hSX.jpg',
        previewSpriteUrl:
          'https://raw.githubusercontent.com/NoMercy-Entertainment/nomercy-media/master/Films/Sintel.(2010)/thumbs_256x109.vtt',
        chapters: [
          { title: 'Intro', start: 0, end: 90 },
          { title: 'Act 1', start: 90, end: 600 },
        ],
      },
    ],
  });

// Wire the back button — it only renders when this listener exists
player.on('back', () => {
  history.back();
});
```

## DOM tree

The plugin builds its tree inside `.nomercyplayer > .nomercyplayer-overlay`:

```
overlay
  ├─ top-bar > title + back button
  ├─ center  > spinner + center play/pause button
  └─ bottom-bar
      ├─ bottom-bar-shadow
      ├─ top-row (slider-bar)
      │   ├─ slider-buffer
      │   ├─ slider-hover
      │   ├─ slider-progress
      │   └─ chapter-progress × N
      └─ bottom-row
          ├─ left controls (play, prev, next, time, volume)
          ├─ center (space)
          └─ right controls (speed, quality, subtitles, audio, playlist, theater, pip, fullscreen)
```

## Default keyboard shortcuts

`KeyHandlerPlugin` is included with `DesktopUiPlugin`. Default bindings:

| Key         | Action                  |
| ----------- | ----------------------- |
| Space / `k` | Toggle playback         |
| `f`         | Toggle fullscreen       |
| `m`         | Toggle mute             |
| `←` / `→`   | Seek ±10 seconds        |
| `↑` / `↓`   | Volume ±5 (0–100 scale) |
| `c`         | Cycle subtitle tracks   |
| `?`         | Toggle shortcut sheet   |

## Customizing the UI

The UI uses standard DOM elements styled by the player's CSS. Override styles by targeting `.nomercyplayer` and its children in your app stylesheet.

To replace specific behaviors without replacing the entire plugin, subclass and override the protected group methods:

```ts
import { DesktopUiPlugin } from '@nomercy-entertainment/nomercy-video-player/plugins';

class MyDesktopUi extends DesktopUiPlugin {
  static readonly id = 'desktop-ui';

  protected addPlaybackHooks(): void {
    super.addPlaybackHooks();
    // add extra behavior
  }
}

player.addPlugin(MyDesktopUi);
```

## TV UI

For 10-foot TV remote navigation, use `TvUiPlugin` instead. It is optimized for D-pad navigation and does not mount the desktop pointer-based controls.

```ts
import { TvUiPlugin } from '@nomercy-entertainment/nomercy-video-player/plugins';

player.addPlugin(TvUiPlugin);
```

## UX rules

- Pointer input (click) on multi-state buttons opens a menu. Cycle actions (cycleAspectRatio, cycleSubtitles) are for keyboard / remote-control contexts only — the control bar uses menus for those features.
- Theater, PiP, and Fullscreen are binary toggles — direct action on click.
- Menus close when clicking outside them or when another menu opens.

## Events emitted

The desktop UI emits internal events for cross-plugin coordination:

| Event                                  | Description                                              |
| -------------------------------------- | -------------------------------------------------------- |
| `'activity'`                           | `{ active: boolean }` — controls show/hide state changed |
| `'plugin:desktop-ui:shortcuts-toggle'` | Keyboard shortcut sheet toggled (via `?` key)            |
