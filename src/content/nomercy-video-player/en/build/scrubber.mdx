# Build a Player: The Scrubber

[Step 1](/nomercy-video-player/build/shell) mounted the real chrome. Nothing new to register here — this step looks closer at one piece of what that mount already gave you: the scrubber.

## Not a plain range input

The progress bar isn't a bare `<input type="range">` — `DesktopUiPlugin` reads `chapters()` (see [Chapters](/nomercy-video-player/tour/chapters)) off the current item and, when it's non-empty, splits the bar into one segment per chapter, each with its own buffer fill. `sintel` carries real chapter marks, so the segments below are real, not simulated. An item with no chapters gets a single unsegmented bar — same component, no configuration needed either way.

## Chapter navigation follows the data

`buttons.chapterPrev` / `chapterNext` both default to `true`, but they gate on content: no chapters, no buttons, regardless of the option. Setting them explicitly below doesn't change anything visible — it's here to name the two toggles that exist, in case a consumer wants to hide chapter navigation on an item that has marks but shouldn't offer to skip between them (a live stream with ad-break markers, say):

{/* partial: the `plugins` property to graft onto setup(), not a standalone program — the complete version is in "See it running" below */}

```ts
plugins: [
  {
    plugin: DesktopUiPlugin,
    opts: { buttons: { chapterPrev: true, chapterNext: true } },
  },
],
```
