# Build a Player: Full Plugin

The last step: the touch layer.

A phone player is not a mouse player. Seeking is a double-tap on the left or right half of the screen, play and pause is a tap in the middle, and a stray tap dismisses the controls.

[TouchZonesPlugin](/nomercy-video-player/plugins-adapters/touch-zones) ships those ideas. Here you build the core of it into your own plugin.

Two fields, one call, and one removal:

{/* partial */}

```ts
private center!: HTMLDivElement;      // NEW
private controlsVisible = false;      // NEW
// REMOVED: private centerButton — the center touch zone replaces it

override use(): void {
  // ...everything from step 9, minus createCenterButton()

  this.createTouchZones();  // NEW
}
```

## A grid under the controls

The touch layer is a 3x6 grid stretched over the whole frame, inserted as the overlay's FIRST child so every bar and button from the previous steps renders above it. Zones are grid cells; `isMobile()` picks the layout, phones get volume zones above and below the center:

{/* partial */}

```ts
this.overlay.insertBefore(center.get(), this.overlay.firstChild);
this.center = center.get();

if (this.player.isMobile()) {
  this.createTouchSeekBack({ x: { start: 1, end: 1 }, y: { start: 2, end: 6 } });
  this.createTouchPlayback({ x: { start: 2, end: 2 }, y: { start: 3, end: 5 } });
  this.createTouchSeekForward({ x: { start: 3, end: 3 }, y: { start: 2, end: 6 } });
  this.createTouchVolume('up', { x: { start: 2, end: 2 }, y: { start: 1, end: 3 } });
  this.createTouchVolume('down', { x: { start: 2, end: 2 }, y: { start: 5, end: 7 } });
}
else {
  this.createTouchSeekBack({ x: { start: 1, end: 2 }, y: { start: 2, end: 6 } });
  this.createTouchPlayback({ x: { start: 2, end: 3 }, y: { start: 2, end: 6 } });
  this.createTouchSeekForward({ x: { start: 3, end: 4 }, y: { start: 2, end: 6 } });
}
```

Each zone is one div placed by grid coordinates, `pointer-events-auto` on the zones only, so the layer itself never eats a click meant for the video:

{/* partial */}

```ts
private createTouchBox(id: string, pos: TouchZonePosition): HTMLDivElement {
  const box = this
    .createElement('div', `touch-box-${id}`)
    .addClasses([
      `touch-box-${id}`,
      'pointer-events-auto',
    ])
    .appendTo(this.center)
    .get();

  box.style.gridColumnStart = String(pos.x.start);
  box.style.gridColumnEnd = String(pos.x.end);
  box.style.gridRowStart = String(pos.y.start);
  box.style.gridRowEnd = String(pos.y.end);

  return box;
}
```

## Double-tap vs single-tap

One helper arbitrates: a second tap inside the window fires the double action and cancels the pending single; otherwise the single action fires after the window closes. The pending timer goes through `this.timeout()`, so a plugin disposed mid-window never fires into a dead UI:

{/* partial */}

```ts
private doubleTap(onDouble: (event: Event) => void, onSingle?: (event: Event) => void): (event: Event) => void {
  let lastTap = 0;
  let singleTimer: number | undefined;

  return (event: Event) => {
    const now = performance.now();
    const sinceLast = now - lastTap;

    if (sinceLast > 0 && sinceLast < DOUBLE_TAP_DELAY_MS) {
      event.preventDefault();
      onDouble(event);
      if (singleTimer !== undefined)
        clearTimeout(singleTimer);
    }
    else {
      singleTimer = this.timeout(() => onSingle?.(event), DOUBLE_TAP_DELAY_MS);
    }
    lastTap = now;
  };
}
```

Each seek zone pairs the helper with a ripple that flashes the amount and hides itself 600ms later:

{/* partial */}

```ts
private createTouchSeekBack(pos: TouchZonePosition): void {
  const box = this.createTouchBox('seek-back', pos);
  const ripple = this.createSeekRipple(box, 'left');

  this.listen(box, 'click', this.doubleTap(
    () => {
      void this.player.rewind(10);
      ripple.show('10 seconds');
    },
    () => this.dismissControls(),
  ));
}
```

(`createTouchSeekForward` is its mirror: `forward(10)`, ripple side `'right'`.) The ripple builder returns a tiny `{ show }` handle instead of leaking its elements. The shape is rounded on the inner edge, anchored on the arrow side, with its text set on each call to `show`:

{/* partial */}

```ts
private createSeekRipple(parent: HTMLDivElement, side: 'left' | 'right'): { show: (text: string) => void } {
  const ripple = this
    .createElement('div', `seek-ripple-${side}`)
    .addClasses([
      'absolute',
      'inset-y-0',
      'w-1/3',
      'hidden',
      'flex-col',
      'items-center',
      'justify-center',
      'bg-white/10',
      'pointer-events-none',
    ])
    .appendTo(parent)
    .get();

  const text = this
    .createElement('p', `seek-ripple-text-${side}`)
    .addClasses([
      'text-white',
      'text-sm',
      'font-medium',
    ])
    .appendTo(ripple)
    .get();

  if (side === 'left') {
    ripple.style.borderRadius = '0 50% 50% 0';
    ripple.style.left = '0px';
  }
  else {
    ripple.style.borderRadius = '50% 0 0 50%';
    ripple.style.right = '0px';
  }

  let hideTimer: number | undefined;
  return {
    show: (label: string): void => {
      text.innerText = label;
      ripple.style.display = 'flex';
      if (hideTimer !== undefined)
        clearTimeout(hideTimer);
      hideTimer = this.timeout(() => {
        ripple.style.display = 'none';
      }, 600);
    },
  };
}
```

The center zone replaces step 2's center play button, which is why `createCenterButton()` left the class. It handles three gestures and one state:

| Interaction | Result |
| --- | --- |
| Single tap, while controls are up | Toggles playback |
| Double tap | Toggles fullscreen |
| Playback paused | The big play glyph shows |

{/* partial */}

```ts
private createTouchPlayback(pos: TouchZonePosition): void {
  const box = this.createTouchBox('playback', pos);
  this.addClasses(box, [
    'flex',
    'items-center',
    'justify-center',
  ]);

  this.listen(box, 'click', this.doubleTap(
    () => this.player.toggleFullscreen(),
    () => {
      if (this.controlsVisible) {
        this.player.togglePlayback();
      }
    },
  ));

  const playButton = this
    .createElement('span', 'big-play')
    .addClasses([
      'pointer-events-none',
      'text-white',
    ])
    .appendTo(box)
    .get();
  playButton.innerHTML = svgFromIcon(icons.bigPlay, 48);

  this.on('ready', () => { playButton.style.display = 'flex'; });
  this.on('pause', () => { playButton.style.display = 'flex'; });
  this.on('play', () => { playButton.style.display = 'none'; });
}
```

On mobile, the volume zones are the same double-tap arbitration around `volumeUp()` / `volumeDown()`:

{/* partial */}

```ts
private createTouchVolume(direction: 'up' | 'down', pos: TouchZonePosition): void {
  const box = this.createTouchBox(`vol-${direction}`, pos);

  this.listen(box, 'click', this.doubleTap(
    () => {
      if (direction === 'up') {
        void this.player.volumeUp();
      }
      else {
        void this.player.volumeDown();
      }
    },
    () => this.dismissControls(),
  ));
}
```

## Dismissing through the activity event

A single tap on a seek zone while the controls are up should hide them. [Step 1](/nomercy-video-player/build/shell) established who owns show-hide: the player tracks activity and the container classes follow the `activity` event. So the plugin dismisses by speaking that same language, and tracks visibility by listening to it, never by reading classes:

{/* partial */}

```ts
this.on('activity', ({ active }) => {
  this.controlsVisible = active;
});

private dismissControls(): void {
  if (this.controlsVisible) {
    this.player.emit('activity', { active: false });
  }
}
```

## What ten steps built

What you built:

- A shell on the player's own show-hide contract
- Transport, a scrubber with buffer fill and chapter ticks, the clock, and volume
- A title bar, a speed menu, and fullscreen
- The subtitle, audio, and quality menus
- A sprite seek preview with chapter titles
- A touch layer

Every line of it sits on the public surface:

- `togglePlayback()`, `seekByPercentage()`, `rewind()`, `forward()`, `volume()`, `toggleMute()`
- `item()`, `playbackRate()`, `toggleFullscreen()`, `subtitle()`, `audioTrack()`, `quality()`, `chapters()`, `this.fetch()`
- The `time` payload and the event bus throughout

No `dispose()` anywhere. The base cleans every element, listener and timer you registered.

If you would rather not own this surface, reach for the shipped pairing instead: [DesktopUiPlugin](/nomercy-video-player/plugins-adapters/desktop-ui) plus [TouchZonesPlugin](/nomercy-video-player/plugins-adapters/touch-zones). Together they cover the whole tutorial and more: a playlist panel, tooltips, keyboard shortcuts, theater, and PiP. Either way, now you know every line they run.
