# Build a Player: Fullscreen

[Step 4](/nomercy-video-player/build/subtitle-menu) added the subtitle menu. This is the last step: a fullscreen button, completing the overlay this tutorial has been building since [The Shell](/nomercy-video-player/build/shell).

## Request, then confirm

`toggleFullscreen()` flips `fullscreen()` through the platform's `FullscreenController` (`setup({ platform })`, defaulting to `browserPlatform`, the browser's own Fullscreen API underneath). Same pattern as every other button in this tutorial: the click only requests the change, the `'fullscreen'` event confirms it settled:

```ts
const fullscreenButton = player.createButton('my-fullscreen', 'Fullscreen', () => {
  player.toggleFullscreen();
});

const syncFullscreen = () => {
  const active = player.fullscreen() === FullscreenState.ON;
  fullscreenButton.textContent = active ? '⤢' : '⛶';
  fullscreenButton.setAttribute('aria-label', active ? 'Exit fullscreen' : 'Fullscreen');
};
player.on('fullscreen', syncFullscreen);
syncFullscreen();
```

Requesting fullscreen requires an actual user gesture, browsers reject a programmatic call outside a click handler, so nothing in `onReady()` calls it automatically; only the button's own click does.
