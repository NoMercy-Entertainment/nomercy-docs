# Build a Player: Fullscreen

[Step 4](/nomercy-video-player/build/subtitle-menu) added the subtitle picker. This is the last step: every remaining default-off button, turned on together, over a real three-item queue.

## The rest of the button set

`theater`, `pip`, `quality`, `audio`, `playlist`, and `aspectRatio` are the buttons the previous four steps left off. None of them need a hand-built click handler or a `toggleFullscreen()`/`fullscreen()` wrapper the way earlier versions of this page taught — `DesktopUiPlugin` already drives every one of those methods internally. Turning them on is the whole change:

{/* partial: the `plugins` property to graft onto setup(), not a standalone program — the complete version is in "See it running" below */}

```ts
plugins: [
  {
    plugin: DesktopUiPlugin,
    opts: {
      buttons: {
        theater: true,
        pip: true,
        quality: true,
        audio: true,
        playlist: true,
        subtitles: true,
        aspectRatio: true,
      },
    },
  },
  SubtitleOverlayPlugin,
],
```

## A real queue for the playlist button

A playlist button with one item is a button that does nothing — this step switches to `films`, the same three-item fixture [The Queue](/nomercy-video-player/tour/queue) uses, so the playlist panel has something real to list and `next()`/`previous()` have somewhere to go.

## What this tutorial built

Five steps, one real player: a shell, a chapter-aware scrubber, a configurable volume control, a subtitle picker backed by a real rendering plugin, and the complete button set. Every method behind every button is documented in full on the [Guided Tour](/nomercy-video-player/tour/transport) — this tutorial mounted the shipped chrome and configured it, it never reinvented it.
