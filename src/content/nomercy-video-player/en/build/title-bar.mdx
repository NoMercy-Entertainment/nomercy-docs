# Build a Player: Title Bar

The top bar has been empty since [step 1](/nomercy-video-player/build/shell). This step gives it a job: show what is playing.

## item() now, the item event later

`item()` reads the current playlist item synchronously; the `item` event fires every time the cursor moves to another one. A readout needs both, the value now and the updates later, so `createTitle()` renders once and subscribes once:

{/* partial */}

```ts
private createTitle(): void {
  this.titleLabel = this.player
    .createElement('div', 'title-display')
    .addClasses([
      'text-white',
      'text-sm',
      'font-medium',
      'truncate',
    ])
    .appendTo(this.topBar)
    .get();

  this.updateTitle();
  this.on('item', () => this.updateTitle());
}
```

## Movies and episodes read differently

`VideoPlaylistItem` carries `title` for everything, plus `show` / `season` / `episode` for episodic content. A movie shows its title; an episode shows the show, then `S1E4: Episode Title`:

{/* partial */}

```ts
private updateTitle(): void {
  const item = this.player.item();
  if (!item)
    return;

  let text = item.title;
  if (item.show) {
    text = item.show;
    if (item.season !== undefined && item.episode !== undefined) {
      text += ` - S${item.season}E${item.episode}: ${item.title}`;
    }
  }
  this.titleLabel.textContent = text ?? '';
}
```

`truncate` on the label is the safety net for long titles: one line, ellipsis, no wrapping over the video.
