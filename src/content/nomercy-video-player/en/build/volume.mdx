# Build a Player: Volume

[Step 2](/nomercy-video-player/build/scrubber) looked at the scrubber. This step is the volume control's one real option: `volumeSlider`.

## Three display modes

`DesktopUiPlugin`'s volume slider isn't a fixed layout — `volumeSlider` picks how it presents next to the mute button:

| Value | Behavior |
| --- | --- |
| `'horizontal'` | Inline, expands on hover. The default. |
| `'vertical'` | A popup above the mute button, toggled on click. |
| `'auto'` | Vertical under ~520 px container width, horizontal above it. |

The player below sets `volumeSlider: 'vertical'` — click the mute button's icon (not the mute action itself) to open the popup, instead of hovering to reveal an inline track. Useful when the bar is too narrow for a hover-expand slider to have anywhere to expand into.

```ts
plugins: [
  { plugin: DesktopUiPlugin, opts: { volumeSlider: 'vertical' } },
],
```

## Underneath, the same methods

Whichever mode renders, the slider and mute button drive `volume()` / `mute()` / `unmute()` and resync on `'volume'` / `'mute'`, exactly what [Volume](/nomercy-video-player/tour/volume) documents for a consumer building their own volume UI from scratch.
