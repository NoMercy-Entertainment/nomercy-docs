# Build a Player: Volume

[Step 4](/nomercy-video-player/build/time-skip) finished the transport cluster. This step adds the audio cluster: a mute button whose icon tracks three states (high, low, muted) and a volume slider that stays collapsed until you hover the group.

One new field and one call:

{/* partial */}

```ts
private volumeSlider!: HTMLDivElement;  // NEW

override use(): void {
  // ...everything from step 4, unchanged

  this.createVolumeControl();  // NEW
}
```

## The cluster: container, button, three icons

Everything lives in one `group/volume` container: the mute button (via the step-2 `createUiButton()` helper) holding three icon spans, high, low, muted, only one visible at a time, then the slider:

{/* partial */}

```ts
private createVolumeControl(): void {
  const volumeContainer = this.player
    .createElement('div', 'volume-container')
    .addClasses([
      'flex',
      'items-center',
      'group/volume',
      'ml-1',
    ])
    .appendTo(this.bottomRow)
    .get();

  const volumeButton = this.createUiButton(volumeContainer, 'volume', 'Mute');

  const volHigh = this.player
    .createElement('span', 'vol-high')
    .appendTo(volumeButton)
    .get();
  volHigh.innerHTML = svgFromIcon(icons.volumeHigh);

  const volLow = this.player
    .createElement('span', 'vol-low')
    .appendTo(volumeButton)
    .get();
  volLow.innerHTML = svgFromIcon(icons.volumeLow);
  volLow.style.display = 'none';

  const volMuted = this.player
    .createElement('span', 'vol-muted')
    .appendTo(volumeButton)
    .get();
  volMuted.innerHTML = svgFromIcon(icons.volumeMuted);
  volMuted.style.display = 'none';

  this.listen(volumeButton, 'click', (event) => {
    event.stopPropagation();
    this.player.toggleMute();
  });

  // ...the slider, its fills, and the handlers below all live here too
}
```

## The hover-expand trick is pure CSS

The slider starts at `w-0 opacity-0` and expands when the surrounding group is hovered or focused, Tailwind's named groups (`group/volume`) scope the hover so only this cluster reacts:

{/* partial */}

```ts
this.volumeSlider = this.player
  .createElement('div', 'volume-slider')
  .addClasses([
    'relative',
    'h-1',
    'rounded-full',
    'bg-white/20',
    'cursor-pointer',
    'group/vol-slider',
    'w-0',
    'opacity-0',
    'group-hover/volume:w-20',
    'group-hover/volume:mx-2',
    'group-hover/volume:opacity-100',
    'group-focus-within/volume:w-20',
    'group-focus-within/volume:mx-2',
    'group-focus-within/volume:opacity-100',
    'hover:h-2',
    'transition-all',
    'duration-150',
  ])
  .appendTo(volumeContainer)
  .get();
```

The `group-focus-within` variants matter for keyboard users: tabbing into the cluster expands the slider the same way hovering does.

Inside it, the same fill-and-nipple pair as the scrubber, plus one function that paints both from a level:

{/* partial */}

```ts
const volumeProgress = this.player
  .createElement('div', 'volume-progress')
  .addClasses([
    'absolute',
    'top-0',
    'left-0',
    'h-full',
    'bg-white',
    'rounded-full',
    'pointer-events-none',
  ])
  .appendTo(this.volumeSlider)
  .get();

const volumeNipple = this.player
  .createElement('div', 'volume-nipple')
  .addClasses([
    'absolute',
    'top-1/2',
    '-translate-y-1/2',
    '-translate-x-1/2',
    'w-3',
    'h-3',
    'rounded-full',
    'bg-white',
    'hidden',
    'group-hover/vol-slider:flex',
    'pointer-events-none',
    'z-20',
  ])
  .appendTo(this.volumeSlider)
  .get();

const updateVolSliderUi = (vol: number): void => {
  const pct = Math.max(0, Math.min(vol, 100));
  volumeProgress.style.width = `${pct}%`;
  volumeNipple.style.left = `${pct}%`;
};
```

## Click and drag set the level

The pointer-to-value math is the scrubber's `getPercentFromEvent` shape scaled to 0-100 (the full example carries `getVolFromEvent`, identical but rounded). Click sets the level once; dragging sets it continuously through `volume(vol)`:

{/* partial */}

```ts
let volDragging = false;

for (const eventName of ['mousedown', 'touchstart']) {
  this.listen(this.volumeSlider, eventName, () => {
    volDragging = true;
  }, { passive: true });
}
this.listen(this.volumeSlider, 'click', (event) => {
  volDragging = false;
  const vol = getVolFromEvent(event as MouseEvent);
  this.player.volume(vol);
  updateVolSliderUi(vol);
});
for (const eventName of ['mousemove', 'touchmove']) {
  this.listen(this.volumeSlider, eventName, (event) => {
    if (!volDragging)
      return;
    const vol = getVolFromEvent(event as MouseEvent | TouchEvent);
    this.player.volume(vol);
    updateVolSliderUi(vol);
  }, { passive: true });
}
this.listen(this.volumeSlider, 'mouseleave', () => {
  volDragging = false;
}, { passive: true });
```

## Two events, one icon

Volume level and mute state are separate concerns in the player, `volume` carries `{ level }`, `mute` carries `{ muted }`. The icon depends on both, so the plugin tracks the mute flag and re-derives the icon on either event, seeded from `volume()` and `volumeState()` at build time:

{/* partial */}

```ts
let muted = this.player.volumeState() === VolumeState.MUTED;

const updateVolumeIcon = (volume: number): void => {
  volHigh.style.display = 'none';
  volLow.style.display = 'none';
  volMuted.style.display = 'none';

  if (muted || volume === 0) {
    volMuted.style.display = 'flex';
  }
  else if (volume < 50) {
    volLow.style.display = 'flex';
  }
  else {
    volHigh.style.display = 'flex';
  }
};

this.on('volume', ({ level }) => {
  updateVolSliderUi(level);
  updateVolumeIcon(level);
});
this.on('mute', (payload) => {
  muted = payload.muted;
  updateVolumeIcon(this.player.volume());
});

const initialVol = this.player.volume();
updateVolSliderUi(initialVol);
updateVolumeIcon(initialVol);
```

## Dragging outside the slider

The drag pattern is the step-3 scrubber pattern again, with one addition: `mouseup` and `touchend` listeners on `document`, not the slider. A drag that ends with the pointer outside the slider would otherwise leave `volDragging` stuck at `true`. `this.listen()` cleans document-level listeners on dispose the same as element-level ones, which is exactly why the base owns listener registration:

{/* partial */}

```ts
this.listen(document, 'mouseup', () => {
  volDragging = false;
}, { passive: true });
this.listen(document, 'touchend', () => {
  volDragging = false;
}, { passive: true });
```

## See it running

Hover the speaker: the slider unfolds. Drag it, click it, click the speaker to mute, the icon follows whichever of the two events fired. The player in this example starts unmuted (`muted: false`) at the default volume of 100, so the icon starts on the high glyph, exactly what `volume()` and `volumeState()` seeded.
