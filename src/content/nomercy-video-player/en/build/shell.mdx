# Build a Player: The Shell

This is a five-step tutorial that mounts and configures a real player chrome: the shell, chapter-aware scrubbing, the volume slider's display mode, a real subtitle picker, and the complete configuration. Nothing here is hand-built DOM — every step mounts `DesktopUiPlugin`, the same overlay every NoMercy app ships, and turns on one more piece of its real options surface.

## Registering a plugin declaratively

Every plugin in this trio used to require an imperative `addPlugin()` call *before* `setup()` — easy to get the timing of wrong, and easy to miss under a framework's re-render cycle. `plugins` on `BasePlayerConfig` is the declarative form: pass the class (or `{ plugin, opts }` for one that takes options) straight into `setup()`, and the kit registers it at the exact same pipeline point `addPlugin()` would have, before `pluginsRegistering` runs:

```ts
const player = nmplayer('my-container').setup({
  baseUrl,
  playlist: [item],
  plugins: [DesktopUiPlugin],
});
await player.ready();
```

No separate call to sequence, no window to miss. This is sugar over `addPlugin()`, not a second registration path — duplicate-id, missing-dependency, and version checks all run identically either way.

## What ships with zero options

`DesktopUiPlugin` needs no configuration to be a complete player. Mounted bare, it already renders play/pause, mute + volume, a scrubber, fullscreen, and a settings button — plus chapter navigation, since `sintel` (this tutorial's fixture) carries real chapter marks. Off by default: theater, PiP, speed, quality, subtitles, audio-track, playlist, and aspect-ratio buttons. The next four steps turn each of those on for a real reason, one at a time.
