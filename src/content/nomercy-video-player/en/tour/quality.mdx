# Quality Levels

Adaptive bitrate is on by default. `hls.js` (or Safari's native HLS) keeps switching renditions to match bandwidth without you doing anything. This page is for when you want a manual quality menu on top of that.

## Listing levels

Once the `'levels'` event has fired, `qualityLevels()` returns the manifest's bitrate renditions. Each entry carries `bitrate`, plus `height`/`width` when the manifest provides them.

`qualityLevels({ includeUnsupported: true })` also returns renditions the current device cannot decode. That lets a menu show them disabled rather than hide them entirely:

```ts
import nmplayer from '@nomercy-entertainment/nomercy-video-player';

const player = nmplayer('player');

const levels = player.qualityLevels(); // QualityLevel[]
const withUnsupported = player.qualityLevels({ includeUnsupported: true });
```

## Reading and setting the selection

`quality()` and `quality(idx)` cover reading and setting the level:

| Call | Result |
| --- | --- |
| `quality()`, level picked manually | `{ index, track }` for that level. |
| `quality()`, ABR driving | The string `'auto'`. |
| `quality(idx)` | Locks a specific level. |
| `quality('auto')` | Hands control back to the backend. |

```ts
player.quality(0); // lock the first (usually lowest) rendition
player.quality('auto'); // back to adaptive
```

Setting a level emits two events, each suited to a different UI need:

| Event | Fires | Subscribe for |
| --- | --- | --- |
| `'quality:requested'` | Immediately, before the backend confirms the switch. Video-specific. | A UI that must reflect the request instantly, without waiting on the network. |
| `'level-switched'` | Once the backend actually applies the switch. | A "now playing at 1080p" toast. |

## Default quality

`defaultQuality` on `VideoPlayerConfig` applies once, after the first manifest parse. It takes `'auto'` or a fixed level index. `'auto'` is already the kit's own default, so setting it explicitly is only useful for readability:

```ts
player.setup({
  baseUrl,
  playlist: [item],
  defaultQuality: 'auto',
});
```

## Bandwidth and capability checks

Three calls round out level selection:

| Method | What it does |
| --- | --- |
| `bandwidth()` | Reads the backend's current estimate in bits per second, the number ABR decides against. |
| `bandwidthEstimator(fn)` | Replaces the estimator with your own, for a measurement shared across several players on one page. |
| `canPlay(profile)` | Asks the platform's `MediaCapabilities` whether a content profile is decodable. |

A profile names a `contentType`, resolution, bitrate, and framerate. Ask `canPlay()` before offering a level in a menu.
