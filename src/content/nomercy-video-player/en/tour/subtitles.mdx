# Subtitles & Text Tracks

Subtitle *selection* and subtitle *rendering* are two separate concerns.

Most of this page is selection: listing tracks, picking one, styling the text. Selection is kit surface. It comes from `nomercy-player-core`'s `mediaTracksMethods`, which read and write state. `cycleSubtitles()` and `subtitleState()` are the two video-only additions, called out below.

Painting cue text on screen is a plugin's job. `SubtitleOverlayPlugin` for VTT, `OctopusPlugin` for ASS/SSA with embedded fonts.

[Build a Player: Selectors](/nomercy-video-player/build/selectors) hand-builds the picker that calls `subtitle(idx)`. Pair it with `SubtitleOverlayPlugin` to render the text.

Neither renderer is loaded by default. Selecting a track without one changes state correctly and paints nothing.

## Listing and selecting tracks

Four calls cover listing and selecting a track:

| Call | What it does |
| --- | --- |
| `subtitles()` | Returns the track list for the active item. |
| `subtitle()` | Reads the current selection as `{ index, track }`, or `null` when subtitles are off. |
| `subtitle(idx)` | Selects a track by index. |
| `subtitle(null)` | Turns subtitles off. |

```ts
import nmplayer from '@nomercy-entertainment/nomercy-video-player';

const player = nmplayer('player');

const tracks = player.subtitles(); // SubtitleTrack[]: { id, language?, label }
const current = player.subtitle(); // { index, track } | null

await player.subtitle(0); // select the first track
await player.subtitle(null); // off
```

`cycleSubtitles()` walks `off → 0 → 1 → ... → N-1 → off` in one call. That is what a keyboard shortcut or a remote's CC button binds to, instead of resolving the next index by hand.

`subtitleState()` returns `SubtitleState.ON` or `OFF`, for a UI that only needs to know whether *any* track is active.

Both are defined on the video player rather than the kit.

## Auto-selecting a language

Once the manifest resolves, `defaultSubtitleLanguage` on `VideoPlayerConfig` auto-selects a track. It matches an exact BCP-47 tag first, then a prefix (`'en'` matches a track tagged `'en-US'`):

```ts
player.setup({
  baseUrl,
  playlist: [sintelItem],
  defaultSubtitleLanguage: 'en',
});
```

When no track matches, subtitles stay off, silently. There is no error, and no fallback track is forced on.

## Styling

`subtitleStyle()` reads the current `SubtitleStyle`. `subtitleStyle(patch)` merges a partial patch onto it, then emits `subtitleStyle` with the merged result. `SubtitleOverlayPlugin` listens for that event and repaints every active cue immediately:

```ts
player.subtitleStyle({ fontSize: 120, edgeStyle: 'dropShadow' });
```

The kit only owns the in-memory value and the event. Persisting a user's choice across sessions is your app's job (or a preference plugin's).
