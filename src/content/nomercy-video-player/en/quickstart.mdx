# Video Player: Quick Start

This gets a real video playing in the preview below: Sintel, streamed over HLS, using the baseUrl pattern every NoMercy player and app is built around. Everything on this page is the same code you would copy into your own project.

## Install

```
npm install @nomercy-entertainment/nomercy-video-player@rc hls.js
```

`hls.js` is a peer dependency. `nomercy-video-player` dynamically imports it for every browser except Safari, which plays HLS natively; without it installed, HLS playback fails outside Safari.

## The baseUrl pattern

`baseUrl` is the one config field every playlist should set. Item paths (`file` in the snippet above) stay relative, exactly the shape a real media server sends, and the player prepends `baseUrl` as a plain string prefix, keeping the whole base path:

```ts
baseUrl: 'https://your-server.example.com/api/files',
playlist: [{ /* ... */ file: '/Movie.(2020)/Movie.(2020).m3u8' }],
```

Move to a different server, a different environment, a signed-URL CDN, and you change one config value; nothing in your catalogue is hardcoded to today's origin. The server sends the base without a trailing slash and paths with a leading slash, so never pre-join an absolute URL into an item yourself. That is the player's job, and doing it twice breaks the moment the base changes.

## Mounting into your own container

The Sintel player above mounts into a container the example creates for you. In your own app, render a container and call the same factory:

```html
<div id="player"></div>
```

```ts
import nmplayer from '@nomercy-entertainment/nomercy-video-player';

const player = nmplayer('player').setup({
  baseUrl: 'https://your-server.example.com/api/files',
  playlist: [/* ... */],
});

await player.ready();
```

`nmplayer(id)` either mounts a new player into `document.getElementById(id)` or returns the instance already registered under that id, so calling it twice for the same id is always safe.
