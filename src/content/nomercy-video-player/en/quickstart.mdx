# Video Player: Quick Start

A working video player in a few lines: mounted in your own element, playing an HLS stream, with the play/pause, seek bar, volume, and fullscreen controls from `DesktopUiPlugin`.

## Install

```
npm install @nomercy-entertainment/nomercy-video-player@rc
```

`hls.js` installs automatically with the player — nothing extra for the npm / bundler path. See [Installation](/nomercy-video-player/installation) for the CDN exception.

## Minimal working player

```ts
import nmplayer from '@nomercy-entertainment/nomercy-video-player';
import { DesktopUiPlugin } from '@nomercy-entertainment/nomercy-video-player/plugins';
import type {
  VideoPlayerConfig,
  VideoPlaylistItem,
} from '@nomercy-entertainment/nomercy-video-player';

const items: VideoPlaylistItem[] = [
  {
    id: 'sintel',
    title: 'Sintel',
    url: '/Sintel.(2010)/Sintel.(2010).NoMercy.m3u8',
    image: 'https://image.tmdb.org/t/p/w780/q2bVM5z90tCGbmXYtq2J38T5hSX.jpg',
    duration: 888,
    subtitles: [
      {
        id: 'eng',
        label: 'English',
        url: '/Sintel.(2010)/subtitles/Sintel.(2010).NoMercy.eng.full.vtt',
        language: 'eng',
      },
    ],
    chapters: [
      { index: 0, start: 0,   end: 196, title: 'Prologue' },
      { index: 1, start: 196, end: 404, title: 'The Hunt' },
      { index: 2, start: 404, end: 609, title: 'Dragon Fight' },
      { index: 3, start: 609, end: 888, title: 'Epilogue' },
    ],
  },
];

const config: VideoPlayerConfig = {
  baseUrl: 'https://raw.githubusercontent.com/NoMercy-Entertainment/nomercy-media/master/Films',
  playlist: items,
};

const player = nmplayer('nomercy-player')
  .addPlugin(DesktopUiPlugin)
  .setup(config);

player.on('ready', () => {
  player.item(0, { autoplay: true });
});
```

The `DesktopUiPlugin` mounts the full built-in UI: play/pause, seek bar, volume, fullscreen, subtitle and quality menus. Remove it if you are building a custom UI. The inline `playlist:` array is auto-queued during setup, and `item(0, { autoplay: true })` selects the first item and starts playback.

## Core controls

```ts
player.play();
player.pause();
player.stop();
player.togglePlayback();

player.next();
player.previous();
player.seekToIndex(2); // jump to a playlist item (1-based)

player.time(120);      // seek to 2:00
player.volume(60);     // 0-100
player.mute();
player.unmute();
player.toggleMute();

player.fullscreen(true);
player.pip(true);
```

See [API Methods](/nomercy-video-player/api-methods) for the full surface and the overloaded getter/setter pattern.

## Listening to events

```ts
player.on('ready', () => { /* setup complete */ });
player.on('time', ({ time }) => updateProgressBar(time / player.duration()));
player.on('play', () => { /* started */ });
player.on('pause', () => { /* paused */ });
player.on('ended', () => { /* reached the end */ });
player.on('level-switched', () => { /* HLS quality changed */ });
```

See [Events](/nomercy-video-player/events) for the full list and payload shapes.
