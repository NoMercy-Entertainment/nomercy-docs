# Video Player: Quick Start

This gets a real video playing in the preview below: Sintel, streamed over HLS, using the baseUrl pattern every NoMercy player and app is built around.

## Install

```
npm install @nomercy-entertainment/nomercy-video-player@rc
```

That's the only package you need. `hls.js` is a regular dependency pulled in through `nomercy-player-core`, so npm installs it for you; the player dynamically imports it for every browser except Safari, which plays HLS natively. There is no peer dependency to add by hand.

## Play your first video

Add a container for the player, then run the code below. The preview underneath is that exact code, running:

```html
<div id="player"></div>
```

`muted` and `autoPlay` are set here only so the preview starts without a click; drop both for a normal app and call `player.play()` from your own UI on a user gesture instead. `nmplayer('player')` mounts into `document.getElementById('player')`, or returns the instance already registered under that id, so calling it twice is always safe.

## The baseUrl pattern

`baseUrl` is the one config field every playlist should set. Item paths (`url` above) stay relative, exactly the shape a real media server sends, and the player prepends `baseUrl` as a plain string prefix, keeping the whole base path:

- The server sends the base with no trailing slash (`.../master/Films`) and each item path with a leading slash (`/Sintel.(2010)/...`).
- Move to a different server, a different environment, or a signed-URL CDN, and you change one config value; nothing in your catalogue is hardcoded to today's origin.
- Never pre-join an absolute URL into an item yourself. That is the player's job, and doing it twice breaks the moment the base changes.
