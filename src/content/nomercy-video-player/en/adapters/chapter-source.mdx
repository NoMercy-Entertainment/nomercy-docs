## What is a chapter source?

`IChapterSource` is the adapter the player calls to load and query chapter data for each playlist item. The default implementation (`VttChapterSource`) reads chapters from the `chapters` typed field on `VideoPlaylistItem`. A custom implementation could fetch chapters from an API endpoint or parse a different file format.

## IChapterSource interface

```ts
import type { IChapterSource } from '@nomercy-entertainment/nomercy-video-player';
```

| Method                 | Signature                                        | Description                                                          |
| ---------------------- | ------------------------------------------------ | -------------------------------------------------------------------- |
| `load(item)`           | `(item: BasePlaylistItem) => Promise<Chapter[]>` | Fetch and cache chapters for the item. Called after `loadedmetadata` |
| `current(timeSeconds)` | `(timeSeconds: number) => Chapter \| null`       | Return the chapter active at `timeSeconds`. Must be synchronous      |
| `all()`                | `() => Chapter[]`                                | Return all chapters for the current item. Synchronous                |
| `unload()`             | `() => void`                                     | Release cached chapter data. Called on unload and dispose            |

## Default implementation: VttChapterSource

`VttChapterSource` is used automatically when no custom chapter source is configured. It reads chapters from the `chapters` typed array on `VideoPlaylistItem`:

```ts
import type { VideoPlaylistItem } from '@nomercy-entertainment/nomercy-video-player';

const item: VideoPlaylistItem = {
  url: 'https://raw.githubusercontent.com/NoMercy-Entertainment/nomercy-media/master/Films/Tears.of.Steel.(2012)/Tears.of.Steel.(2012).NoMercy.m3u8',
  chapters: [
    { title: 'Opening', start: 0, end: 90 },
    { title: 'Act 1', start: 90, end: 720 },
    { title: 'Credits', start: 720, end: 730 },
  ],
};
```

When `chapters` is present and non-empty, `VttChapterSource.load()` resolves immediately with the pre-supplied list without making any network request.

Or reference a VTT chapter file via the `tracks` sidecar:

```ts
const item: VideoPlaylistItem = {
  url: 'https://raw.githubusercontent.com/NoMercy-Entertainment/nomercy-media/master/Films/Sintel.(2010)/Sintel.(2010).NoMercy.m3u8',
  tracks: [
    {
      kind: 'chapters',
      file: 'https://raw.githubusercontent.com/NoMercy-Entertainment/nomercy-media/master/Films/Sintel.(2010)/chapters.vtt',
    },
  ],
};
```

## Custom chapter source

Implement `IChapterSource` to load chapters from a different format or source. When calling your API from inside a plugin, use `this.fetch()` instead of the global `fetch`. The plugin's `this.fetch()` applies the player's bearer token, handles 401 refresh-and-retry, and respects the retry policy — raw `fetch()` skips all of that.

```ts
import { Plugin } from '@nomercy-entertainment/nomercy-player-core';
import type { IChapterSource } from '@nomercy-entertainment/nomercy-video-player';
import type { Chapter, VideoPlaylistItem } from '@nomercy-entertainment/nomercy-video-player';

class ApiChapterSource extends Plugin implements IChapterSource {
  static readonly id = 'my-chapter-source';
  static readonly description = 'Chapter source from /api/chapters/:id';

  async load(item: VideoPlaylistItem): Promise<Chapter[]> {
    const data = await this.fetch<ApiChapter[]>(`/api/chapters/${item.id}`, {
      responseType: 'json',
    });
    return data.map((ch) => ({
      title: ch.name,
      start: ch.start_ms / 1000,
      end: ch.end_ms / 1000,
    }));
  }
}

player.setup({
  chapterSource: new ApiChapterSource(),
});
```

The built-in `VttChapterSource` uses `this.fetch()` the same way — auth-aware, no manual token threading required.

## Chapter type

`Chapter` is defined in `@nomercy-entertainment/nomercy-player-core`:

```ts
interface Chapter {
  title: string;
  start: number; // seconds
  end: number; // seconds
}
```

## Querying chapters

The player exposes chapter queries through its top-level API:

```ts
// All chapters for the current item
const chapters = player.chapters();

// Chapter active at the current playback position
const currentChapter = player.currentChapter();

// Navigate chapters
player.nextChapter();
player.previousChapter();
```

The `'chapter'` event fires when the playback position crosses a chapter boundary:

```ts
player.on('chapter', ({ index, title }) => {
  console.log(`Now in chapter ${index}: ${title}`);
});
```
