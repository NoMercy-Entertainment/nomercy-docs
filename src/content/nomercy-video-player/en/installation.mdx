# Installation

## Requirements

- Node.js 18 or later (tooling only; the player itself runs in any modern browser)
- A module bundler (Vite, Webpack, Rollup, or similar)

## Install the package

```bash
npm install @nomercy-entertainment/nomercy-video-player@rc
```

While v2 is in prerelease it publishes under the `rc` dist-tag — `@rc` always resolves to the newest v2 release. The default `latest` tag still points at the v1 line, so install with `@rc` for v2. The package-manager toggle, pinned to the top right, switches this command to yarn, pnpm, or bun.

`hls.js` installs automatically with the player — it is a dependency, loaded lazily the first time you point at an HLS (`.m3u8`) source. Nothing extra to install for the npm / bundler path.

## CDN (no bundler)

You can drop the player onto a page without a bundler. Load `hls.js` first (the IIFE bundle reads it from the `Hls` global), then the player bundle, which exposes a `nmplayer` global.

```html
<script src="https://cdn.jsdelivr.net/npm/hls.js@1.6.15/dist/hls.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/@nomercy-entertainment/nomercy-video-player@rc/dist/nomercy-video-player.iife.js"></script>
```

Built-in plugins are not part of the IIFE bundle, so use the npm install above when you need them.

## Import paths

```ts
// Main player + types
import nmplayer from '@nomercy-entertainment/nomercy-video-player';
import type {
  VideoPlaylistItem,
  VideoPlayerConfig,
  IVideoPlayer,
} from '@nomercy-entertainment/nomercy-video-player';

// Plugins — always from the /plugins subpath
import {
  DesktopUiPlugin,
  SubtitleOverlayPlugin,
  OctopusPlugin,
} from '@nomercy-entertainment/nomercy-video-player/plugins';
```

Importing plugins from the main entry point is not supported; always use `/plugins`.

## TypeScript

The package ships full TypeScript declarations. No `@types/` package is needed.

The recommended type for a consumer-held player reference is `IVideoPlayer<T>`:

```ts
import type { IVideoPlayer, VideoPlaylistItem } from '@nomercy-entertainment/nomercy-video-player';

let player: IVideoPlayer<VideoPlaylistItem>;
```

Use the concrete `NMVideoPlayer<T>` type only when you need internals not exposed on the interface.
