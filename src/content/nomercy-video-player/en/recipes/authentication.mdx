# Authentication

When your stream URLs require an `Authorization` header, pass an `auth` block to `setup()`. The player injects `Authorization: Bearer <token>` on every HLS manifest and segment request the backend makes.

```ts
import nmplayer from '@nomercy-entertainment/nomercy-video-player';

const player = nmplayer('main').setup({
  playlist: [{ id: '1', url: 'https://protected.cdn.your-domain.com/stream.m3u8' }],
  auth: {
    bearerToken: () => myAuth.getAccessToken(),
    refreshOnUnauthenticated: async () => {
      await myAuth.refresh();
      // bearerToken() is re-read automatically on the retry — no return value needed.
    },
  },
});

player.on('ready', () => {
  player.item(0, { autoplay: true });
});
```

- On a **401**, the player calls `refreshOnUnauthenticated` once and retries the request.
- On a **403**, the error propagates — the player does not retry.

See [Configuration](/nomercy-video-player/configuration) for the full `auth` option shape.
