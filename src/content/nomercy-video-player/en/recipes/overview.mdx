# Video Player: Recipes

Short, focused guides for common integration tasks.
Each recipe shows the minimal working code first, then explains what is happening.

**Prerequisites for all recipes:** complete the [Quick Start](/nomercy-video-player/quickstart) first.

## Available recipes

| Recipe                                                                 | What it covers                                                                    |
| ---------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| [Subtitles](/nomercy-video-player/recipes/subtitles)                   | VTT and ASS/SSA rendering, multi-language switching, style persistence            |
| [Chapters](/nomercy-video-player/recipes/chapters)                     | Inline chapter data, VTT chapter files, seek-bar markers, programmatic navigation |
| [Quality Selection](/nomercy-video-player/recipes/quality-selection)   | Manual ABR override, HDR-aware constraints, building a quality menu               |
| [Playlist and Queue](/nomercy-video-player/recipes/playlist-and-queue) | Append/remove/reorder, shuffle, repeat modes, automatic advance                   |
| [Keyboard Shortcuts](/nomercy-video-player/recipes/keyboard-shortcuts) | Custom bindings, standalone KeyHandlerPlugin, conflict resolution                 |
| [Live Transcoding](/nomercy-video-player/recipes/live-transcoding)     | Server-side on-demand transcode with quality negotiation                          |
