# Chapters

Read this when you want named chapters in your video, displayed on the seek bar and usable for programmatic navigation.
Chapters are provided per-item and loaded by an `IChapterSource` adapter.

**Prerequisites:** [Video Quick Start](/nomercy-video-player/quickstart).
For the full chapter API see [Chapters](/nomercy-video-player/adapters/chapter-source).

## Inline chapter data

The simplest approach is to embed chapter data directly in each queue item:

```ts
const player = nmplayer('main').setup({
  container: document.getElementById('player')!,
  baseUrl: 'https://raw.githubusercontent.com/NoMercy-Entertainment/nomercy-media/master/Films',
  playlist: [
    {
      id: 'sintel',
      url: '/Sintel.(2010)/Sintel.(2010).NoMercy.m3u8',
      chapters: [
        { index: 0, start: 0, end: 90, title: 'Cold Open' },
        { index: 1, start: 90, end: 900, title: 'Act 1' },
        { index: 2, start: 900, end: 1800, title: 'Act 2' },
        { index: 3, start: 1800, end: 2700, title: 'Credits' },
      ],
    },
  ],
});
```

`DesktopUiPlugin` reads chapter data automatically and renders chapter markers on the seek bar.
No extra configuration is needed.

## VTT chapter file

Supply a custom `IChapterSource` that fetches and parses a WebVTT chapter file,
then register it in `setup()`:

```ts
import type {
  IChapterSource,
  Chapter,
  VideoPlaylistItem,
} from '@nomercy-entertainment/nomercy-video-player';

class VttFileChapterSource implements IChapterSource {
  constructor(private readonly vttUrl: string) {}

  private _chapters: Chapter[] = [];

  async load(_item: VideoPlaylistItem): Promise<Chapter[]> {
    const text = await fetch(this.vttUrl).then((r) => r.text());
    this._chapters = parseVttChapters(text);
    return this._chapters;
  }

  current(timeSeconds: number): Chapter | null {
    return this._chapters.find(
      (ch) => timeSeconds >= ch.start && timeSeconds < ch.end,
    ) ?? null;
  }

  all(): Chapter[] {
    return this._chapters;
  }

  unload(): void {
    this._chapters = [];
  }
}

const player = nmplayer('main').setup({
  container: document.getElementById('player')!,
  baseUrl: 'https://raw.githubusercontent.com/NoMercy-Entertainment/nomercy-media/master/Films',
  chapterSource: new VttFileChapterSource(
    'https://raw.githubusercontent.com/NoMercy-Entertainment/nomercy-media/master/Films/Sintel.(2010)/chapters.vtt',
  ),
  playlist: [
    {
      id: 'sintel',
      url: '/Sintel.(2010)/Sintel.(2010).NoMercy.m3u8',
    },
  ],
});
```

A valid WebVTT chapters file:

```
WEBVTT

cold-open
00:00:00.000 --> 00:01:30.000
Cold Open

act-1
00:01:30.000 --> 00:15:00.000
Act 1

credits
00:45:00.000 --> 00:47:00.000
Credits
```

## Chapter events and API

```ts
// Fires when currentTime() enters a new chapter range:
player.on('chapter', ({ index, title }) => {
  console.log(`Now in chapter ${index}: ${title}`);
});

// Read all chapters for the current item:
const chapters = player.chapters();
// [{ index, start, end, title }, ...]

// Read the currently active chapter:
const current = player.currentChapter();
// { index, start, end, title } | null
```

## Programmatic chapter seek

Jump to a chapter by index or by its start time:

```ts
// Seek to the start of chapter at index 2:
const chapters = player.chapters();
if (chapters[2]) {
  player.currentTime(chapters[2].start);
}

// Build a chapter menu:
chapters.forEach((chapter) => {
  const button = document.createElement('button');
  button.textContent = chapter.title;
  button.addEventListener('click', () => player.currentTime(chapter.start));
  chapterMenu.appendChild(button);
});
```

## Custom chapter source

Load chapters from a database or API instead of a VTT file:

```ts
import type {
  IChapterSource,
  Chapter,
  VideoPlaylistItem,
} from '@nomercy-entertainment/nomercy-video-player';

class ApiChapterSource implements IChapterSource {
  async load(item: VideoPlaylistItem): Promise<Chapter[]> {
    // item.id is the queue item id passed to the server
    const response = await fetch(`/api/chapters/${item.id}`);
    const data: Array<{ id: number; start_ms: number; end_ms: number; name: string }> =
      await response.json();

    return data.map((ch, index) => ({
      index,
      start: ch.start_ms / 1000,
      end: ch.end_ms / 1000,
      title: ch.name,
    }));
  }
}

player.setup({
  chapterSource: new ApiChapterSource(),
});
```
