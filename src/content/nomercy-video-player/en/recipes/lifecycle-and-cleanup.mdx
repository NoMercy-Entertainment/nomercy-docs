# Cleanup & Disposal

Call [`dispose()`](/nomercy-video-player/api-methods) when the player is no longer needed.

```ts
player.dispose();
```

It tears down the HLS engine (the hls.js instance), all plugins, the backend `<video>` element, and removes the player from the internal instance registry.

In a single-page app, **not** calling `dispose()` when you unmount a view leaks the hls.js instance — it keeps fetching segments against an orphaned `MediaSource` in the background. Dispose on unmount:

```ts
// framework teardown (React effect cleanup, Vue onUnmounted, etc.)
return () => {
  player.dispose();
};
```

After `dispose()`, calling the factory with the same id creates a fresh instance.
