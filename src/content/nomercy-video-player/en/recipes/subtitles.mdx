# Subtitles

Read this when you need subtitle rendering beyond the bare minimum in the quickstart. It covers the two rendering paths (VTT and ASS/SSA), multi-language switching, and user style preferences.

**Prerequisites:** [Video Quick Start](/nomercy-video-player/quickstart). For the full subtitle API see [Subtitle Overlay](/nomercy-video-player/plugins/subtitle-overlay).

---

## VTT subtitles — default path

`SubtitleOverlayPlugin` renders WebVTT cues as styled DOM text over the video. It is the lightest option and works without any extra dependencies.

```ts
import nmplayer from '@nomercy-entertainment/nomercy-video-player';
import { SubtitleOverlayPlugin } from '@nomercy-entertainment/nomercy-video-player/plugins';

const player = nmplayer('main').setup({
  container: document.getElementById('player')!,
  baseUrl: 'https://raw.githubusercontent.com/NoMercy-Entertainment/nomercy-media/master/Films',
  defaultSubtitleLanguage: 'en',
  queue: [
    {
      id: 'sintel',
      url: '/Sintel.(2010)/Sintel.(2010).NoMercy.m3u8',
      subtitles: [
        {
          id: 'en',
          language: 'en',
          label: 'English',
          file: '/Sintel.(2010)/subtitles/Sintel.(2010).NoMercy.eng.full.vtt',
          kind: 'subtitles',
        },
      ],
    },
  ],
});

player.addPlugin(SubtitleOverlayPlugin);
await player.ready();
await player.play();
```

Switch languages at runtime:

```ts
// List available tracks:
const tracks = player.subtitles();
// [{ id: 'en', language: 'en', label: 'English' }, ...]

// Activate by index:
player.currentSubtitle(0); // English
player.currentSubtitle(1); // Dutch

// Disable subtitles:
player.currentSubtitle(null);

// Read which is active (null = off):
const active = player.currentSubtitle();
```

Listen for changes:

```ts
player.on('subtitle', ({ index }) => {
  // index is null when subtitles are off
  updateSubtitleMenu(index);
});
```

## ASS/SSA subtitles — OctopusPlugin

Use `OctopusPlugin` when you need full ASS/SSA typesetting — custom fonts, karaoke effects, complex positioning, motion. It loads `@nomercy-entertainment/nomercy-subtitle-octopus` at runtime via a dynamic import.

**Copy worker files to your public directory** (Vite example):

```ts
// vite.config.ts
import { viteStaticCopy } from 'vite-plugin-static-copy';

export default {
  plugins: [
    viteStaticCopy({
      targets: [
        {
          // Worker JS files from the octopus package go into your public/static folder
          src: 'node_modules/@nomercy-entertainment/nomercy-subtitle-octopus/dist/*.js',
          dest: 'static',
        },
      ],
    }),
  ],
};
```

**Register the plugin:**

```ts
import nmplayer from '@nomercy-entertainment/nomercy-video-player';
import { OctopusPlugin } from '@nomercy-entertainment/nomercy-video-player/plugins';

const player = nmplayer('main').setup({
  container: document.getElementById('player')!,
  defaultSubtitleLanguage: 'en',
  queue: [
    {
      id: 'rail-wars',
      url: 'https://raw.githubusercontent.com/NoMercy-Entertainment/nomercy-media/master/Anime/Rail.Wars!.(2014)/Rail.Wars!.S00E00/Rail.Wars!.(2014).S00E00.NoMercy.m3u8',
      subtitles: [
        {
          id: 'en',
          language: 'en',
          label: 'English (ASS)',
          file: 'https://raw.githubusercontent.com/NoMercy-Entertainment/nomercy-media/master/Anime/Rail.Wars!.(2014)/Rail.Wars!.S00E00/subtitles/Rail.Wars!.(2014).S00E00.NoMercy.eng.full.ass',
          kind: 'ass',
        },
      ],
      fonts: [
        {
          file: 'https://raw.githubusercontent.com/NoMercy-Entertainment/nomercy-media/master/Anime/Rail.Wars!.(2014)/Rail.Wars!.S00E00/fonts.json',
        },
      ],
    },
  ],
});

player.addPlugin(OctopusPlugin, {
  workerUrl: '/static/subtitles-octopus-worker.js',
  legacyWorkerUrl: '/static/subtitles-octopus-worker-legacy.js',
  fallbackFont: '/static/fonts/Roboto.ttf',
  targetFps: 24,
});
```

`nomercy-subtitle-octopus` ships as a dependency of `nomercy-video-player`. The plugin loads it lazily — if it cannot be resolved at runtime (e.g. bundler exclusion), it falls back to no rendering with no error thrown. Enable `logLevel: 'debug'` to confirm the fallback path.

## Font manifest format

The font manifest is a JSON array. The plugin fetches each font before first render:

```json
[
  { "file": "https://your-domain.com/fonts/NotoSans.ttf", "mimeType": "font/ttf" },
  { "file": "https://your-domain.com/fonts/ScriptBold.otf", "mimeType": "font/otf" }
]
```

## Multi-language switching with VTT and ASS mixed

You can mix VTT and ASS tracks on the same item. The player selects the renderer based on the `kind` field:

```ts
subtitles: [
  // VTT tracks — rendered by SubtitleOverlayPlugin
  { id: 'en-vtt', language: 'en', label: 'English (VTT)', file: '/subs/ep1.en.vtt', kind: 'subtitles' },
  // ASS tracks — rendered by OctopusPlugin
  { id: 'en-ass', language: 'en', label: 'English (Styled)', file: '/subs/ep1.en.ass', kind: 'ass' },
],
```

Register both plugins. The correct one activates for each track.

## Subtitle style customization

`SubtitleOverlayPlugin` persists user preferences (font size, color, background opacity) via the `ISubtitleStyleStore` adapter. The default store writes to `localStorage` under the player's namespace.

Override the store to use a different backend:

```ts
import type {
  ISubtitleStyleStore,
  SubtitleStyle,
} from '@nomercy-entertainment/nomercy-video-player';

class RemoteSubtitleStyleStore implements ISubtitleStyleStore {
  async load(): Promise<SubtitleStyle | null> {
    const response = await fetch('/api/user/subtitle-style');
    return response.ok ? response.json() : null;
  }

  async save(style: SubtitleStyle): Promise<void> {
    await fetch('/api/user/subtitle-style', {
      method: 'PUT',
      body: JSON.stringify(style),
      headers: { 'Content-Type': 'application/json' },
    });
  }
}

player.setup({
  subtitleStyleStore: new RemoteSubtitleStyleStore(),
});
```
