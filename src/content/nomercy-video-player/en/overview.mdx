# What is the NoMercy Video Player

`nomercy-video-player` is the headless HLS engine that powers video on NoMercy TV.
It does the parts of video that are genuinely hard, switching bitrate as the network changes, matching HDR to the display, rendering subtitles in several formats, and keeping the picture moving through all of it, then hands you the result as plain events and methods.
No UI is bundled: add the built-in `DesktopUiPlugin` for a full set of controls, or build your own.

## What you get

- `NMVideoPlayer<T>`, a typed player class generic over your own item type
- `nmplayer(id)`, a factory that creates or returns a named instance
- Adaptive bitrate, HDR-aware quality, multi-track subtitles, chapters, skip markers, and Chromecast
- A plugin for every optional capability, from the full desktop UI to subtitle overlays
- Full TypeScript types for every method, event, and option

## Where it sits

The generic parts (queue, auth, plugins, i18n, storage) live in `nomercy-player-core` underneath, so this package stays focused on the hard video parts.
