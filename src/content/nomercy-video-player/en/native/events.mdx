---
title: Video player events
description: Every event the video surface announces, from ecosystem contract 2.2.0.
---

The video surface announces 19 events. Subscribe with the
typed key rather than the string: the key carries the payload type, so a
rename becomes a compile error instead of a listener that never fires.

The `before` events are the cancellable seam. They are dispatched directly
rather than through the emitter, so a firehose subscription does not see
them and anything watching for one has to subscribe by name.

| --- | --- |
| `aspectRatio` | `{ value: Stretching }` |
| `audioTracks` | `{ tracks: AudioTrack[] }` |
| `back` | `void` |
| `canplay` | `void` |
| `cast` | `void` |
| `close` | `void` |
| `display-message` | `{ text: string; ms?: number }` |
| `fullscreen` | `{ active: boolean }` |
| `levels` | `{ levels: QualityLevel[] }` |
| `pip` | `{ active: boolean }` |

| `subtitle-size-down` | `void` |
| `subtitle-size-up` | `void` |
