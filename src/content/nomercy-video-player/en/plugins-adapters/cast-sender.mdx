# Plugin: Cast Sender

## Purpose

`CastSenderPlugin` (id `'cast-sender'`) sends a video item to a Chromecast receiver: session lifecycle, remote-state mirroring, and resume-on-disconnect. It is a two-method specialization of the kit's [`CastSenderPlugin`](/nomercy-player-core/plugins-adapters/cast-sender). This subclass supplies only the two things that differ per medium: the default MIME type, and how a `VideoPlaylistItem` becomes Cast metadata.

## Using it

```ts
import nmplayer from '@nomercy-entertainment/nomercy-video-player';
import { CastSenderPlugin } from '@nomercy-entertainment/nomercy-video-player/plugins/cast-sender';

const player = nmplayer('player');

player.addPlugin(CastSenderPlugin, { chromecastAppId: 'ABCD1234' });
await player.ready();

await player.getPlugin(CastSenderPlugin)?.connect();
```

Subclass and override `buildMetadata()` when your items carry fields beyond the canonical `VideoPlaylistItem`, such as a server-specific `name`:

```ts
class MyCastSenderPlugin extends CastSenderPlugin {
	protected override async buildMetadata(item, ctors) {
		const meta = await super.buildMetadata(item, ctors);
		// add app-specific fields on top of the canonical set super() already built
		return meta;
	}
}
```

## Reference

`defaultContentType` defaults to `'video/mp4'` here, unless you override it explicitly.

`buildMetadata(item, ctors)` reads only fields already on the canonical `VideoPlaylistItem`:

| Item has... | Metadata built |
|---|---|
| `item.show` set (non-empty string) | `TvShowMediaMetadata` (falls back to `GenericMediaMetadata` if the SDK build lacks the TV-show constructor), `seriesTitle` from `show`, `season` / `episode` set when present. |
| `item.show` unset or empty | Plain `GenericMediaMetadata`, `title` only, `subtitle` is not set on this path. |
| `item.poster` | Resolved through `resolveUrl(item.poster, 'poster')` and set as the metadata's `images`. |

Options, events, browser restrictions, the volume conversion, and the `transferTo('cast')` boundary are unchanged from the kit. See [Plugin: Cast Sender (core)](/nomercy-player-core/plugins-adapters/cast-sender) for the full surface.
