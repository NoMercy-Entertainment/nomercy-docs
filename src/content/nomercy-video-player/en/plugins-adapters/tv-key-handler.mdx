# Plugin: TV Key Handler

`cls TvKeyHandlerPlugin` (id `str tv-key-handler`) is the same keyboard set aimed at a remote control. A remote has no pointer and no focus ring inside the video. The keys a desktop browser reserves for moving around the page are free to drive playback instead.

It extends [Plugin: Key Handler](/nomercy-video-player/plugins-adapters/key-handler) and keeps everything that set installs. Fifty-five combos are registered in total, read back from `bindings()` on a player running the published build: the desktop fifty-three, with four groups rewritten and two keys added.

## Options

| Option | Type | Default | Purpose |
|---|---|---|---|
| `key arrowSeekSeconds` | `cls number` | `5` | Seconds the left and right arrows seek. |
| `key infoDisplayMs` | `cls number` | `5000` | How long the Info OSD stays up. |

Both are declared by `cls TvKeyHandlerOptions`, and they reach `fn addPlugin` alongside a base option, so spread them in beside one:

```ts
import nmplayer from '@nomercy-entertainment/nomercy-video-player';
import { TvKeyHandlerPlugin } from '@nomercy-entertainment/nomercy-video-player/plugins';
import type { TvKeyHandlerOptions } from '@nomercy-entertainment/nomercy-video-player/plugins';

const player = nmplayer('player');

const tvKeys: TvKeyHandlerOptions = {
  arrowSeekSeconds: 10,
  infoDisplayMs: 8000,
};

player.addPlugin(TvKeyHandlerPlugin, { ...tvKeys, extend: true });
```

Every option the base plugin takes still applies, and the [core page](/nomercy-player-core/plugins-adapters/key-handler) documents them. `key extend` above is one of those, at its own default.

The color buttons keep their fixed 30, 60, 90 and 120 second jumps. `key arrowSeekSeconds` does not reach them.

## What a remote changes

| Group | On desktop | On a remote |
|---|---|---|
| Left and right arrows | Held back, because the page owns focus. | Seek `key arrowSeekSeconds` in that direction. Measured with the option at 10, the two keys reached `fn rewind` and `fn forward` with 10. |
| Up and down arrows | Held back on a TV and on a phone. | Raise and lower the level. A web TV shell that owns system volume forwards them on from there. |
| `str a` and `str BrowserFavorites` | Cycle the aspect ratio, and the control bar shows the result. | Cycle it and put the new ratio on the OSD, since a remote has no control bar to read it from. |

The host page is expected to take focus off its own interactive elements before this plugin mounts. That is the trade the first row makes: the arrows belong to playback for as long as the player is up.

Two keys are new.

`str Info` shows what is playing: the item title, the covering chapter, the elapsed time and the time remaining, joined into one OSD line. It also emits `str plugin:tv-key-handler:info` carrying those five fields separately, so a shell can paint the same facts its own way.

`str MediaRecord` emits `str plugin:tv-key-handler:bookmark` with the current time. Storing it is yours to do, and the key is quiet when nothing is listening.

## The shortcuts overlay

A TV shell brings its own shortcuts overlay rather than sharing the desktop one, so the plugin publishes `str plugin:tv-key-handler:shortcuts-toggle` as the channel between them.

Listen for it, and open the overlay from a binding for whichever key your remote sends:

```ts
import nmplayer from '@nomercy-entertainment/nomercy-video-player';
import { TvKeyHandlerPlugin } from '@nomercy-entertainment/nomercy-video-player/plugins';

const player = nmplayer('player');

player.addPlugin(TvKeyHandlerPlugin);

const sheet = document.createElement('aside');
sheet.hidden = true;
document.body.append(sheet);

const toggleSheet = () => {
  sheet.hidden = !sheet.hidden;
};

await player.ready();

player.on('plugin:tv-key-handler:shortcuts-toggle', toggleSheet);

player.getPlugin(TvKeyHandlerPlugin)?.bind('Help', toggleSheet);
```

## Rules & restrictions

- OSD text goes through `cls MessagePlugin` when that plugin is mounted, and the plugin emits `str display-message` either way. A consumer that prefers the event surface needs no second plugin.
- An OSD line raised without its own duration sits for 3000 ms. The Info OSD passes `key infoDisplayMs` instead, so that one line answers to its own option.
- Every binding calls a player method on this machine. Routing a remote command over a socket is `keyHandler.replace(combo, fn)` on one combo at a time, and the plugin knows nothing about NoMercy Connect on its own.
- The `key translations` field replaces the base plugin's rather than adding to it. Registering merges this plugin's keys into the player's table under `str plugin.tv-key-handler.`, and dispose takes them out again.

## How to extend it

Add a group of your own and call it after the inherited set:

```ts
import nmplayer from '@nomercy-entertainment/nomercy-video-player';
import { TvKeyHandlerPlugin } from '@nomercy-entertainment/nomercy-video-player/plugins';

const player = nmplayer('player');

class MyTvKeyHandler extends TvKeyHandlerPlugin {
  protected addBackKey(): void {
    this.bind('GoBack', () => {
      this.player.emit('back', undefined);
    });
  }

  protected override addDefaults(): void {
    super.addDefaults();
    this.addBackKey();
  }
}

player.addPlugin(MyTvKeyHandler);
```

`fn addDefaults` is the one hook that must call `super`. Every other group replaces itself outright.
