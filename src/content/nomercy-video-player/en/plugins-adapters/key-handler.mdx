# Plugin: Key Handler

`cls KeyHandlerPlugin` (id `str key-handler`) is this library's desktop keyboard set. Transport, volume, track cycling, modifier seeks, chapters, speed, fullscreen and aspect ratio arrive as one registration. Every group behind them is a `protected` method a subclass can replace on its own.

It subclasses the kit's [Plugin: Key Handler](/nomercy-player-core/plugins-adapters/key-handler), which brings scope resolution, the cooldown, input-field awareness and `fn bind` / `fn unbind` / `fn replace`.

[Plugin: TV Key Handler](/nomercy-video-player/plugins-adapters/tv-key-handler) subclasses this one for remote-control input.

## Using it

```ts
import nmplayer, { KeyHandlerPlugin } from '@nomercy-entertainment/nomercy-video-player';

const player = nmplayer('player');

player.addPlugin(KeyHandlerPlugin);

player.setup({
  baseUrl: 'https://raw.githubusercontent.com/NoMercy-Entertainment/nomercy-media/master/Films',
  playlist: [
    {
      id: 'sintel',
      title: 'Sintel',
      url: '/Sintel.(2010)/Sintel.(2010).NoMercy.m3u8',
      duration: 888,
    },
  ],
});

await player.ready();
```

This subclass adds no option fields of its own. `key scope`, `key bindings`, `key extend`, `key when`, `key cooldownMs` and `key disableMediaControls` are the base plugin's, and the core page documents them.

## The bindings

Fifty-three combos install by default. The table below was read back from `player.getPlugin(KeyHandlerPlugin).bindings()` on a player running the published build, so it is the live map rather than a transcription of the source.

The left column is the combo string exactly as the map stores it, which is what you pass to `fn unbind` and `fn replace`.

| Combo | Action |
|---|---|
| The spacebar | Toggle playback. Its combo string is one space, so `fn unbind` takes `ts ' '`. |
| `str MediaPlay` `str MediaPause` `str MediaPlayPause` `str MediaStop` `str MediaRewind` `str MediaFastForward` | Hardware media keys. Gated by `key disableMediaControls` on the player config. |
| `str ArrowLeft` `str ArrowRight` | Rewind or forward five seconds, the kit's own default step. Desktop only: `fn isTv` gates them off. |
| `str ArrowUp` `str ArrowDown` | Volume up or down five percentage points. Desktop only: gated off when `fn isTv` or `fn isMobile` answers true. |
| `str m` | Toggle mute. |
| `str Subtitle` `str 5` `str v` | Cycle subtitle tracks. `str Subtitle` is a remote key. |
| `str Audio` `str 2` `str b` | Cycle audio tracks. `str Audio` is a remote key. |
| `str shift+ArrowLeft` `str shift+ArrowRight` | Seek 3 seconds back or forward. |
| `str alt+ArrowLeft` `str alt+ArrowRight` | Seek 10 seconds back or forward. |
| `str ctrl+ArrowLeft` `str ctrl+ArrowRight` | Seek 60 seconds back or forward. |
| `str 1` `str 3` `str 6` `str 9` | Skip forward 120, 30, 60 and 90 seconds. |
| `str ColorF0Red` `str ColorF1Green` `str ColorF2Yellow` `str ColorF3Blue` | Remote color buttons. Skip forward 30, 60, 90 and 120 seconds. |
| `str MediaTrackNext` `str MediaTrackPrevious` | Next or previous item. Gated by `key disableMediaControls`. |
| `str n` `str p` | Next or previous item. Not gated. |
| `str shift+n` `str shift+p` | Next or previous chapter. |
| `str f` `str F11` | Toggle fullscreen. |
| `str Escape` | Leave fullscreen, when `player.fullscreen()` reads `str on`. |
| `str ]` `str [` | Step up or down one entry in `playbackRates()`, and show the new rate as an OSD message. |
| `str =` | Reset the rate to 1, with the same message. |
| `str e` | Advance one frame at 30 fps. Runs while paused, idle or stopped, and is skipped while playing or loading. |
| `str t` | Show elapsed and remaining time as an OSD message. |
| `str +` `str shift++` `str -` | Emit `str subtitle-size-up` or `str subtitle-size-down`. |
| `str a` `str BrowserFavorites` | Cycle aspect ratio. |
| `str s` | Stop. |
| `str shift+?` | Open the shortcuts overlay on a mounted `cls DesktopUiPlugin`. |

Two rows repay a closer look.

`str +` is the numeric keypad's plus, which arrives with no shift held, and `str shift++` is the main row's. Both raise the same event, so a reader gets the key their keyboard has.

`str subtitle-size-up` and `str subtitle-size-down` are announcements with no listener in the trio. Attach your own and step `subtitleStyle().fontSize` from it.

## The groups

`fn addDefaults` calls sixteen group methods in this order:

`fn addPlaybackKeys`, `fn addNavigationKeys`, `fn addVolumeKeys`, `fn addMediaKeys`, `fn addModifierSeekKeys`, `fn addQuickSkipKeys`, `fn addNextPrevKeys`, `fn addChapterKeys`, `fn addFullscreenKeys`, `fn addSpeedKeys`, `fn addFrameAdvanceKey`, `fn addShowTimeKey`, `fn addSubtitleSizeKeys`, `fn addAspectRatioKeys`, `fn addStopKey`, `fn addHelpKey`.

Each one is `protected`, so overriding a single group leaves the other fifteen installed.

## Rules & restrictions

- One cooldown covers the whole map, not one binding each. At the default 300 ms, two presses inside that window fire once. Measured: a second `str ArrowLeft` sent immediately reached `fn rewind` zero times, and a third sent 350 ms later reached it.
- `key disableControls` on `cls VideoPlayerConfig` returns from `fn addDefaults` before the first group runs, so none of the 53 install. The `key bindings` option is applied afterwards and still does, which is how a config-driven player keeps a chosen few.
- `key disableMediaControls`, also on the config, gates the six `str MediaX` keys and the `str MediaTrackNext` and `str MediaTrackPrevious` pair. It leaves the spacebar, the arrows and every letter key alone.
- `player.fullscreen()` reports the last request rather than the browser, so `str Escape` acts on the player's own flag. `player.platform().fullscreen.isActive()` is the reader that answers for the browser.
- A binding with no modifier fires only when no modifier is held. `str ArrowLeft` and `str shift+ArrowLeft` are independent entries, which is what lets the modifier seeks sit beside the plain ones.

## How to extend it

Override the one group you want to change:

```ts
import nmplayer, { KeyHandlerPlugin } from '@nomercy-entertainment/nomercy-video-player';

const player = nmplayer('player');

class MyKeyHandler extends KeyHandlerPlugin {
  protected override addFullscreenKeys(): void {
    this.bind('f', () => {
      void this.player.toggleFullscreen();
    });
  }
}

player.addPlugin(MyKeyHandler);
```

That leaves `str F11` and `str Escape` unbound and every other group intact. [Recipe: Customizing Keyboard Shortcuts](/nomercy-video-player/recipes/keyboard-shortcuts) covers the range from one runtime `fn bind` call up to replacing `fn addDefaults` outright.
