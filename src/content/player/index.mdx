## What is the Player SDK?

The NoMercy Player SDK is three TypeScript packages that together form a complete media player foundation:

| Package | npm name | Purpose |
|---------|----------|---------|
| `nomercy-player-core` | `@nomercy-entertainment/nomercy-player-core` | Shared kit — lifecycle, queue, auth, plugins, i18n, 28 adapter ports |
| `nomercy-video-player` | `@nomercy-entertainment/nomercy-video-player` | HLS video player — HDR-aware ABR, subtitle rendering, skip markers |
| `nomercy-music-player` | `@nomercy-entertainment/nomercy-music-player` | Music player — WebAudio crossfade, EQ, lyrics, group listening |

## Five-layer architecture

Everything in layers 1–4 is generic — no NoMercy server endpoints, no SignalR protocols, no app-specific logic. Your app glue lives at layer 5 in consumer plugins.

| Layer | Package | What it knows |
|-------|---------|--------------|
| 1. Backend | `IVideoBackend` / `IAudioBackend` impls | Browser APIs: `<video>`, `<audio>`, MediaSource, AudioContext |
| 2. Kit | `nomercy-player-core` | Generic contracts only |
| 3. Per-library | `nomercy-video-player` / `nomercy-music-player` | Generic video / music behavior |
| 4. Built-in plugin | Plugins inside kit and library packages | Domain-generic UI and features |
| 5. Consumer plugin | Your app code | All app-specific glue |

## npm

```
npm install @nomercy-entertainment/nomercy-video-player@beta
npm install @nomercy-entertainment/nomercy-music-player@beta
npm install @nomercy-entertainment/nomercy-player-core@beta
```
