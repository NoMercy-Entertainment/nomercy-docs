# API Methods Reference

All public methods on `NMVideoPlayer<T>`. Methods follow the overloaded getter/setter pattern: `method()` reads, `method(value)` writes.

---

## Factory

### `nmplayer(id)`

```ts
nmplayer(id: string | number): NMVideoPlayer<VideoPlaylistItem>
nmplayer<T extends VideoPlaylistItem>(id: string | number): NMVideoPlayer<T>
```

Creates or retrieves a named player instance. Two calls with the same `id` return the same instance. Instances persist until `dispose()` is called.

---

## Setup

### `setup(opts)`

```ts
setup(opts: VideoPlayerConfig<T>): NMVideoPlayer<T>
```

Initialize the player. Returns the player for chaining. See [Configuration](/player/video/configuration) for all options.

### `ready()`

```ts
ready(): Promise<void>
```

Resolves when setup is complete and all plugins' `use()` promises have resolved.

### `dispose()`

```ts
dispose(): void
```

Tears down the player: stops playback, disposes all plugins, removes event listeners. The instance is removed from the internal registry.

---

## Transport

### `play(opts?)`, `pause(opts?)`, `stop(opts?)`, `restart(opts?)`

```ts
play(opts?: ActionOptions): Promise<void>
pause(opts?: ActionOptions): Promise<void>
stop(opts?: ActionOptions): Promise<void>
restart(opts?: ActionOptions): Promise<void>
togglePlayback(opts?: ActionOptions): Promise<void>
```

`stop()` resets position to 0. `restart()` seeks to 0 and plays. `togglePlayback()` switches between play and pause.

`ActionOptions` carries `source: 'user' | 'auto' | 'remote'` — pass `{ source: 'user' }` when triggered by user input.

## Current item

### `current()`

```ts
current(): T | undefined
```

Return the currently loaded item.

### `current(item, opts?)`

```ts
current(item: T, opts?: ActionOptions): void
```

Set the current item. The item must be in the queue.

### `currentIndex()`

```ts
currentIndex(): number
```

Index of the current item. Returns `-1` if nothing is loaded.

### `load(item, opts?)`

```ts
load(item: T, opts?: LoadOptions): Promise<void>
```

Load a single item without requiring it to be in the queue.

## Queue management

All queue methods mirror the music player. See [Music — API Methods](/player/music/api-methods) for the full queue method signatures — `queue`, `queueAppend`, `queuePrepend`, `queueInsert`, `queueRemove`, `queueRemoveAt`, `queueMove`, `queueClear`, `queueShuffle`, `queueSort`, `queueIndexOf`, `queueLength`.

### `loadQueue(url, parser?)`

```ts
loadQueue(url: string, parser?: (response: Response) => Promise<T[]>): Promise<void>
```

Fetch a URL and replace the queue. Uses the player's auth pipeline. Optionally supply a custom parser if the response is not a raw JSON array.

## Phase and diagnostics

### `phase()`

```ts
phase(): PlayerPhase
```

Current phase: `'idle' | 'setup' | 'ready' | 'loading' | 'starting' | 'playing' | 'paused' | 'buffering' | 'seeking' | 'ended' | 'stopped' | 'disposing' | 'disposed'`.

### `playState()`

```ts
playState(): PlayState  // 'idle' | 'loading' | 'playing' | 'paused' | 'stopped' | 'error'
```

### `metrics()`

```ts
metrics(): PlaybackMetrics
```

Snapshot of playback metrics. `ttfb`, `avgBitrate`, and `decoderStalls` are `null` on the html5 backend — they are not currently wired. `droppedFrames` is `number` (from `getVideoPlaybackQuality()`). Guard nullable fields before use.

### `bandwidth()`

```ts
bandwidth(): number
```

Current estimated bandwidth in bits/sec (from hls.js).

### `now()`

```ts
now(): number
```

Monotonic clock. Uses `options.clockSource()` if configured, else `Date.now()`.
