# Subtitle Overlay

Two plugins handle subtitle rendering. Use `SubtitleOverlayPlugin` for VTT/SRT text subtitles. Use `OctopusPlugin` for ASS/SSA subtitles with full typesetting.

---

## VTT subtitles — SubtitleOverlayPlugin

Renders WebVTT cues as styled DOM elements over the video.

```ts
import { SubtitleOverlayPlugin } from '@nomercy-entertainment/nomercy-video-player';

player.addPlugin(SubtitleOverlayPlugin);
```

Pass subtitle tracks with each playlist item:

```ts
player.setup({
  queue: [
    {
      id: '1',
      url: 'https://cdn.example.com/ep1.m3u8',
      subtitles: [
        { id: 'en', language: 'en', label: 'English', file: 'ep1.en.vtt', kind: 'subtitles' },
        { id: 'nl', language: 'nl', label: 'Dutch',   file: 'ep1.nl.vtt', kind: 'subtitles' },
      ],
    },
  ],
  defaultSubtitleLanguage: 'en',
});
```

Switch tracks at runtime:

```ts
const tracks = player.subtitles();
player.currentSubtitle(0);     // activate first track
player.currentSubtitle(null);  // disable subtitles
```

User style preferences (font size, color, background opacity) are persisted via the `ISubtitleStyleStore` adapter. The default `StorageBackedSubtitleStyleStore` writes to `LocalStorage`.

## ASS/SSA subtitles — OctopusPlugin

The `OctopusPlugin` uses `@nomercy-entertainment/nomercy-subtitle-octopus` (a fork of `JavascriptSubtitlesOctopus`) for full ASS/SSA typesetting — custom fonts, karaoke effects, motion, complex positioning.

**The octopus package is an optional dependency.** Install it separately:

```
npm install @nomercy-entertainment/nomercy-subtitle-octopus
```

The plugin uses a dynamic `import('@nomercy-entertainment/nomercy-subtitle-octopus')` at runtime. If the package is absent, the plugin runs in degraded mode (no rendering, no errors). Enable `logLevel: 'debug'` to confirm the fallback.

```ts
import { OctopusPlugin } from '@nomercy-entertainment/nomercy-video-player';

player.addPlugin(OctopusPlugin, {
  workerUrl: '/static/subtitles-octopus-worker.js',
  legacyWorkerUrl: '/static/subtitles-octopus-worker-legacy.js',
  fallbackFont: '/static/fonts/Roboto.ttf',
});
```

The worker files come from the `@nomercy-entertainment/nomercy-subtitle-octopus` package. Copy them to your public directory during build:

```ts
// vite.config.ts
import { viteStaticCopy } from 'vite-plugin-static-copy';

export default {
  plugins: [
    viteStaticCopy({
      targets: [
        {
          src: 'node_modules/@nomercy-entertainment/nomercy-subtitle-octopus/dist/*.js',
          dest: 'static',
        },
      ],
    }),
  ],
};
```

## OctopusPlugin options

```ts
interface OctopusOptions {
  workerUrl?: string;          // Modern worker (required for WASM). Default: bundled URL.
  legacyWorkerUrl?: string;    // Asm.js fallback worker for older browsers.
  fallbackFont?: string;       // Font used when ASS font is not found.
  targetFps?: number;          // Rendering frame rate. Default: 24.
  renderMode?: 'wasm' | 'js'; // Backend. Default: 'wasm'.
  debug?: boolean;             // Verbose octopus logging.
  prescaleFactor?: number;     // Resolution scale factor (0–1). Default: 1.
  renderAhead?: number;        // Frames to render ahead. Default: 0.
}
```

## Font loading

ASS subtitles embed font names. The player loads fonts via the font manifest:

```ts
// Pass a font manifest URL with each playlist item
player.setup({
  queue: [
    {
      id: '1',
      url: '...ep1.m3u8',
      tracks: [
        { kind: 'fonts', file: 'https://cdn.example.com/ep1-fonts.json' },
      ],
    },
  ],
});
```

Font manifest format (JSON array):

```json
[
  { "file": "https://cdn.example.com/fonts/NotoSans.ttf", "mimeType": "font/ttf" },
  { "file": "https://cdn.example.com/fonts/ScriptBold.otf", "mimeType": "font/otf" }
]
```

The plugin loads fonts lazily before first render.

## Subtitle cue stream

The player emits `subtitleCue` events as active cues change. This is the low-level cue stream — useful for custom renderers:

```ts
player.on('subtitleCue', ({ trackIndex, cues }) => {
  renderMyCues(cues);
});
```

## Track selection API

```ts
player.subtitles();                // SubtitleTrack[]
player.currentSubtitle();          // number | null (null = off)
player.currentSubtitle(0);         // activate by index
player.currentSubtitle(null);      // disable
player.subtitleState();            // 'on' | 'off'
```

The `subtitle` event fires on changes:

```ts
player.on('subtitle', ({ index }) => {
  console.log(`Subtitle track: ${index ?? 'off'}`);
});
```
