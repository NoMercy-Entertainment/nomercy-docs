# Chapters

Chapters let users jump to named sections of a video (Cold Open, Act 1, Credits). The player reads them from a VTT file using the built-in `VttChapterSource`, or from any custom `IChapterSource` — a JSON API, a server-side lookup, or an embedded manifest field. `DesktopUiPlugin` renders chapter markers on the seek bar automatically when chapters are present.

---

## Providing chapters

Pass a chapters URL with each playlist item:

```ts
player.setup({
  queue: [
    {
      id: '1',
      url: 'https://cdn.example.com/ep1.m3u8',
      chapters: [
        { id: 'cold-open', startTime: 0,    endTime: 90,  title: 'Cold Open' },
        { id: 'act-1',     startTime: 90,   endTime: 900, title: 'Act 1' },
        { id: 'act-2',     startTime: 900,  endTime: 1800, title: 'Act 2' },
        { id: 'credits',   startTime: 1800, endTime: 2700, title: 'Credits' },
      ],
    },
  ],
});
```

Or reference a VTT chapter file via the `tracks` sidecar:

```ts
{
  id: '1',
  url: 'https://cdn.example.com/ep1.m3u8',
  tracks: [
    { kind: 'chapters', file: 'https://cdn.example.com/ep1.chapters.vtt' },
  ],
}
```

The `VttChapterSource` adapter (default) loads the VTT file and parses WEBVTT chapter cues.

---

## Chapter event

The player emits `chapter` when `currentTime()` enters a new chapter range:

```ts
player.on('chapter', ({ index, title }) => {
  updateChapterDisplay(index, title);
});
```

---

## Chapter API

```ts
player.chapters();          // Chapter[] — all chapters for the current item
player.currentChapter();    // Chapter | undefined — active chapter at currentTime()
```

`Chapter` shape:

```ts
interface Chapter {
  id: string;
  startTime: number;  // seconds
  endTime: number;    // seconds
  title: string;
}
```

## Custom chapter source

Implement `IChapterSource` to load chapters from a different format or source.

When calling your API from inside a plugin, use `this.fetch()` instead of the global `fetch`. The plugin's `this.fetch()` applies the player's bearer token, handles 401 refresh-and-retry, and respects the retry policy — raw `fetch()` skips all of that.

```ts
import { Plugin } from '@nomercy-entertainment/nomercy-player-core';
import type { IChapterSource } from '@nomercy-entertainment/nomercy-video-player';
import type { Chapter, VideoPlaylistItem } from '@nomercy-entertainment/nomercy-video-player';

class ApiChapterSource extends Plugin implements IChapterSource {
  static readonly id = 'my-chapter-source';
  static readonly description = 'Chapter source from /api/chapters/:id';

  async load(item: VideoPlaylistItem): Promise<Chapter[]> {
    // this.fetch applies bearer token + 401 refresh + retry policy
    const data = await this.fetch<ApiChapter[]>(`/api/chapters/${item.id}`, {
      responseType: 'json',
    });
    return data.map(ch => ({
      id: String(ch.id),
      startTime: ch.start_ms / 1000,
      endTime: ch.end_ms / 1000,
      title: ch.name,
    }));
  }
}

player.setup({
  chapterSource: new ApiChapterSource(),
});
```

The built-in `VttChapterSource` uses `this.fetch()` the same way — auth-aware, no manual token threading required.

---

## Chapter display in the DesktopUiPlugin

`DesktopUiPlugin` renders chapter markers on the seek bar automatically when chapters are available. Hovering a chapter marker shows the chapter title. No additional configuration needed.
