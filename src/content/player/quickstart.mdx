# Quick Start

Read this if you have never used the NoMercy Player SDK before. Three integration styles — pick the one that matches your setup. Every snippet below is verified — paste it into a fresh project and it runs.

**Success looks like:** a `<div id="player">` fills with the player UI, the video or audio loads, and playback starts on `ready` without errors in the console.

---

## ESM bundler (Vite, webpack, etc.)

Install the video player:

```
npm install @nomercy-entertainment/nomercy-video-player@beta
```

Minimal working video player — Sintel from the public CC-licensed nomercy-media catalog:

```ts
import nmplayer from '@nomercy-entertainment/nomercy-video-player';
import { DesktopUiPlugin } from '@nomercy-entertainment/nomercy-video-player/plugins';

const NM_MEDIA = 'https://raw.githubusercontent.com/NoMercy-Entertainment/nomercy-media/master/Films';

const player = nmplayer('player')
  .addPlugin(DesktopUiPlugin)
  .setup({
    basePath: NM_MEDIA,
    playlist: [
      {
        id: 'sintel',
        title: 'Sintel',
        url: '/Sintel.(2010)/Sintel.(2010).NoMercy.m3u8',
        image: 'https://image.tmdb.org/t/p/w780/q2bVM5z90tCGbmXYtq2J38T5hSX.jpg',
        duration: 888,
      },
    ],
  });

player.on('ready', () => {
  player.current(0, { autoplay: true });
});
```

Install the music player (separate package, not bundled with the video player):

```
npm install @nomercy-entertainment/nomercy-music-player@beta
```

Minimal working music player — a real Derek Clegg track from nomercy-media:

```ts
import nmMPlayer from '@nomercy-entertainment/nomercy-music-player';
import { AutoAdvancePlugin } from '@nomercy-entertainment/nomercy-music-player/plugins';

const FMA = 'https://raw.githubusercontent.com/NoMercy-Entertainment/nomercy-media/master/Music';

const player = nmMPlayer('player')
  .addPlugin(AutoAdvancePlugin)
  .setup({
    playlist: [
      {
        id: 'derek-clegg-thaw',
        name: 'Thaw You Out',
        url: `${FMA}/D/Derek%20Clegg/%5B2010%5D%20KJC/01%20Thaw%20You%20Out.mp3`,
        artist_track: [{ id: 1, name: 'Derek Clegg' }],
      },
    ],
  });

player.on('ready', () => {
  player.current(0, { autoplay: true });
});
```

Why `current(0, { autoplay: true })` in the `ready` handler? `setup({ playlist: [...] })` auto-queues the inline array, but doesn't select or play. Calling `current(0, { autoplay: true })` selects the first item and starts playback in one step — race-free.

## CDN embed (no bundler)

For landing pages, simple sites, or anywhere you cannot use a build step. The IIFE bundle exposes the factory as a `nmplayer` / `nmMPlayer` global. Built-in plugins are not included in the IIFE bundle — install via npm and use ESM when you need them.

Video player:

```html
<!DOCTYPE html>
<html>
<head>
  <title>Player</title>
  <style>
    #player { width: 100%; max-width: 900px; aspect-ratio: 16/9; background: #000; }
  </style>
</head>
<body>
  <div id="player"></div>

  <script src="https://cdn.jsdelivr.net/npm/@nomercy-entertainment/nomercy-video-player@beta/dist/nomercy-video-player.iife.js"></script>
  <script>
    var NM_MEDIA = 'https://raw.githubusercontent.com/NoMercy-Entertainment/nomercy-media/master/Films';
    var player = window.nmplayer('player').setup({
      basePath: NM_MEDIA,
      playlist: [
        {
          id: 'sintel',
          title: 'Sintel',
          url: '/Sintel.(2010)/Sintel.(2010).NoMercy.m3u8',
          duration: 888,
        },
      ],
    });

    player.on('ready', function () {
      player.current(0, { autoplay: true });
    });
  </script>
</body>
</html>
```

## Framework integration

### Vue 3

```ts
// composables/useVideoPlayer.ts
import { onMounted, onUnmounted, shallowRef } from 'vue';
import nmplayer from '@nomercy-entertainment/nomercy-video-player';
import { DesktopUiPlugin } from '@nomercy-entertainment/nomercy-video-player/plugins';
import type { NMVideoPlayer } from '@nomercy-entertainment/nomercy-video-player';

export function useVideoPlayer() {
  const player = shallowRef<NMVideoPlayer | null>(null);

  onMounted(() => {
    const instance = nmplayer('player')
      .addPlugin(DesktopUiPlugin)
      .setup({
        basePath: 'https://raw.githubusercontent.com/NoMercy-Entertainment/nomercy-media/master/Films',
        playlist: [
          { id: 'sintel', title: 'Sintel', url: '/Sintel.(2010)/Sintel.(2010).NoMercy.m3u8', duration: 888 },
        ],
      });

    instance.on('ready', () => instance.current(0, { autoplay: true }));
    player.value = instance;
  });

  onUnmounted(() => {
    player.value?.dispose();
    player.value = null;
  });

  return { player };
}
```

```vue
<!-- VideoPlayer.vue -->
<script setup lang="ts">
import { useVideoPlayer } from '@/composables/useVideoPlayer';
const { player } = useVideoPlayer();
</script>

<template>
  <div id="player"></div>
</template>
```

Use `shallowRef` — `NMVideoPlayer` is a class with internal state. A regular `ref` deep-proxies the instance which breaks event emission and queue methods.

### React

```tsx
// components/VideoPlayer.tsx
import { useEffect, useRef } from 'react';
import nmplayer from '@nomercy-entertainment/nomercy-video-player';
import { DesktopUiPlugin } from '@nomercy-entertainment/nomercy-video-player/plugins';
import type { NMVideoPlayer } from '@nomercy-entertainment/nomercy-video-player';

export function VideoPlayer() {
  const playerRef = useRef<NMVideoPlayer | null>(null);

  useEffect(() => {
    const player = nmplayer('player')
      .addPlugin(DesktopUiPlugin)
      .setup({
        basePath: 'https://raw.githubusercontent.com/NoMercy-Entertainment/nomercy-media/master/Films',
        playlist: [
          { id: 'sintel', title: 'Sintel', url: '/Sintel.(2010)/Sintel.(2010).NoMercy.m3u8', duration: 888 },
        ],
      });

    player.on('ready', () => player.current(0, { autoplay: true }));
    playerRef.current = player;

    return () => {
      player.dispose();
      playerRef.current = null;
    };
  }, []);

  return <div id="player" />;
}
```

## Authentication

If your media sources require authorization:

```ts
const player = nmplayer('main').setup({
  playlist: [{ id: '1', url: 'https://protected.cdn.your-domain.com/stream.m3u8' }],
  auth: {
    bearerToken: () => myAuth.getAccessToken(),
    refreshOnUnauthenticated: async () => {
      await myAuth.refresh();
      return myAuth.getAccessToken();
    },
  },
});

player.on('ready', () => player.current(0, { autoplay: true }));
```

The player injects `Authorization: Bearer <token>` on every HLS manifest and segment request. On 401, `refreshOnUnauthenticated` is called once and the request is retried. On 403, the error propagates — the player never retries a 403.
