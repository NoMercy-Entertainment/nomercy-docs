# Discs (DVD and Blu-ray)

The Ripper reads a disc in your server's drive and adds it to a library.

## Before you start

The drive has to be attached to the machine running the server. A drive in your laptop is not visible to a server running on another machine.

You also need a library to put the result in. See [Library Management](/nomercy-media-server/libraries).

## Rip a disc

1. Put the disc in the server's drive.
2. Open the dashboard and go to **Ripper**.
3. The drive appears in the list on the left. When the disc has been read, it shows **Disc ready**.
4. Select the drive. The disc is scanned, and you get its name, its length, and the list of titles on it.
5. Check the identification panel. If NoMercy matched the wrong film, correct it here.
6. Choose **Rip disc**.

Progress appears as a task card. You can keep working while it runs. When it finishes, the title shows up on your home screen.

## Fixing a wrong match

Correct the match before you start the rip, not after. The match decides the artwork, the title, and where the result is filed.

Discs with generic volume labels are the usual cause. A label like `LOGICAL_VOLUME_1` gives the matcher nothing to work with.

::Troubleshooting

**The drive is not in the list.**
The drive has to be on the server machine. If it is, use **Refresh**.

**The disc never reaches "Disc ready".**
The drive may not be able to read that disc type. Some drives read DVDs but not Blu-rays. Try the disc in another player to rule out damage.

**The wrong film was matched.**
Fix it in the identification panel before ripping.

::
