# Coming from another media server

You already run another media server and want to try NoMercy with the same files. This page covers what comes across and how to do it.

## What comes across

Your media files come across. NoMercy builds its own library from them.

NoMercy has no importer for another server's data. The other server's database, users, watch history, playlists and settings stay where they are. You invite your users again, and watch progress starts fresh.

## Before you start

- The media folders must be on the server machine, or on a share the server can reach. See [Storage](/nomercy-media-server/storage).
- NoMercy is installed and first-run setup is done. See the [installation guide](/nomercy-media-server/installation-guide).
- Keep the other server and its data until you have checked the new library.

## Point NoMercy at your folders

Make one library per kind of content, the same way the other server splits them.

1. Open the dashboard and go to **Libraries**.
2. Create a library and pick its type: Movies, TV Shows or Music. [Library Management](/nomercy-media-server/libraries) explains the types.
3. Add the folder that already holds that content.
4. Repeat for each kind of content you have.

When you add a folder that already holds media, the server scans it and lists what it finds. You do not copy or move anything.

Scanned files are listed in their original form. They are not converted unless **Auto-encode files found by scanning** is on in the library's settings. [Adding and scanning files](/nomercy-media-server/media/scanning) explains the difference between scanning files in place and adding content for encoding.

## Folder names from the other server

NoMercy works out what a file is from its name and the folder around it. The layout most media servers ask for is read as it is:

```text
Arrival (2016)/Arrival (2016).mkv
The Expanse/Season 01/The Expanse - S01E03.mkv
```

An episode in a `Season 01` folder takes its season from the folder when the file name leaves the season out.

The `.nfo` metadata files another server may have written into those folders are not read. NoMercy matches each title again and fetches its own details.

## Check the result

1. Wait for the scan to finish. The task list on the dashboard shows it.
2. Open a few titles in each library. Look first at movies with common names and at episodes with unclear numbering.
3. Correct a wrong match from the title's page. See [Metadata](/nomercy-media-server/media/metadata).
4. Play one title per library on the device you use most.

::Troubleshooting

**Everything matched the wrong thing.**
Check the library's type. Films in a TV Shows library are read as episodes.

**A library stays empty.**
The server cannot see the folder. Check the path on the server machine, and check that the share is mounted there.

::
