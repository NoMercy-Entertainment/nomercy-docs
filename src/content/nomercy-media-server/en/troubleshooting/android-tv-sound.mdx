# No sound on Android TV with a soundbar

Use this order when video plays in the NoMercy Android TV app but the soundbar is silent. Change one setting at a time and replay the same title after each step.

## 1. Check where sound is going

1. Confirm the soundbar is on and set to its TV or HDMI ARC input.
2. Check that the HDMI cable runs from the TV's ARC or eARC port to the soundbar's ARC or eARC port. A regular HDMI input may carry video without returning TV audio to the bar.
3. In the TV's sound settings, select the soundbar or HDMI ARC/eARC output. Test another app on the same Android TV box. If that app is silent too, fix the TV-to-soundbar route before changing NoMercy settings.

## 2. Test a compatible audio format

In the TV or Android TV box's audio settings, start with the output format set to **Auto**. If the title is still silent, try **PCM** or **Stereo** as a diagnostic. If PCM works, the HDMI route is working and the issue is likely the format negotiated among the box, TV, and soundbar.

Check the TV's digital audio output or pass-through setting and the soundbar's supported Dolby formats before restoring Auto. Menu names and supported formats vary by device.

Do not assume that a Dolby label on the title means every device in the HDMI chain can play that exact audio format. Test a second title with a different audio track before changing a server encoding profile.

## 3. Check volume and mute

Use the TV or soundbar remote to unmute and raise the soundbar volume. On an ARC-connected TV, the soundbar owns the volume level. The NoMercy Android client sends relative volume steps for this route; setting an absolute app volume may not change the amplifier.

If the on-screen volume indicator moves but there is still no sound, return to the output and format checks above.

## 4. Isolate the failing link

Try the same title on another NoMercy client, then try another title on this Android TV box. If only one title is silent, select a different audio track for that title.

If every title is silent only on the TV box while other apps have sound, restart playback after checking the box's output format. If every app is silent, inspect the box, TV, cable, and soundbar settings.

For a playback failure that includes an error or buffering, see [Common issues](/nomercy-media-server/troubleshooting/common-issues).
