# Repositories and trust

A repository is a catalogue of plugins your server can install from. Trust is decided per repository, by you.

## The default repository

Your server starts with the official NoMercy repository configured and marked trusted.

## Adding a repository

Add one from the Plugins section of the dashboard by giving its catalogue address. Refreshing it pulls the current list, and the available plugins then show alongside what you already have, with updates flagged.

Only the server owner can add or remove a repository.

## What trusted means

Marking a repository trusted says: plugins from here do not need me to approve their capabilities.

A plugin from a trusted repository skips the consent step described in [Plugins overview](/nomercy-media-server/plugins/overview) and starts enabled, even when it asks for the network or its own endpoints.

A plugin from an untrusted repository installs the same way, then waits for you.

Trust attaches to the repository, never to a name inside a plugin's own manifest. A plugin cannot describe itself as trustworthy; trust only comes from you having marked the place it came from.

## Whether to trust one

Trusting a repository is trusting its owner with your server, continuously. It applies to every plugin they publish now and to every update they push later.

Trust the official repository. Trust others only when you would also let that person run software on your machine unattended.

Leaving a repository untrusted costs you one approval per plugin and keeps the decision in your hands.

## What is checked regardless

Trusted or not, every install is checked for two things.

**Version compatibility.** A plugin built against a different server version is rejected rather than loaded.

**Checksum.** A plugin downloaded from a repository is checked against the checksum that repository published, so a file altered in transit does not install.

## A note on the name

Elsewhere in the dashboard you may meet **trusted publishers** under encoding. That is a different feature: it verifies signatures on imported encoding profiles. It has nothing to do with plugins.
