# Plugins from the CLI

Plugins extend the server. The dashboard is where you install and configure them. The CLI can tell you what is installed, which is what you need when you are diagnosing something over a terminal.

## List installed plugins

```bash
nomercy plugin list
```

## When a plugin is the suspect

A plugin that fails to load says so in the log:

```bash
nomercy logs --level Warning,Error
```

Comparing that against `plugin list` tells you whether a plugin you expected is actually loaded.
