# Queue

The server does its heavy work in a queue: encoding titles, fetching artwork, building preview thumbnails. When a title has not appeared yet, the queue is the answer.

## See the queue

```bash
nomercy queue status
```

This shows what is waiting and what is being worked on right now.

## Reading the result

Work is processed in order, so a long list is not a stall. A title added after thirty others waits for those thirty.

Encoding a title is the slow part, and how slow depends on the machine and whether the server can use a GPU. See [Encoding overview](/nomercy-media-server/encoding/overview).

If the queue is empty and a title still has not appeared, the work never started. The log says why:

```bash
nomercy logs --level Warning,Error
```
