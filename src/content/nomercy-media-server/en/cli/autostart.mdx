# Autostart

A media server is expected to be there. Autostart makes it come back on its own after a reboot or a power cut, without someone signing in to start it.

## Check

```bash
nomercy autostart status
```

## Turn it on

```bash
nomercy autostart enable
```

## Turn it off

```bash
nomercy autostart disable
```

## What it does per platform

On Windows the server is registered to start with the machine. On macOS it runs as a launch agent. On Linux it runs as a systemd service.

For a Debian or RPM package, enable and start the packaged user unit with `systemctl --user enable --now nomercymediaserver.service`. On a machine that should run without anyone logged in, also run `loginctl enable-linger $USER`. The Arch package does not ship this unit. Docker handles boot through the `restart: unless-stopped` policy in the compose file.
