# Autostart

A media server is expected to be there. Autostart makes it come back on its own after a reboot or a power cut, without someone signing in to start it.

## Check

```bash
nomercy autostart status
```

## Turn it on

```bash
nomercy autostart enable
```

## Turn it off

```bash
nomercy autostart disable
```

## What it does per platform

On Windows the server is registered to start with the machine. On macOS it runs as a launch agent. On Linux it runs as a systemd service.

Linux packages install a user service but do not enable it. After installing a Debian or RPM package, run `systemctl --user enable --now nomercymediaserver.service`. On a headless server, run `sudo loginctl enable-linger "$USER"` so the user service can run without a login session. The Arch package does not include a service unit; see its installation page. Docker handles restarts through the `restart: unless-stopped` policy in the compose file.
