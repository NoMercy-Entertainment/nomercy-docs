# Configuration

Settings live in the server, not in a file you edit. The dashboard is the normal place to change them. The CLI is there for a machine with no screen.

## See the current configuration

```bash
nomercy config get
```

This prints what the server is actually using, which is the useful thing when a setting was changed somewhere and you want to confirm it took.

## Change a setting

```bash
nomercy config set <key> <value>
```

Take the key from the output of `config get`, so you are setting something that exists rather than something you assumed.

Some settings apply immediately and some need a restart. Restart with:

```bash
nomercy restart
```

## Prefer the dashboard

Everything here is also in the dashboard under Settings, with the valid choices shown and a description next to each one. Use the dashboard when the machine has a screen.
