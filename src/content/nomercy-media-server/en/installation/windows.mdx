# Windows

Windows uses a normal installer. Nothing else has to be installed first: the server carries everything it needs, including its own .NET runtime.

## Install

1. Download the installer from the [latest release](https://github.com/NoMercy-Entertainment/nomercy-media-server/releases/latest). The file is named `NoMercyMediaServer-<version>-windows-x64-setup.exe`.
2. Run it and follow the prompts.
3. The server starts when the installer finishes, and opens the setup page in your browser.

Windows builds are 64-bit Intel or AMD.

## Allow it through the firewall

Windows asks about network access the first time the server runs. Allow it.

If you dismiss that prompt, your other devices cannot reach the server. You can fix it afterwards in Windows Defender Firewall by allowing `NoMercyMediaServer` on private networks.

## What runs afterwards

The server runs in the background and starts with Windows. A tray icon gives you start, stop, restart and a link to the logs.

## If the setup page does not open

Browse to `http://localhost:7626/setup` yourself.

If nothing answers there, the server has not started. Check the tray icon, and check that nothing else is using port 7626.
