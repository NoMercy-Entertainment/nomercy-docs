# macOS

macOS has an installer package, and standalone binaries for people who would rather not use one.

Both are self-contained. Each carries its own .NET runtime.

## Install with the package

1. Download `NoMercyMediaServer-<version>-macos-x64-setup.pkg` from the [latest release](https://github.com/NoMercy-Entertainment/nomercy-media-server/releases/latest).
2. Open it and follow the prompts.
3. The server starts when installation finishes and opens the setup page in your browser.

## Apple Silicon

The installer package is built for Intel Macs. It runs on Apple Silicon through Rosetta.

If you would rather run natively, take the standalone `NoMercyMediaServer-<version>-macos-arm64` binary from the same release and run it directly.

## If macOS blocks it

macOS may refuse to open a download from outside the App Store. Open **System Settings**, go to **Privacy & Security**, and choose **Open Anyway** next to the blocked item.

## If the setup page does not open

Browse to `http://localhost:7626/setup` yourself.
