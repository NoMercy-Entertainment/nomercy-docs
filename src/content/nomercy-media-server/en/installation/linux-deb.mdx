# Linux (Debian and Ubuntu)

Debian and Ubuntu install from the NoMercy apt repository, so updates arrive with the rest of your system updates.

Packages are built for 64-bit Intel and AMD.

## Add the repository and install

```bash
wget -O - https://repo.nomercy.tv/nomercy_repo.gpg.pub | sudo gpg --dearmor -o /etc/apt/keyrings/nomercy-archive-keyring.gpg
echo "deb [signed-by=/etc/apt/keyrings/nomercy-archive-keyring.gpg] https://repo.nomercy.tv/apt stable main" | sudo tee /etc/apt/sources.list.d/nomercy.list
sudo apt update && sudo apt install nomercy
```

The package is self-contained. It carries its own .NET runtime.

## Updating

```bash
sudo apt update && sudo apt upgrade
```

## Complete setup

A server installed this way runs as a service, so there is no browser to open and no terminal output to watch.

Browse to `http://<your-server-ip>:7626/setup` from any machine on your network.

If you would rather work from the terminal, `nomercy logs` shows the setup link and the sign-in code.
