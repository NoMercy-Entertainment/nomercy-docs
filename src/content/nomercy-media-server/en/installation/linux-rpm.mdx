# Linux (Fedora, RHEL and CentOS)

Fedora, RHEL and CentOS install from the NoMercy rpm repository, so updates arrive with the rest of your system updates.

Packages are built for 64-bit Intel and AMD.

## Add the repository and install

```bash
sudo dnf config-manager --add-repo https://repo.nomercy.tv/rpm/nomercy.repo
sudo rpm --import https://repo.nomercy.tv/nomercy_repo.gpg.pub
sudo dnf install nomercy
```

The package is self-contained. It carries its own .NET runtime.

## Updating

```bash
sudo dnf upgrade nomercy
```

## Complete setup

Start and enable the packaged systemd user service before opening setup:

```bash
systemctl --user enable --now nomercymediaserver.service
```

Browse to `http://<your-server-ip>:7626/setup` from any machine on your network.

If you would rather work from the terminal, `nomercy logs` shows the setup link and the sign-in code.
