# Installation Guide

Pick the page for your platform below. Each one covers the installer for that channel.

## Choose your platform

- [Windows](/nomercy-media-server/installation/windows)
- [Linux (.deb)](/nomercy-media-server/installation/linux-deb)
- [Linux (.rpm)](/nomercy-media-server/installation/linux-rpm)
- [Linux (Arch)](/nomercy-media-server/installation/linux-arch)
- [macOS](/nomercy-media-server/installation/macos)
- [Docker](/nomercy-media-server/installation/docker)
- [NAS](/nomercy-media-server/installation/nas)

Linux packages are published to `repo.nomercy.tv` (apt, rpm, and Arch repositories); Docker images are published to `ghcr.io/nomercy-entertainment/nomercymediaserver`.

## After installing

Once the server is running, open the setup page at `http://localhost:7626/setup`, or at `http://<your-server-ip>:7626/setup` from another machine, and complete first-run configuration. On a desktop install that page opens by itself.

Setup links your NoMercy account to the server and gets it a secure address. You can create the account during setup if you do not have one. See [First-Run Setup](/nomercy-media-server/first-run).

When it finishes you are taken to the NoMercy app, where you create your first library. See [Library Management](/nomercy-media-server/libraries).

## What is built

| Platform | Architecture |
|----------|--------------|
| Windows installer | 64-bit Intel and AMD |
| macOS installer | Intel, and Apple Silicon through Rosetta |
| macOS standalone binary | Intel and Apple Silicon |
| Linux packages (deb, rpm, Arch) | 64-bit Intel and AMD |
| Docker images | `linux/amd64` |

Setup needs an internet connection to link your account and get a certificate.

## Troubleshooting

If you encounter installation issues:

- Ensure port 7626 is available (the server also binds a loopback-only health check on 7627)
- Review the installation logs
- Consult the FAQ or open an issue on GitHub
