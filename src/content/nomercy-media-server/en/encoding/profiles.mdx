# Encoding profiles

A preset is the format your library is kept in: which video codec, which audio, how many quality steps, and which container.

Every library folder has one, and everything imported into that folder is stored the way it says. That is the whole point of it. Pick the one you want your collection to be in and the shelf becomes one thing instead of an accumulation.

Every preset here plays. The server converts anything a client cannot take directly, while it plays, so this choice is about the library, never about whether something works.

The exception is the machine itself. Converting a 4K Dolby Atmos source in real time asks a lot, and a small server or a NAS may not keep up. Encoding those titles into something it can send as they are, or into a ladder of bitrates a client can pick from, moves that work off playback. See [Encoding overview](/nomercy-media-server/encoding/overview).

## The default

**H.264 Streaming (Universal)** is the default. It produces a full H.264 ladder from 144p up to 2160p.

## Streaming presets

These produce a ladder of quality steps, which is what lets a client switch quality mid-play without stalling.

| Preset | Keeps the library as |
|--------|----------|
| H.264 Streaming (Universal) | H.264. The default. |
| HEVC Streaming (Premium) | HEVC. Roughly half the bitrate for the same picture. |
| AV1 Streaming (Efficient) | AV1. The cheapest bitrate per step, and the slowest to produce. |
| DASH Streaming (Universal) | MPEG-DASH rather than HLS. |

There are also HDR and tone-mapped ladders for HDR sources.

## Fixed-resolution presets

The ladders above adapt to each source. These pin every title in a library to one resolution instead, which suits a library where you want everything to land in the same shape.

Height clamps to the source, so a lower-resolution episode is never stretched to meet the name.

| Preset | What it does |
|--------|--------------|
| Anime 1080p HEVC 10-bit | HEVC 10-bit at 1080p, tuned for animation. Flat colour and hard line art get the bitrate that the default tuning spends on film grain. |
| 1080p HEVC 10-bit | HEVC 10-bit 1080p at CRF 18. Visually lossless against a 1080p source. |
| 1080p SDR HEVC 10-bit | The same, for libraries you want kept in SDR. |
| 4K HDR HEVC 10-bit | HEVC 10-bit 2160p with HDR carried through untouched. |

## Archive presets

These re-encode the video and copy the audio and subtitles untouched. They produce one file, not a ladder, so they are for keeping rather than for streaming to many devices.

| Preset | What it does |
|--------|--------------|
| HEVC Archive (Visually Lossless) | HEVC 10-bit at CRF 18. Indistinguishable at normal viewing distance, typically 40 to 60 percent smaller. |
| HEVC Space Saver | HEVC 10-bit at CRF 22. The best size-to-quality trade for a large library. |
| AV1 Archive (Maximum Compression) | AV1 10-bit at CRF 26. Smallest files here, and slow to produce. |

## Single-file presets

One MP4 rather than a ladder. Useful when you want a file you can copy somewhere else.

| Preset | What it does |
|--------|--------------|
| H.264 MP4 (Universal) | H.264 with stereo AAC. |
| HEVC MP4 (High Quality) | Smaller than the H.264 export at the same quality. |
| H.264 MP4 1080p (2-Pass 5 Mbps) | A fixed-bitrate 1080p file. |
| Legacy Device H.264 Baseline | The most conservative H.264 settings, for a file you are handing to something else entirely. |

## Remux

**Remux (Lossless MKV)** copies every track straight into an MKV. Nothing is re-encoded.

Use it when the source is already exactly what you want and only the container is wrong. It costs one pass over the disk and no quality.

It is not a streaming preset, so it does not produce quality steps.

## Choosing

Decide what you want your collection to be, then pick the preset that says it:

- Storage is tight. **HEVC Space Saver**.
- The smallest library you can have, and you do not mind slow encodes. **AV1 Archive**.
- The sources are already what you want, and only the container is wrong. **Remux**.
- Every title at the same resolution. A fixed-resolution preset.
- The machine cannot convert your heaviest sources in real time. A streaming preset, so the steps exist ahead of time.
- No strong opinion. The default.

A device that struggles with a title is not a reason to change preset. The server converts it while you watch.

Changing a library's preset applies to titles imported afterwards. Titles already in the library keep the format they were encoded in.
