# MediaServer Overview

MediaServer is the heart of NoMercy. It turns discs and video files you own into a clean, permanent library.

## The one idea to hold on to

It builds you a library.

You give it content. It works out what each title is, files it where that title belongs, and names it the same way as everything else on the shelf.

Playback is a separate question, and it is already answered: the server converts anything a client cannot take directly, while it plays. What is on the shelf never decides whether something plays.

## Two ways to fill a library

NoMercy can work either way, and the difference matters.

**Import.** You pick files or a disc and add them to a library. NoMercy lays each title out in the library folder and encodes it with that folder's profile, so the shelf holds one codec rather than whatever each source happened to be. Your own file is read, never moved or altered.

**Scan.** You point a library at a folder you already have. NoMercy reads what is there, works out what each file is, and lists it. The files are left exactly as they are.

You can mix them. Neither one moves, renames, or deletes your files.

### Which to use

MediaServer is an organiser and an archiver. Its purpose is to take what you own and turn it into a library that is laid out one way and kept in one format, so it is still yours and still readable years from now.

Import is that job done properly, and it is the route this documentation follows. A library folder that only ever receives imported titles has one layout and one codec, so there is nothing ambiguous about what is on it.

Scanning is fully supported and always will be. Point it at a collection you have already organised yourself and it reads it, lists it, and plays it, leaving every file untouched. Nothing about that path is second best.

The two answer different questions. Scanning asks the server to present what you already have. Importing asks it to build the archive.

## What happens when you import a title

1. You point NoMercy at a disc or a file.
2. It works out which movie or episode it is.
3. It encodes the title with the folder's profile: video, audio tracks, subtitles, chapters and preview thumbnails.
4. The result lands in your library folder, named and filed like everything else there.
5. Every client sees it.

Your source file stays where it was, unchanged.

## Playing back

Everything in a library plays, imported or scanned. Where a client cannot take a file as it stands, the server converts it while it plays.

So the codec your library is stored in is a choice about the library, not about playback. See [Encoding profiles](/nomercy-media-server/encoding/profiles).
