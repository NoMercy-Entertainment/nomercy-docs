# Recipes

These are the **kit-level** recipes — patterns that apply to any player built on `nomercy-player-core`, regardless of whether you are playing video or audio. Each is a self-contained guide with working code.

**Prerequisites:** a working install from the [Kit quickstart](/nomercy-player-kit/quickstart).

---

## Kit recipes

| Recipe                                                        | What it solves                                                            |
| ------------------------------------------------------------- | ------------------------------------------------------------------------- |
| [Media Session](/nomercy-player-kit/recipes/media-session)    | System MediaSession integration, lock-screen metadata, artwork            |
| [Persistence](/nomercy-player-kit/recipes/persistence)        | Storage adapter selection, saving playback position, restoring on reload  |
| [Auth and Tokens](/nomercy-player-kit/recipes/auth-and-tokens) | authFetch wrapper, refresh-on-401, propagating-on-403                     |

## Library-specific recipes

Anything tied to a media type lives with that library, not here. Subtitles, chapters, quality selection and keyboard shortcuts are video concerns; crossfade, gapless and lyrics/EQ are music concerns.

- **[Video Player recipes](/nomercy-video-player/recipes/overview)** — subtitles, chapters, quality selection, playlist/queue, keyboard shortcuts, live transcoding
- **[Music Player recipes](/nomercy-music-player/recipes/overview)** — playlist/queue, crossfade and gapless, lyrics and equalizer
