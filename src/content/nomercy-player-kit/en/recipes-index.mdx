# Recipes

You have a working player from the quickstart. This section covers the next most common integration tasks — each a self-contained recipe with working code.

**Prerequisites:** a working install from one of the quickstarts ([Video](/player/video/quickstart), [Music](/player/music/quickstart), or [Kit](/player/kit/quickstart)).
