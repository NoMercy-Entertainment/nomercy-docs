# Writing a Backend

Read this when you need to replace a built-in backend — either the HLS/html5 video backend (for DASH or a custom MSE pipeline) or the audio backend (for a custom Web Audio pipeline).

For the video-specific surface (`IVideoBackend`) see [Custom Video Backend](/nomercy-video-player/adapters/video-backend). For the music-specific surface (`IAudioBackend`) see [Custom Audio Backend](/nomercy-music-player/advanced/writing-an-audio-backend).

**Prerequisites:** [HLS](/nomercy-video-player/hls) covers the default video backend's capabilities. Read it first — many needs can be addressed without replacing the backend.

---

## When to replace the backend

Before replacing the backend, check whether the need can be addressed with lower-effort options:

1. **Custom stream factory** — register a `StreamFactory` via `registerStream()` to handle a new URL scheme or content type (e.g. DASH, smooth streaming). See [Adapter Ports — Streams](/nomercy-player-kit/streams).

2. **hls.js config override** — if you need to tune HLS behavior (bitrate cap, fragment retry count, level cap), configure it through the `hlsConfig` setup option rather than replacing the entire backend.

3. **Custom plugin** — if the need is behavioral (custom ABR, buffer management, fragment interception), write a plugin that wraps the backend rather than replacing it. See [Advanced: Custom Plugin](/nomercy-player-kit/advanced/custom-plugin).

Replace the backend only when none of the above covers the use case.

---

## Registering the backend

```ts
player.setup({
  backendFactory: (kind, config) => {
    return new MyVideoBackend(config.container);
  },
});
```

`backendFactory` receives the `kind` string and a `config` object that includes the player container element. Return an object that implements `IVideoBackend` or `IAudioBackend`.

## The IVideoBackend interface

All methods follow the overloaded-function convention: stateful values are read with no argument and written with an argument.

```ts
import type { IVideoBackend } from '@nomercy-entertainment/nomercy-video-player';
```

### Lifecycle

| Method    | Signature                               | Description                                |
| --------- | --------------------------------------- | ------------------------------------------ |
| `load`    | `(url: string, opts?) => Promise<void>` | Load a media URL                           |
| `unload`  | `() => void`                            | Clear the source                           |
| `dispose` | `() => void`                            | Full teardown                              |

### Transport

| Method  | Signature             | Description      |
| ------- | --------------------- | ---------------- |
| `play`  | `() => Promise<void>` | Begin playback   |
| `pause` | `() => void`          | Pause playback   |
| `stop`  | `() => void`          | Stop playback    |

### Time and position

| Method               | Signature                | Description                 |
| -------------------- | ------------------------ | --------------------------- |
| `currentTime()`      | `() => number`           | Current position in seconds |
| `currentTime(t)`     | `(t: number) => void`    | Seek to position `t`        |
| `duration()`         | `() => number`           | Total duration in seconds   |
| `buffered()`         | `() => number`           | End of buffered range       |
| `bufferedRanges()`   | `() => TimeRanges`       | Full buffered `TimeRanges`  |
| `seekable()`         | `() => TimeRanges`       | Seekable range              |
| `playbackRate()`     | `() => number`           | Current playback rate       |
| `playbackRate(rate)` | `(rate: number) => void` | Set playback rate           |

### Volume

| Method      | Signature             | Description              |
| ----------- | --------------------- | ------------------------ |
| `volume()`  | `() => number`        | Current volume (0–1)     |
| `volume(v)` | `(v: number) => void` | Set volume               |
| `mute()`    | `() => void`          | Mute audio               |
| `unmute()`  | `() => void`          | Unmute audio             |

### Events

Backends emit through a typed `on` / `off` pair. The kit subscribes in `backend()`:

```ts
backend.on('play', () => { /* ... */ });
backend.on('timeupdate', () => { /* ... */ });
backend.on('ended', () => { /* ... */ });
```

All event names and payload shapes are defined in `BackendEventPayload`. Your backend must call `on` / `off` with the same signature.

## Minimal custom backend

A skeleton that wraps a `<video>` element:

```ts
import type {
  IVideoBackend,
  BackendEvent,
  BackendEventPayload,
  BackendState,
  BackendLoaderState,
  QualityLevel,
} from '@nomercy-entertainment/nomercy-video-player';
import type { AudioTrack, SubtitleTrack } from '@nomercy-entertainment/nomercy-player-core';

type Listener<E extends BackendEvent> = (data?: BackendEventPayload[E]) => void;

export class MyNativeBackend implements IVideoBackend {
  readonly kind = 'html5' as const;

  private video: HTMLVideoElement;
  private listeners = new Map<string, Set<Listener<any>>>();

  constructor(container: HTMLElement) {
    this.video = document.createElement('video');
    this.video.style.width = '100%';
    this.video.style.height = '100%';
    container.appendChild(this.video);

    // Bridge native element events to the backend's own emitter:
    this.video.addEventListener('play', (event) => this._emit('play', event as Event));
    this.video.addEventListener('pause', (event) => this._emit('pause', event as Event));
    this.video.addEventListener('ended', (event) => this._emit('ended', event as Event));
    this.video.addEventListener('timeupdate', (event) => this._emit('timeupdate', event as Event));
    this.video.addEventListener('loadstart', (event) => this._emit('loadstart', event as Event));
    this.video.addEventListener('loadedmetadata', () => {
      this._emit('loadedmetadata', {
        url: this.video.src,
        kind: 'html5',
        duration: this.video.duration,
      });
    });
    this.video.addEventListener('canplay', (event) => this._emit('canplay', event as Event));
    this.video.addEventListener('waiting', (event) => this._emit('waiting', event as Event));
    this.video.addEventListener('playing', (event) => this._emit('playing', event as Event));
    this.video.addEventListener('emptied', (event) => this._emit('emptied', event as Event));
  }

  // Lifecycle
  async load(url: string): Promise<void> {
    this.video.src = url;
    this.video.load();
  }

  unload(): void {
    this.video.src = '';
    this.video.load();
  }

  dispose(): void {
    this.unload();
    this.video.remove();
    this.listeners.clear();
  }

  // Transport
  play(): Promise<void> { return this.video.play(); }
  pause(): void { this.video.pause(); }
  stop(): void { this.video.pause(); this.video.currentTime = 0; }

  // Time / position
  currentTime(): number;
  currentTime(t: number): void;
  currentTime(t?: number): number | void {
    if (t === undefined) return this.video.currentTime;
    this.video.currentTime = t;
  }

  duration(): number { return this.video.duration; }

  buffered(): number {
    const ranges = this.video.buffered;
    return ranges.length > 0 ? ranges.end(ranges.length - 1) : 0;
  }

  bufferedRanges(): TimeRanges { return this.video.buffered; }
  seekable(): TimeRanges { return this.video.seekable; }

  playbackRate(): number;
  playbackRate(rate: number): void;
  playbackRate(rate?: number): number | void {
    if (rate === undefined) return this.video.playbackRate;
    this.video.playbackRate = rate;
  }

  // Volume
  volume(): number;
  volume(v: number): void;
  volume(v?: number): number | void {
    if (v === undefined) return this.video.volume;
    this.video.volume = v;
  }

  mute(): void { this.video.muted = true; }
  unmute(): void { this.video.muted = false; }

  // Video-specific (no ABR on native backend)
  videoWidth(): number { return this.video.videoWidth; }
  videoHeight(): number { return this.video.videoHeight; }
  audioTracks(): AudioTrack[] { return []; }
  setAudioTrack(_idx: number): void { /* no-op */ }
  subtitleTracks(): SubtitleTrack[] { return []; }
  setSubtitleTrack(_idx: number | null): void { /* no-op */ }
  qualityLevels(): QualityLevel[] { return []; }
  setQuality(_idx: number | 'auto'): void { /* no-op */ }
  currentLevel(): number { return -1; }

  // State
  state(): BackendState { return this.video.paused ? 'paused' : 'playing'; }

  // Raw element access
  mediaElement(): HTMLVideoElement { return this.video; }

  // MediaStream capture
  captureStream(): MediaStream {
    return (this.video as HTMLVideoElement & { captureStream?: () => MediaStream }).captureStream?.() ?? new MediaStream();
  }

  // Audio output
  async setSinkId(deviceId: string): Promise<void> {
    const el = this.video as HTMLVideoElement & { setSinkId?: (id: string) => Promise<void> };
    await el.setSinkId?.(deviceId);
  }

  getSinkId(): string {
    const el = this.video as HTMLVideoElement & { sinkId?: string };
    return el.sinkId ?? '';
  }

  // EME / DRM
  mediaKeys(): MediaKeys | undefined { return this.video.mediaKeys ?? undefined; }
  async setMediaKeys(keys: MediaKeys): Promise<void> { await this.video.setMediaKeys(keys); }
  outputProtectionState(): 'unrestricted' | 'restricted' | 'unsupported' { return 'unrestricted'; }

  // Loader backpressure (no-ops for native element)
  pauseLoader(): void { /* no-op */ }
  resumeLoader(): void { /* no-op */ }
  loaderState(): BackendLoaderState { return 'running'; }

  // Events
  on<E extends BackendEvent>(event: E, fn: Listener<E>): void {
    if (!this.listeners.has(event)) this.listeners.set(event, new Set());
    this.listeners.get(event)!.add(fn as Listener<any>);
  }

  off<E extends BackendEvent>(event: E, fn: Listener<E>): void {
    this.listeners.get(event)?.delete(fn as Listener<any>);
  }

  private _emit<E extends BackendEvent>(event: E, data?: BackendEventPayload[E]): void {
    this.listeners.get(event)?.forEach(fn => fn(data));
  }
}
```

Register it:

```ts
player.setup({
  backendFactory: (_kind, config) => new MyNativeBackend(config.container),
});
```

## Shaka Player backend example

Shaka Player is a DASH/HLS player from Google. The Shaka SDK uses its own `getVariantTracks()` / `selectVariantTrack()` API — those are Shaka's methods, not the kit's. Your backend wraps them and exposes the kit's overloaded-function surface:

```ts
import shaka from 'shaka-player';
import type {
  IVideoBackend,
  BackendEvent,
  BackendEventPayload,
  BackendState,
  BackendLoaderState,
  QualityLevel,
} from '@nomercy-entertainment/nomercy-video-player';
import type { AudioTrack, SubtitleTrack } from '@nomercy-entertainment/nomercy-player-core';

type Listener<E extends BackendEvent> = (data?: BackendEventPayload[E]) => void;

export class ShakaBackend implements IVideoBackend {
  readonly kind = 'html5' as const;

  private shakaPlayer: shaka.Player;
  private video: HTMLVideoElement;
  private listeners = new Map<string, Set<Listener<any>>>();

  constructor(container: HTMLElement) {
    this.video = document.createElement('video');
    container.appendChild(this.video);
    this.shakaPlayer = new shaka.Player();
    this.shakaPlayer.attach(this.video);

    this.video.addEventListener('play', (event) => this._emit('play', event as Event));
    this.video.addEventListener('pause', (event) => this._emit('pause', event as Event));
    this.video.addEventListener('ended', (event) => this._emit('ended', event as Event));
    this.video.addEventListener('timeupdate', (event) => this._emit('timeupdate', event as Event));
    this.video.addEventListener('loadstart', (event) => this._emit('loadstart', event as Event));
    this.video.addEventListener('loadedmetadata', () => {
      this._emit('loadedmetadata', {
        url: this.video.src,
        kind: 'html5',
        duration: this.video.duration,
      });
    });
    this.video.addEventListener('canplay', (event) => this._emit('canplay', event as Event));
    this.video.addEventListener('waiting', (event) => this._emit('waiting', event as Event));
    this.video.addEventListener('playing', (event) => this._emit('playing', event as Event));
    this.video.addEventListener('emptied', (event) => this._emit('emptied', event as Event));

    // Shaka-specific: bridge variant changes to level-switched
    this.shakaPlayer.addEventListener('variantchanged', () => {
      const variant = this.shakaPlayer.getVariantTracks().find((t) => t.active);
      if (variant) this._emit('level-switched', { level: variant.id });
    });
  }

  async load(url: string): Promise<void> {
    await this.shakaPlayer.load(url);
    const levels = this.qualityLevels();
    this._emit('levels', { levels });
  }

  unload(): void { this.shakaPlayer.unload(); }

  async dispose(): Promise<void> {
    await this.shakaPlayer.destroy();
    this.video.remove();
    this.listeners.clear();
  }

  play(): Promise<void> { return this.video.play(); }
  pause(): void { this.video.pause(); }
  stop(): void { this.video.pause(); this.video.currentTime = 0; }

  currentTime(): number;
  currentTime(t: number): void;
  currentTime(t?: number): number | void {
    if (t === undefined) return this.video.currentTime;
    this.video.currentTime = t;
  }

  duration(): number { return this.video.duration; }

  buffered(): number {
    const ranges = this.video.buffered;
    return ranges.length > 0 ? ranges.end(ranges.length - 1) : 0;
  }

  bufferedRanges(): TimeRanges { return this.video.buffered; }
  seekable(): TimeRanges { return this.video.seekable; }

  playbackRate(): number;
  playbackRate(rate: number): void;
  playbackRate(rate?: number): number | void {
    if (rate === undefined) return this.video.playbackRate;
    this.video.playbackRate = rate;
  }

  volume(): number;
  volume(v: number): void;
  volume(v?: number): number | void {
    if (v === undefined) return this.video.volume;
    this.video.volume = v;
  }

  mute(): void { this.video.muted = true; }
  unmute(): void { this.video.muted = false; }

  videoWidth(): number { return this.video.videoWidth; }
  videoHeight(): number { return this.video.videoHeight; }
  audioTracks(): AudioTrack[] { return []; }
  setAudioTrack(_idx: number): void { /* no-op */ }
  subtitleTracks(): SubtitleTrack[] { return []; }
  setSubtitleTrack(_idx: number | null): void { /* no-op */ }

  // Shaka's getVariantTracks() is Shaka's own SDK API — wrapped here:
  qualityLevels(): QualityLevel[] {
    return this.shakaPlayer.getVariantTracks().map((track) => ({
      id: track.id,
      width: track.width ?? 0,
      height: track.height ?? 0,
      bitrate: track.bandwidth,
      label: track.label ?? undefined,
    }));
  }

  setQuality(idx: number | 'auto'): void {
    if (idx === 'auto') {
      this.shakaPlayer.configure({ abr: { enabled: true } });
      return;
    }
    const tracks = this.shakaPlayer.getVariantTracks();
    const target = tracks.find((t) => t.id === idx);
    if (target) this.shakaPlayer.selectVariantTrack(target, true);
  }

  currentLevel(): number {
    const active = this.shakaPlayer.getVariantTracks().find((t) => t.active);
    return active?.id ?? -1;
  }

  state(): BackendState { return this.video.paused ? 'paused' : 'playing'; }

  mediaElement(): HTMLVideoElement { return this.video; }

  captureStream(): MediaStream {
    return (this.video as HTMLVideoElement & { captureStream?: () => MediaStream }).captureStream?.() ?? new MediaStream();
  }

  async setSinkId(deviceId: string): Promise<void> {
    const el = this.video as HTMLVideoElement & { setSinkId?: (id: string) => Promise<void> };
    await el.setSinkId?.(deviceId);
  }

  getSinkId(): string {
    const el = this.video as HTMLVideoElement & { sinkId?: string };
    return el.sinkId ?? '';
  }

  mediaKeys(): MediaKeys | undefined { return this.video.mediaKeys ?? undefined; }
  async setMediaKeys(keys: MediaKeys): Promise<void> { await this.video.setMediaKeys(keys); }
  outputProtectionState(): 'unrestricted' | 'restricted' | 'unsupported' { return 'unrestricted'; }

  pauseLoader(): void { /* no-op */ }
  resumeLoader(): void { /* no-op */ }
  loaderState(): BackendLoaderState { return 'running'; }

  on<E extends BackendEvent>(event: E, fn: Listener<E>): void {
    if (!this.listeners.has(event)) this.listeners.set(event, new Set());
    this.listeners.get(event)!.add(fn as Listener<any>);
  }

  off<E extends BackendEvent>(event: E, fn: Listener<E>): void {
    this.listeners.get(event)?.delete(fn as Listener<any>);
  }

  private _emit<E extends BackendEvent>(event: E, data?: BackendEventPayload[E]): void {
    this.listeners.get(event)?.forEach(fn => fn(data));
  }
}
```
