# Player trio map

**Scope:** the three player trio collections, checked against each package master recorded in toolchain.md.
**Excluded:** native reference and native guides, plus nomercy-media-session and eslint-plugin-player.
**Audience:** a web developer installing Player Core, the video player, or the music player.
**Destination:** `src/content/nomercy-player-core/en/`, `src/content/nomercy-video-player/en/`, and `src/content/nomercy-music-player/en/`.
**Conventions:** `DOCS-CONTRACT.md`, `CLAUDE.md`, and the player-trio brief.
**Reference pages:** introduce `/nomercy-player-core`, quickstart `/nomercy-player-core/quickstart`, tour `/nomercy-player-core/tour/queue`, build `/nomercy-player-core/build/compose-methods`, recipes `/nomercy-player-core/recipes/auth-fetch`, catalog `/nomercy-player-core/plugins-adapters/adapter-event-bus`, reference `/nomercy-player-core/reference/testing`. Core pages have no live player. Live players belong only on the quickstart and build pages of video and music.

## Excluded

- `src/content/nomercy-player-core/en/native`: generated from the player contract, and the native guides document the Kotlin ports.
- `src/content/nomercy-video-player/en/native`: generated from the player contract, and the native guides document the Kotlin ports.
- `src/content/nomercy-music-player/en/native`: generated from the player contract, and the native guides document the Kotlin ports.
- `nomercy-media-session`: not one of the three collections.
- `eslint-plugin-player`: not one of the three collections.
- `nomercy-player-core/src/core/append-auth-token-param.ts`: the coverage checker treats this filename as secret-bearing, so it is outside the map denominator. Behavior is in the core-kernel slice.
- `nomercy-player-core/src/core/title-tokens.ts`: the coverage checker treats this filename as secret-bearing, so it is outside the map denominator. Behavior is in the core-kernel slice.
- `nomercy-video-player/src/plugins/desktop-ui/i18n/token-bundle.ts`: the coverage checker treats this filename as secret-bearing, so it is outside the map denominator. Behavior is in the video-i18n slice.
